● 통계청 KOSIS 통계표 검색 (가동률)
  20건 · 예: DT_1F32002 제조업 평균가동률 / DT_2OEHG021 급성기 치료 병상 가동률 / DT_1F32001 제조업 생산능력 및 가동률지수(2020=100)
  ※ 표를 자동으로 고르지 않는다 — 같은 조사에 지수(2020=100)와 평균가동률(%)이 함께 있다
  ※ 항목·대조까지 보려면: npm run im:smoke -- --kosis-tbl <통계표ID>
  ※ 공장등록을 보려면: npm run im:smoke -- --factory-name <상호> [--factory-sido <시도>]
  ※ 수출입 단가를 보려면: npm run im:smoke -- --hs <HS코드> [--hs-from/to YYYYMM] [--hs-dir export|import]
  ※ 환경 인허가를 보려면: npm run im:smoke -- --enviro-name <상호> [--enviro-addr <주소>]
  ※ 계통 여유를 보려면: npm run im:smoke -- --grid-region <시·군·구> [--grid-mw <MW>]
  ※ 휴폐업을 보려면: npm run im:smoke -- --biz-no <사업자등록번호 10자리>
    ↳ **법인등록번호(13자리)가 아니다** — 넣으면 거절한다
  ※ 사업장 인원을 보려면: npm run im:smoke -- --workplace <사업장명>
  ※ 납세증명(국세완납증명)·지방세 납세증명·체납 내역은 **어떤 공개 API 로도 조회할 수 없다** — 「국세기본법」 제81조의13(비밀 유지)이 과세정보의 제3자 제공을 막는다. **본인이 발급하거나 본인 동의를 증명한 제3자만** 신청할 수 있다. 4대보험 완납증명도 같다. **당사자에게 서류로 받는다** (corp.tax_clearance)
