지금까지의 세션 내용을 다음 세션 인수인계용으로 정리하여
저장소 루트에 HANDOVER.md 파일로 저장하라.

반드시 포함할 항목:

## 1. 세션 목표
이번 세션에서 하려던 작업이 무엇이었는지 한 줄로.

## 2. 완료된 작업
- 수정/생성한 파일 목록과 각 변경의 핵심 내용
- 커밋했다면 커밋 해시와 메시지

## 3. 결정사항과 그 이유
- "A 대신 B 방식을 택했다 — 이유는 ___" 형식으로.
- 시도했다가 실패한 접근법도 기록한다 (다음 세션에서 같은 실수 반복 방지).

## 4. 미완료 작업 (다음 할 일)
- 우선순위 순서로, 각 항목에 관련 파일 경로 명시.

## 5. 주의사항
- 다음 세션에서 반드시 알아야 할 함정, 미해결 버그, 임시 처리(TODO/FIXME) 위치.

작성 규칙:
- 한국어로 작성한다.
- 기존 HANDOVER.md가 있으면 덮어쓰되, 파일 상단에 작성 일시(KST)를 남긴다.
- 코드 전체를 붙여넣지 말고 파일 경로와 변경 요지만 기록한다.
- 저장 후 "HANDOVER.md 저장 완료. 새 세션에서 'HANDOVER.md 읽고 이어서 진행'으로
  시작하세요."라고 안내한다.
