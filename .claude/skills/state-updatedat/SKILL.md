# 상태 변경 — 단일 출처 updatedAt

정본은 **`MEMORY.md` M-02** 한 곳이다 (규칙 · 체크리스트 · 재지시 경위). 이 스킬은 거기로 가는 절차다 — 여기 옮겨 적지 않는다(두 벌이면 한쪽이 옛말을 한다).

## 핵심 넷 (CLAUDE.md §7 · 2026-10-07 재지시)

1. **규칙** — 상태를 바꾸는 모든 길은 같은 자리에서 `updatedAt`(KST · `core/kst.js` 의 `kstStamp()` / 앱은 그 자료의 updatedAt 한 곳)을 새로 찍는다.
   파생값(그림 주소의 판 `v=` · 캐시 · 딱지 색)은 그 시각 하나에서 나온다.
2. **까닭** — 시각 없는 값·옛 사본·못 물은 «없음»이 새 값을 덮는다. M-02 색인 줄에 재지시 스물한 번(2026-10-22 까지)의 결이 쌓여 있다.
3. **재는 자리** — 그 기능의 검사 파일. 없으면 «못 잰다»라고 적는다.
4. **어디에 적었는지** — 답변에 절 번호·M 번호를 옮긴다.

## 절차

1. `grep -n "상태 토글 기능 검증 체크리스트" MEMORY.md` 로 체크리스트를 열고 **한 줄씩** 대 본다.
2. 새 결이 나왔으면 체크리스트 끝에 한 줄(〈날짜 · 출처〉 · 무엇이 났나 · 재는 자리)을 덧댄다.
3. 같은 지시를 또 받았으면 `### 재지시 경위 — 날짜 (N 번째 · …)` 를 마지막 경위 뒤에 더하고, **색인(맨 위 표의 M-02 줄)도 같은 커밋에서** 고친다.
4. 새 사고면 `## M-NNN` 본문 + 색인 줄을 함께 단다 — `memory-index.test.js` 가 빠짐을 잡는다.
5. 「적었다」는 커밋이 원격에 있는 것까지다 (M-130).
