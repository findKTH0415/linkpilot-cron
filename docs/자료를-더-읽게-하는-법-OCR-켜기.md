# 자료를 더 읽게 하는 법 — 읽기 힘(OCR) 켜기

> **왜 이 문서가 필요한가** 2026-08-23, 잠원동 딜 자료 11건 중 **7건이 안 읽혔습니다.**
> 그중에는 시행사 투자자료와 필지개발계획 PDF 가 있었습니다 — **딜의 핵심이 그쪽**입니다.
> 안 읽히면 그 자료의 값은 보고서에 안 실리고, 재무 항목은 「통상치」로 대체됩니다.
> 화면은 초록이고 보고서도 나옵니다. **달라지는 것은 숫자의 근거뿐**이라 눈에 안 띕니다.

---

## 1. 지금 무슨 일이 일어났나

3단계에서 자료를 올리면 화면이 파일마다 한 줄로 답합니다. 이번에는 이렇게 나왔습니다.

| 자료 | 결과 |
|---|---|
| 대상사업지_네이버 뉴스.pdf | 본문을 읽음 |
| 서초구 잠원동 38-23외 매각 자료 793평 동의서.pdf | 본문을 읽음 |
| 잠원동 38-23 주상복합 신축사업…코리아에셋자증권.xlsx | 본문을 읽음 |
| **시행사 잠원동 블럭개발 투자 (1).pdf** | **못 읽음** — 글자의 58% 가 코드값 |
| **잠원동 38-23외필지개발계획_(주)부강디앤씨.pdf** | **못 읽음** — 글자의 87% 가 코드값 |
| 스크린샷 4장 (.png) | **못 읽음** — 이미지 |
| 잠원동 역세권 활성화사업 용적율 인세티브 (1)(2).png | **못 읽음** — 이미지 |

읽힌 것은 **4건**이고, 거기서 값 15개가 나왔습니다.

### 「글자의 87% 가 코드값」이 무슨 말인가

PDF 안의 글자는 **글자 그 자체가 아니라 번호**로 들어 있을 때가 있습니다.
그 번호를 글자로 되돌리는 표(`ToUnicode`)를 같이 넣어 주지 않으면, 컴퓨터가
읽어도 **뜻 없는 기호만** 나옵니다. 한글 문서를 PDF 로 내보낼 때 자주 그렇습니다.

★ 이때 **억지로 뽑지 않습니다.** 깨진 글자를 그대로 뽑으면 그 안의 숫자가
**멀쩡한 값처럼** 들어가고, 그건 못 읽은 것보다 나쁩니다.

## 2. 무엇을 하면 되나 — 한 줄

**엔진에 「읽기 힘(OCR)」 키를 하나 넣으면 위 7건이 전부 읽힙니다.**

이미 그 기능은 만들어져 있습니다. 켜는 열쇠만 없습니다.

- 이미지(.png)는 글자로 옮겨 읽습니다.
- **코드값만 든 PDF 도 같은 길로 읽습니다** — 그림처럼 놓고 글자를 옮겨 적습니다.
- 옮겨 적은 값은 **신뢰도를 낮춰** 표시하고, 출처에 「옮겨 적은 것」이라고 남깁니다.
  사람이 나중에 원본을 다시 봐야 한다는 뜻입니다.

## 3. 열쇠 받기 (5분)

Google 계정이 있으면 무료로 받습니다.

1. 브라우저에서 **aistudio.google.com/apikey** 를 엽니다.
2. Google 계정으로 로그인합니다.
3. 파란 단추 **[Create API key]** 를 누릅니다.
4. 프로젝트를 고르라고 하면 아무거나 골라도 됩니다 (없으면 만들라고 나옵니다).
5. `AIza…` 로 시작하는 긴 글자가 나옵니다. **복사 단추**를 눌러 둡니다.

### 여기서 대개 막힙니다

- **결제 정보를 묻는 화면이 나오면** 무료 등급으로도 됩니다 — 넘어가도 됩니다.
- 열쇠는 **한 번만 통째로 보여 줍니다.** 창을 닫기 전에 복사해 두십시오.
  잃어버려도 새로 만들면 되니 겁내실 것은 없습니다.

## 4. 열쇠를 NAS 에 넣기 — 마우스로 하는 길

터미널을 쓰지 않습니다. **File Station 으로** 합니다.

### ★ 먼저 — **검색을 쓰지 마십시오**

오른쪽 위 돋보기에 `env` 를 치면 **55개가 쏟아집니다.** 이 NAS 에는 `.env` 라는
이름의 파일이 여러 프로젝트에 하나씩 있어서, 검색 결과만 보면 **어느 것이
LinkPilot 것인지 알 수 없습니다.** 폴더를 따라 들어가셔야 합니다.

1. NAS 관리 화면(DSM)에 로그인합니다.
2. **File Station** 을 엽니다.
3. 왼쪽 나무 목록에서 **docker** 를 펼치고, 그 안의 **linkpilot** 을 누릅니다.
4. **여기가 맞는지 확인합니다.** 오른쪽 목록에 이 셋이 보여야 합니다:
   - `im-agent` (폴더)
   - `im-engine-server.cjs`
   - `start-engine.sh`

   **셋 중 하나라도 안 보이면 다른 폴더입니다.** 그 자리에서 멈추시고
   보이는 것을 알려 주십시오 — 제가 짚어 드리겠습니다.
### ★★ File Station 에서는 **파일을 못 만듭니다**

**[생성]** 을 눌러 보시면 **「폴더」밖에 없습니다.** 파일을 만드는 메뉴가 아예
없습니다 — 그래서 여기서 누르시면 `env` 라는 **폴더**가 만들어집니다.
(2026-08-23 에 실제로 그렇게 됐습니다. 안내가 없는 메뉴를 적고 있었습니다.)

그리고 점(`.`)으로 시작하는 이름은 NAS 화면에서 **기본으로 숨겨집니다.**

**그래서 점이 없는 이름도 읽도록 엔진을 고쳤습니다.**
`linkpilot.env` 라는 이름이면 됩니다 — 점이 없어 화면에 그냥 보입니다.

### 맥에서 만들어 올립니다 (마우스만)

5. **맥에서 텍스트 편집기(TextEdit)** 를 엽니다.
6. **[포맷] → [일반 텍스트로 만들기]** 를 누릅니다.
   (서식 있는 텍스트로 저장하면 글자가 깨져 들어갑니다 — **여기서 대개 막힙니다.**)
7. 한 줄만 적습니다. 등호 뒤에 복사해 둔 열쇠를 붙여 넣습니다.

       GEMINI_API_KEY=여기에_복사한_열쇠를_붙여넣습니다

8. **`linkpilot.env`** 라는 이름으로 바탕화면에 저장합니다.
9. File Station 의 **docker → linkpilot** 폴더에서 위쪽 **[업로드] → [업로드 - 건너뛰기]**
   를 누르고 그 파일을 고릅니다.
10. **올라온 파일의 이름을 확인합니다.** `linkpilot.env` 가 아니면 오른쪽 눌러
    **[이름 바꾸기]** 로 고칩니다.

### ★★ 이름이 두 번 붙는 함정 〈2026-08-23 · 실제로 그렇게 됐다〉

이름에 `linkpilot.env` 라고 적고 저장하면 맥이 **「.env」를 한 번 더 붙여**
`linkpilot.env.env` 가 됩니다. 대화상자에서 「.env 사용」을 눌러도 그렇습니다.

★ **맥에서 고치려 하지 마십시오.** Finder 는 확장자를 바꿀 때마다 또 물어봅니다.
  **그대로 올린 다음 File Station 에서 [이름 바꾸기]** 로 고치는 것이 가장 빠릅니다 —
  File Station 은 확장자를 안 물어봅니다.

### ★★★ 이미 올린 파일이 **서식 문서**였을 때 〈2026-08-23 · 실제로 그랬다〉

배포 #77 의 진단이 이렇게 말했습니다:

> `linkpilot.env — 475바이트 · 10줄 · **서식 문서(RTF)** · **읽힌 키가 없다** · 못 읽은 줄 9개`

한 줄만 적으셨는데 **10줄**인 것이 증거입니다. 텍스트 편집기가 글꼴·색·여백을
앞뒤에 아홉 줄쯤 붙여 놓았고, 그 안에 열쇠가 파묻혔습니다. 파일 이름도 자리도
맞고 크기도 그럴듯해서 **열어 보기 전에는 알 수가 없습니다.**

고치는 길이 둘입니다. **위쪽이 훨씬 짧습니다.**

**① NAS 안에서 고칩니다 (맥을 안 씁니다 — 권합니다)**

1. File Station 에서 **docker → linkpilot** 으로 갑니다.
2. `linkpilot.env` 를 **오른쪽 클릭** → **[Text Editor 로 열기]**
   - 이 메뉴가 안 보이면 Text Editor 가 안 깔린 것입니다. ②로 가십시오.
3. 창이 열리면 **알아볼 수 없는 글자가 잔뜩** 보입니다 — 그것이 서식입니다.
4. **⌘A(전체 선택) → Delete** 로 **전부 지웁니다.**
5. 등호 뒤에 열쇠를 붙여 넣어 **한 줄만** 남깁니다.
6. **[저장]** 을 누릅니다. Text Editor 는 서식을 안 붙입니다 — 이걸로 끝입니다.

**② 맥에서 다시 만들어 덮어씁니다**

1. 텍스트 편집기(TextEdit)를 **먼저 열고**, **[포맷] → [일반 텍스트로 만들기]** 를
   **누른 다음에** 글을 적습니다.
   - ★ **순서가 중요합니다.** 다 적고 나서 누르면 이미 서식이 붙은 뒤입니다.
   - 눌렀는지 어떻게 아나: 창의 글자가 **고정폭(타자기 글꼴)**으로 바뀌고,
     [포맷] 메뉴의 그 자리가 **[서식 있는 텍스트로 만들기]** 로 바뀝니다.
2. `linkpilot.env` 로 저장 → File Station 의 **docker → linkpilot** 에
   **[업로드] → [업로드 - 덮어쓰기]** 로 올립니다.
   - 이번에는 **건너뛰기가 아니라 덮어쓰기**입니다. 건너뛰기를 누르면
     **서식 문서가 그대로 남습니다.**
3. 이름이 `linkpilot.env.env` 로 붙었으면 File Station 에서 [이름 바꾸기].

### 이미 `.env` 가 있으시면

위쪽 **[설정]** 에서 **「숨김 파일 표시」**를 켜면 보입니다. 그 파일을 오른쪽 눌러
**[Text Editor 로 열기]** 하고 맨 아래에 위 한 줄을 더하시면 됩니다.
**둘 다 있으면 `.env` 가 이깁니다.**

### 지켜야 할 것 넷

- **`env` 나 `.env` 라는 폴더를 만드셨으면 지워 주십시오.** 그냥 두어도 고장은
  안 납니다(엔진이 폴더는 건너뜁니다) — 다만 다음에 볼 때 헷갈립니다.
- **올린 뒤 이름을 눈으로 확인하십시오.** `linkpilot.env.env` 처럼 두 번 붙기
  쉽습니다. 이름이 틀리면 **오류 없이 그냥 계속 「꺼짐」**입니다.
- **따옴표로 감싸지 않습니다.** 감싸면 따옴표까지 열쇠의 일부로 읽혀
  **인증만 실패하고 이유가 안 보입니다.**
- **등호 앞뒤에 빈칸을 넣지 않습니다.**
- 이 파일은 **NAS 안에만** 둡니다. 저장소(GitHub)에 올리지 않습니다 — 공개
  저장소라 열쇠가 그대로 남습니다.

### 넣을 곳이 왜 하필 거기인가

엔진은 **자기 폴더 바로 위**에서 `.env` 또는 `linkpilot.env` 를 찾습니다. `im-agent` 가 들어 있는
그 폴더입니다. 한 칸 위(`docker`)나 한 칸 아래(`im-agent` 안)에 두면 **안 읽습니다** —
그때도 오류는 안 나고 그냥 계속 「꺼짐」입니다.

★ 이 파일은 배포가 **안 건드립니다.** 배포는 `im-agent` 폴더만 바꿔 넣습니다.
한 번 넣어 두시면 그대로 남습니다.

## 6. 켜졌는지 확인하는 법 — 두 가지

**① 배포 기록에서**

배포가 끝나면 요약에 한 줄이 적힙니다.

- `OCR: 켜짐 — 스캔본·이미지·코드값 PDF 를 글자로 옮겨 읽는다` → 된 것입니다.
- `OCR: **꺼짐**` → 아직입니다. 파일 이름(`.env`)과 줄 모양을 다시 봐 주십시오.

**★ 「꺼짐」이 나오면 — 그 바로 아래 줄에 원인이 적힙니다** 〈2026-08-23 추가〉

앞 판은 「꺼짐」 한 마디로 끝났습니다. 그런데 그 말로는 **다음에 무엇을 봐야
할지 알 수가 없습니다** — 아래 다섯이 전부 똑같이 「꺼짐」으로 보입니다.

| 실제로 일어난 일 | 이제 로그에 나오는 말 |
|---|---|
| 이름이 파일이 아니라 폴더다 | `.env — **폴더다.** 파일이어야 한다` |
| 서식 있는 텍스트로 저장됐다 ← **이번에 이것이었습니다** | `**서식 문서(RTF)** — [일반 텍스트로 만들기] 를 안 눌렀다` |
| 줄이 `KEY=값` 모양이 아니다 | `못 읽은 줄 1개 (KEY=값 모양이 아니다)` |
| 값에 따옴표·빈칸이 섞였다 | `**따옴표가 값에 섞였다**` |
| 자리표시자를 안 바꿨다 | `**자리표시자가 그대로 들어 있다**` |

제대로 됐으면 `읽힌 키: GEMINI_API_KEY` 와 `엔진이 보는 상태: OCR 켜짐` 이
나옵니다. **열쇠 값 자체는 로그에 한 글자도 안 남습니다** — 길이와 앞 네 글자가
`AIza` 인지 여부만 적습니다.

**② 화면에서**

3단계에서 **안 읽혔던 파일을 다시 올려** 봅니다.
「못 읽었습니다 — GEMINI_API_KEY 가 필요합니다」가 사라지고
「글자로 옮겨 읽음」으로 바뀌면 된 것입니다.

## 7. 켠 뒤에 달라지는 것

| | 지금 | 켠 뒤 |

| 읽히는 자료 | 11건 중 4건 | **11건 전부** |

돌립니다. 근거 문구를 원문과 대조하는 장치도 그대로 돕니다 — 다만 **신뢰도를
낮춰** 표시하므로, 출처표에서 「이 값은 원본을 다시 봐야 한다」가 보입니다.
