## 1. 요청 취지

배포본 지침과 실제 앱을 대조한 결과 **4건이 어긋나 있었습니다.** 앱 쪽은 지침에
맞추어 수정을 마쳤으나(§2), **지침 자체를 고쳐야 하는 것과 확정이 필요한 것**이
남아 있어 요청드립니다.

지침은 사내 문서가 아니라 **협력사에 배포된 문서**입니다. 앱과 어긋나면
"지침에는 된다는데 안 된다"는 문의가 외부에서 들어오고, 그때는 이미 신뢰 문제가
된 뒤입니다. 그래서 앱을 지침에 맞추는 것을 원칙으로 삼았고, 지침을 고쳐야만
해소되는 것만 아래에 남겼습니다.

## 2. 앱 수정으로 이미 해소한 것 (참고 · 회신 불필요)

| 지침 | 어긋나 있던 상태 | 조치 |
|---|---|---|
| §2 보고서 생성 **(Pro)** | 검증 보고서만 Business 요구 → Pro 회원이 문서대로 눌렀다 403 | 화면·서버 모두 Pro 로 통일 |
| §2 무료 이용 범위 | Free 플랜 카드에 "프로젝트 3건" 등 **지침에 없는 한도** 표시 | 근거 없는 한도 문구 삭제 |
| §2 "보이되 잠겨 있습니다" | 화면마다 잠금 표시가 달랐음 (자물쇠 없는 화면 존재) | 전 화면 공통 적용 |
| §1 "[외부 브라우저로 열기] 배너" | **배너 자체가 없었음** | 카카오톡·라인 등 감지 후 배너 표시 |

지침 §7-3 「[인쇄 · PDF 저장]」도 화면에 추가했습니다(연결 작업은 §4-2 참조).

## 3. 지침 개정이 필요한 항목

### A-1. 유료 기능의 등급 표기 〈확정 필요〉

지침 §2 는 유료 기능을 하나로 묶고 `보고서 생성 (Pro)` 한 건만 등급을 적었습니다.
그러나 요금제는 **Free / Basic USD 25 / Pro USD 55 / Business USD 130** 4단계입니다.
등급이 적히지 않은 기능은 현재 아래와 같이 **잠정 설정**되어 있습니다.

| 기능 | 현재 잠정 등급 | 근거 |
|---|---|---|
| 오늘의 한줄생각 | Basic | 추정 |
| 아침브리핑 | Basic | 추정 |
| **통화음성분석** | **Pro** | **추정 — 확정 필요** |
| **프리미엄 투자소스 DB** | **Pro** | **추정 — 확정 필요** |
| **신재생에너지 분석** | **Business** | **추정 — 확정 필요** |
| 보고서 생성 | Pro | **지침 명시** |

> **위험** — Basic(USD 25) 회원에게 열려야 할 기능이 Pro 로 잠겨 있으면 결제한
> 회원이 못 씁니다. 반대로 Business 전용이어야 할 기능이 Pro 에 열려 있으면
> 상위 플랜의 가치가 사라집니다. 어느 쪽이든 등급이 확정되어야 합니다.

**요청** — 위 3건(★)의 등급을 확정해 주십시오. 확정 후 지침 §2 에도
`(Pro)` 처럼 등급을 병기하면 협력사 문의가 줄어듭니다.

### A-2. Free 플랜의 사용 한도 〈확정 필요〉

지침 §2 무료 칸은 기능만 나열하고 **한도를 적지 않았습니다.**
앱에는 "프로젝트 3건"이라는 근거 없는 문구가 있어 삭제했습니다.

**요청** — 아래 중 하나를 지정해 주십시오.

- [ ] 한도 없음 (기능 구분만)
- [ ] 한도 있음 → 항목과 수치: ________________________

한도를 두는 경우 지침 §2 에 명기해야 합니다. 앱에만 있으면 협력사가 예고 없이 막힙니다.

### A-3. 요금 표기 통화 〈확인 필요〉

현재 화면은 **USD** 로 표기합니다(Basic 25 / Pro 55 / Business 130).
국내 협력사 대상 문서라면 원화 표기 또는 병기가 자연스럽습니다.

- [ ] USD 유지  · [ ] KRW 로 변경  · [ ] 병기

### A-4. 지침 §4 「서버 자동 변환 준비 중」 〈시점 확인〉

H.265 영상을 서버에서 변환하는 기능이 "준비 중"으로 적혀 있습니다.
**이 저장소에는 해당 기능이 없습니다.** 본체에 있는지, 계획만 있는지 확인이 필요합니다.

- [ ] 본체에 이미 있음 → 담당/경로: ________________
- [ ] 계획만 있음 → 지침에서 문구 조정 권고 (기대만 생기고 동작하지 않으면 문의가 됩니다)

### A-5. 지침 §3 「이어서 올라갑니다」 〈동작 확인〉

업로드 재개(이어올리기)는 **본체 기능이라 이 저장소에서 검증할 수 없었습니다.**
지침이 명시적으로 약속한 동작이므로 실제 확인이 필요합니다.

- [ ] 확인함 — 정상 동작
- [ ] 확인함 — 동작하지 않음 → 지침 문구 수정 필요

## 4. 제공 요청 자료

### 4-1. 본체 앱 소스 〈최우선〉

`linkpilot-platform` 저장소가 비어 있어 아래 작업이 전부 멈춰 있습니다.

- 보고서 생성 API 를 실제 서버에 배선 (**코드는 완성 상태, 붙이기만 하면 됨**)
- 로그인 세션 연결 (현재는 화면 설정값으로만 동작)
- 새로 만든 화면들을 실제 메뉴에 편입
- 업무지시 보드 저장 기능

> 지금 만든 화면들은 스크린샷과 지침을 근거로 테마를 맞춘 것이며,
> **실제 앱 소스를 보고 만든 것이 아닙니다.** 소스가 오면 다시 맞춰야 합니다.

### 4-2. 산출물 파일 경로

지침 §7-3 「[인쇄 · PDF 저장]」 버튼은 화면에 추가했으나, 산출물 HTML 을 내려주는
경로가 서버에 없어 현재는 안내만 표시됩니다.

**요청** — `12_Final/*.html` 을 서빙하는 경로 규칙을 알려주시면 즉시 연결합니다.
