## 1. 개요 및 목적
본 업무지침은 LinkPilot 플랫폼의 AI 엔진 연동 방식과 요금제(Free, Pro, Business) 간의 가격 정책 및 서비스 구조를 명확히 정의하고, 고객 가치 극대화와 인프라 운영 효율성을 동시에 달성하는 것을 목적으로 한다.

## 2. AI 엔진 연동 방식 및 요금제 구조

LinkPilot은 **BYOK (Bring Your Own Key)** 모델과 **플랫폼 일체형 구독 모델**을 혼용하여 사용자 선택권을 보장한다.

```
[ LinkPilot 요금 체계 모델 ]
├─ Free (무료)      : 기본 횟수 제한 제공
│   └─ API 연동     : 사용자 개인 API Key 직접 등록 시 횟수 제한 없이 무제한 무료 이용
├─ Pro (프리미엄)    : 월 ₩29,000 / 별도 API 발급 없이 제약 없는 무제한 사용
└─ Business (비즈니스): 사용자 AI 엔진 + 유료 콘텐츠 제한 없음 (기업 및 헤비유저 전용)
```

### 2.1. 요금제별 상세 명세

| 항목 | 무료 (Free) | 프리미엄 (Pro) | 비즈니스 (Business) |
| :--- | :--- | :--- | :--- |

## 3. API 이용료 대비 Pro 요금제(₩29,000) 원가 및 가격 타당성 분석

### 3.1. 사용자 AI API 직접 사용 시 예상 원가
* **경량형 모델 (GPT-4o mini, Claude 3.5 Haiku 등)**
  * 일반 비즈니스 데이터 처리 기준 월 평균 $1 ~ $5 (약 1,400원 ~ 7,000원) 발생
* **고성능 모델 (GPT-4o, Claude 3.5 Sonnet 등)**
  * 대용량 문서 분석 및 다량 처리 시 월 평균 $10 ~ $25 (약 14,000원 ~ 35,000원) 발생

### 3.2. Pro 요금제(₩29,000) 가격 타당성 원가 구성표

Pro 요금제 29,000원은 단순 API 비용의 대행이 아닌, 서비스 안정성과 인프라 통합 관리를 포함하는 합당한 가격 책정이다.

```
[Pro 요금제 ₩29,000 구성 비율]
┌─────────────────────────────────────────────────────────────┐
│ ■ AI API 원가 대행 및 보장 (약 25% ~ 35%) : ₩7,000 ~ ₩10,000│
│ ■ 서버/DB/음성인식 인프라 관리비 (약 25%) : ₩7,000 ~ ₩8,000 │
│ ■ 데이터 정제, UI/UX, 플랫폼 마진 (약 40%) : ₩11,000 ~ ₩12,000│
└─────────────────────────────────────────────────────────────┘
```

#### 가격 타당성 확보 요인
1. **복잡성 제거**: 카드 등록, 해외 결제, API Key 관리 및 보안 리스크를 플랫폼이 전적으로 대행.
2. **비용 예측 가능성**: 종량제 API 사용 시 발생할 수 있는 '비용 폭탄' 리스크 방지 (고정 월정액 제공).
3. **부가 서비스 통합**: 통화 음성 인식(STT), AI 프롬프트 최적화, 딜 파이프라인 연동 기능 제공.

## 4. 고객 세그먼트별 대응 및 운영 가이드라인

### 4.1. 사용자 세그먼트별 추천 요금제

* **개발자 / IT 친화적 사용자 (API 직접 보유)**
  * **무료(Free) 플랜 + API Key 연동** 안내
  * API Key만 입력하면 모든 기능을 제약 없이 사용할 수 있음을 강조하여 사용자 유입 유도.
* **비개발자 / 일반 비즈니스 사용자**
  * **프리미엄(Pro) 플랜** 안내
  * 설정의 번거로움 없이 안정적인 AI 서비스와 넉넉한 할당량(통화분석 300분 등)을 한 번에 이용 가능함을 강조.
* **기업 및 단체 (Enterprise)**
  * **비즈니스(Business) 플랜** 안내
  * 보안 강화, 전용 AI 엔진 연동, 유료 콘텐츠 및 보고서 무제한 생성 솔루션 제공.

---

## 5. 서비스 운영 및 세일즈 가이드

1. **API 키 관리 및 보안 강화**: 사용자가 입력한 개인 API Key는 암호화하여 저장하며, 오직 해당 사용자의 요청 처리에만 사용됨을 안내.
2. **이용률 모니터링**: Pro 요금제 사용자의 사용량이 초과할 경우, 차단 대신 알림 및 상위 플랜(Business) 안내 팝업 노출.
3. **프로모션 활용**: 신규 가입자에게 Pro 요금제 체험권을 제공하여 프리미엄 기능 경험 후 결제 전환 유도.
