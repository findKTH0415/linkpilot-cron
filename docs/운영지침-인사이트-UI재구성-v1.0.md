# LinkPilot 오늘의 인사이트 사용자 중심 UI 재구성 지침서

## 1. 문서 목적

오늘의 인사이트를 사용자가 짧은 시간 안에 원하는 글을 찾고, 상황에 맞게 다듬어, 소중한 사람에게 바로 전달할 수 있는 개인화 공유 서비스로 재구성한다.

핵심 원칙은 다음과 같다.

- 1차 선택: 무엇을 활용할 것인지 선택한다.
- 2차 선택: 누구에게 어떤 목적으로 보낼 것인지 선택한다.
- 3차 선택: 어떤 말투와 형식으로 전달할 것인지 선택한다.
- 사용자가 모든 항목을 직접 입력하지 않아도 오늘의 날짜·날씨·음력·절기·공휴일·개인일정을 바탕으로 기본값을 제안한다.
- 선택 단계는 단순하게 유지하고, 세부 설정은 접어서 제공한다.

## 2. 서비스 핵심 문구

> 오늘, 소중한 사람에게 보낼 말을 만들어 보세요.

보조 설명:

> 나의 글과 명언, 시, 인스타 글을 바탕으로 오늘의 상황에 맞는 메시지와 카드를 만들어 드립니다.

## 3. 전체 사용자 흐름

```text
오늘의 인사이트
  ↓
1차 선택: 콘텐츠 출처
  ↓
2차 선택: 수신자·목적·상황
  ↓
3차 선택: 말투·길이·전달 형식
  ↓
AI 메시지 3개 제안
  ↓
복사·저장·카드 만들기·공유
```

사용자는 1차 선택 후 기본 추천 결과를 즉시 볼 수 있어야 한다. 2차·3차 선택은 결과를 더 개인화하고 싶을 때 추가한다.

## 4. 1차 선택 구조 — 콘텐츠 출처

첫 화면에는 다음 5개 메뉴만 노출한다.

| 메뉴 | 사용자에게 제공하는 기능 |
|---|---|
| 오늘 추천 | 날짜·날씨·음력·절기·공휴일·개인일정을 반영한 자동 추천 |
| 나의 글 | 직접 작성한 글, 저장한 글, 새 글 작성 |
| 명언 | 주제별 명언과 짧은 해설 |
| 시집 | 인생시·창작시·짧은 시·주제별 시 |
| 인스타 글 | 인기·감성·일상·관계·비즈니스 콘텐츠의 요약 및 활용 |

### 4.1 오늘 추천

기본 진입 화면으로 사용한다.

자동 반영 항목:

- 오늘의 요일과 날짜
- 날씨와 계절
- 음력 날짜
- 24절기
- 공휴일·대체공휴일
- 기념일과 특별한 날
- 사용자의 일정과 오늘 보낼 사람
- 최근 사용한 콘텐츠와 중복 방지 이력

화면 문구 예시:

> 오늘은 금요일, 초가을입니다. 가까운 사람에게 가볍게 안부를 전해 보세요.

### 4.2 나의 글

하위 메뉴는 다음 순서로 제공한다.

1. 최근 작성한 글
2. 저장한 글
3. 새 글 작성
4. 주제별 내 글

사용자가 직접 쓴 글은 원문을 우선 보존하고, AI는 다음 작업만 수행한다.

- 한 줄 요약
- 카드용 문장 변환
- 말투 변경
- 길이 조정
- 수신자별 표현 조정

원문을 임의로 삭제하거나 의미를 바꾸지 않는다.

### 4.3 명언

초기 화면에는 인기 주제 5개만 노출하고 나머지는 `더보기`로 제공한다.

- 성공·도전
- 위로·공감
- 감사·관계
- 협업·상생
- 감성·힐링

추가 주제:

- 경제·투자
- 초심·기본
- 인내·장기전
- 신앙·묵상
- 리더십
- 배움·성장
- 가족·사랑
- 계절·자연
- 일상·안부

명언은 가능한 경우 출처, 저자, 원문 여부를 표시한다. 출처가 불분명한 문구는 유명인의 발언으로 단정하지 않는다.

### 4.4 시집

사용자가 어려운 문학 용어를 보지 않도록 쉬운 분류를 사용한다.

- 인생시
- 창작시
- 짧은 시
- 사랑·그리움
- 가족·감사
- 위로·회복
- 자연·계절
- 신앙·묵상

저작권 보호가 필요한 작품은 전문을 무단으로 노출하지 않고, 허용 범위의 짧은 인용·요약·출처 링크 방식으로 제공한다.

### 4.5 인스타 글

인스타 글은 원문 복사 기능이 아니라 다음 방식으로 제공한다.

- 주제 요약
- 출처 링크
- 핵심 메시지
- LinkPilot식 재구성 문장
- 저작권 및 이용 가능 여부

원문 전체 복제, 출처 없는 재게시, 작성자·계정 정보의 임의 변경을 금지한다.

## 5. 2차 선택 구조 — 수신자·목적·상황

2차 선택에서는 사용자가 메시지를 보내는 이유와 대상을 정한다. 한 화면에 모든 선택지를 펼치지 않고, `누구에게`와 `무슨 목적으로`를 순서대로 표시한다.

### 5.1 수신자

- 나에게
- 가족
- 연인
- 친구
- 동료
- 고객·거래처
- 사업 파트너
- 투자자
- 선배·어른
- 교인
- 직접 선택한 연락처

명함 또는 휴대전화 연락처와 연결된 경우 이름과 관계를 자동 제안하되, 최종 수신자는 사용자가 확인한다.

### 5.2 메시지 목적

- 평범한 하루의 안부
- 감사 전하기
- 응원·격려
- 위로·회복
- 축하하기
- 생일·기념일
- 출산·입학·졸업
- 취업·승진·새 출발
- 명절·공휴일 인사
- 계절·절기 인사
- 업무·비즈니스 인사
- 투자자·파트너 소식
- 나를 위한 기록

### 5.3 특별한 날 자동 제안

달력·특일 API와 연결해 해당 날짜에만 관련 선택지를 먼저 제안한다.

예시:

- 생일·기념일
- 결혼·출산
- 입학·졸업
- 취업·승진
- 명절·대체공휴일
- 음력 생일
- 절기
- 기독교·종교 기념일
- 국가기념일
- 사용자가 등록한 개인 기념일

특별한 날이 없으면 `오늘은 평범한 하루입니다`를 기본값으로 두고, 일반 안부 메시지를 제안한다.

## 6. 3차 선택 구조 — 말투·길이·전달 형식

3차 선택은 기본값을 자동 적용하고 사용자가 원할 때만 수정한다.

### 6.1 말투

- 따뜻하게
- 담백하게
- 진심 있게
- 유쾌하게
- 격식 있게
- 전문적으로
- 신앙·묵상형

### 6.2 길이

- 한 줄
- 짧은 메시지
- 카드 문구
- 긴 글

### 6.3 전달 형식

- 문자·카카오톡
- 인스타 캡션
- 이미지 카드
- 영상 카드
- 저장만 하기

### 6.4 이미지 테마

문장이 확정된 뒤 카드 제작 단계에서만 표시한다.

- 오늘 추천
- 자연·풍경
- 계절·날씨
- 명절·기념일
- 일상·감정
- 축하·경조사
- 종교·마음
- 업무·성공
- 취미·여행

실제 사진을 우선 사용하고, Unsplash·Pexels 등 외부 이미지는 출처·이용조건을 기록한다. AI 이미지 생성은 `원하는 이미지가 없나요?`라는 보조 선택으로 제공한다.

## 7. 메시지 생성 결과 화면

선택이 완료되면 한 번에 3개의 문장을 제안한다.

각 결과 카드에는 다음을 표시한다.

- 추천 문장
- 추천 이유
- 콘텐츠 출처 또는 생성 방식
- 적용된 수신자와 목적
- 말투와 길이
- 출처 링크가 있는 경우 링크

버튼:

- 복사
- 저장
- 이 글로 카드 만들기
- 다른 문장으로
- 말투 바꾸기
- 길이 바꾸기

추천 이유 예시:

> 금요일·초가을·지인에게 보내기 좋은 담백한 안부 문장입니다.

## 8. 카드 제작 및 공유 흐름

카드 제작은 문장과 수신자가 확정된 이후 시작한다.

```text
문장 선택
  ↓
수신자 확인
  ↓
배경 선택 또는 오늘 추천
  ↓
카드 미리보기
  ↓
저장·복사·공유
```

카드 미리보기에는 다음 기능을 제공한다.

- 문장 위치 조정
- 글자 크기 조정
- 배경 후보 변경
- 수신자 이름 표시 여부
- 출처 표시 여부
- 카드 저장
- 시스템 공유 시트 열기

자동 발송은 하지 않는다. 공유 또는 전송은 반드시 사용자가 마지막으로 실행한다.

## 9. 화면 배치 지침

### 9.1 첫 화면

1. 서비스 제목
2. 오늘의 추천 문장 또는 추천 이유
3. 1차 선택 탭
4. 최근 사용한 수신자
5. 오늘의 특별한 날 안내

### 9.2 선택 화면

- 현재 단계 표시: `1 콘텐츠 → 2 상황 → 3 표현`
- 한 화면에 핵심 질문 하나만 표시
- 선택 완료 시 다음 단계로 이동
- 이전 단계 수정 가능
- 기본값은 자동 적용

### 9.3 모바일 하단 고정 버튼

- 다시 만들기
- 저장
- 복사
- 카드 만들기

버튼은 문장이 생성된 이후에만 활성화한다.

## 10. 현재 화면에서 수정할 항목

| 기존 구조 | 개선 방향 |
|---|---|
| 명언·SNS·캘린더·카드가 한 화면에 길게 배치됨 | 1차·2차·3차 단계로 분리 |
| 테마 버튼이 처음부터 많이 노출됨 | 인기 5개만 노출하고 `더보기` 제공 |
| SNS 인사말이 별도 긴 영역으로 분리됨 | 메시지 생성 결과의 전달 형식으로 통합 |
| 캘린더가 본문 중간에 크게 표시됨 | `오늘의 상황 근거` 접이식 영역으로 이동 |
| 연락처 선택이 여러 화면에 반복됨 | 수신자 선택을 2차 단계에서 한 번만 수행 |
| 배경 이미지 선택이 문장보다 먼저 보임 | 문장 확정 후 카드 단계에서 제공 |
| 카드가 없다는 빈 상태가 먼저 보임 | 문장 선택 전 카드 영역을 비활성화 |
| 자동·나의 글 기능이 상위 구조와 혼재됨 | `나의 글` 내부에서 자동 변환·직접 작성으로 분리 |

## 11. 개인화 규칙

- 같은 문장이나 같은 콘텐츠 유형을 연속 3일 이상 추천하지 않는다.
- 최근 복사·저장·공유한 문장은 우선순위를 낮춘다.
- 수신자별로 최근 사용한 말투와 길이를 기억하되, 사용자가 언제든 변경할 수 있게 한다.
- 가족·친구·고객·투자자 등 관계에 따라 기본 말투를 다르게 제안한다.
- 날씨·계절·음력·절기·기념일은 문장 추천의 근거로 사용하되 과도하게 드러내지 않는다.
- 개인정보와 연락처는 사용자의 승인 없이 외부에 공개하거나 자동 발송하지 않는다.

## 12. 접근성 및 문구 기준

- 메뉴명은 `콘텐츠`, `상황`, `표현`처럼 쉬운 단어를 사용한다.
- 한 화면의 주요 선택지는 최대 5~7개로 제한한다.
- 긴 설명은 접어서 제공한다.
- 카드와 버튼의 글자는 모바일에서 쉽게 읽히는 크기로 유지한다.
- 생성 실패 시 원인을 짧게 설명하고 다시 시도 버튼을 제공한다.
- 출처·저작권·이미지 이용조건은 결과 화면에서 확인할 수 있어야 한다.

## 13. 성공 기준

다음 조건을 만족하면 사용자 중심 재구성이 완료된 것으로 본다.

- 첫 화면에서 사용자가 5초 안에 시작 메뉴를 이해할 수 있다.
- 1차 선택 후 기본 추천 결과가 즉시 표시된다.
- 2차 선택에서 수신자와 목적을 한 번에 설정할 수 있다.
- 3차 선택은 선택하지 않아도 기본값으로 문장이 생성된다.
- 생성 결과는 항상 3개가 제공된다.
- 복사·저장·카드 만들기·공유가 한 화면에서 가능하다.
- 모바일에서 긴 스크롤 없이 핵심 행동을 완료할 수 있다.
- 인스타 글과 외부 이미지에 출처·이용조건이 표시된다.
- 자동 발송 없이 사용자가 최종 공유를 승인한다.

## 14. 최종 화면 문구 예시

### 시작 화면

> 오늘, 누구에게 어떤 말을 보내고 싶으세요?

### 1차 선택

> 어떤 글에서 시작할까요?

### 2차 선택

> 누구에게, 어떤 마음을 전할까요?

### 3차 선택

> 어떤 느낌으로 표현할까요?

### 결과 화면

> 오늘의 상황에 맞춰 3개의 문장을 준비했습니다.

### 카드 화면

> 마음에 드는 문장을 카드로 만들어 보세요.

## 15. 최종 권장 구조

```text
[오늘 추천] [나의 글] [명언] [시집] [인스타 글]

1차: 무엇을 활용할까?
  → 콘텐츠 출처 선택

2차: 누구에게 왜 보낼까?
  → 수신자·목적·특별한 날 선택

3차: 어떻게 표현할까?
  → 말투·길이·전달 형식 선택

결과:
  → 문장 3개
```
