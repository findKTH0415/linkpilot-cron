- 측정일: 2026-10-13 (v4 이후 `커뮤니티 글로벌 재구성` 화면 추가분 반영 · 필터 명칭 변경 후 재측정, CSS 값 변동 없음)
- 측정 대상 (6개 파일)

  - `통화분석 일관 디자인.dc.html`

- 측정 방법: 템플릿의 모든 `style` · `style-hover` · `style-focus` · `style-active` 속성을 선언 단위로 나눠 집계했습니다. 실행 중에 바뀌는 값(`{{ }}` 자리)은 뺐습니다. `font:` 축약형은 굵기 · 크기 · 행간 · 글꼴로 풀어서 합산했습니다. 색상은 템플릿과 로직(JS)의 모든 hex · rgba 표기를 셌고, `#fff`와 `#FFF`는 같은 값으로 합쳤습니다.
- 규모: style 속성 8,347개 · 고정 CSS 선언 35,859개 (본 앱 30,687 · 통화분석 822 · 영수증 912 · 할일 860 · 브리핑 865 · 커뮤니티 1,713)
- 표기: `×N`은 여섯 파일을 합친 사용 횟수, `[커N]`은 그중 커뮤니티 화면의 횟수입니다.
