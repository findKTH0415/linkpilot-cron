# 광물 가치사슬 앱 제작 절차 + 상태 변경 규칙 (핵심 포인트)

기록일 2026-10-24 · 대표님 지시: 「광물자원 앱 만들어가는 과정을 숙지했다가 직접 할 때 참고」, 「스킬지침 업데이트를 항상 반영할 수 있도록 핵심 포인트 기록」

## 1. 규칙 — 상태 변경 시 단일 소스 updatedAt 필수

- 산출물(앱·미리보기·검증 HTML)의 갱신 시각과 rev는 **상수 하나**(`UPDATED_AT`)에서만 나온다.
- 화면 상단 스탬프, 검증 HTML, 보고 문구는 모두 이 값에서 파생한다. 손으로 따로 적지 않는다.
- 빌드 스크립트가 빌드할 때마다 `/*STAMP*/` 자리에 「YYYY-MM-DD HH:MM KST · rev N」을 넣는다. rev는 빌드마다 올린다.
- 데이터가 바뀌면 rev를 올려 다시 빌드한다. 같은 rev로 내용만 바꾸지 않는다.
- 미리보기가 옛 판으로 열리면 같은 아티팩트를 고치지 않고 새 ID로 다시 만든다(록키 rocky-preview-b7 전례).

## 2. 상태토글 기능 검증 체크리스트

배포 전에 브라우저로 직접 눌러 확인한다. 하나라도 어긋나면 배포하지 않는다.

1. 토글을 켜고 끌 때마다 화면 숫자가 실제 목록 수와 같다.
   - 대상: 칩(단계·광종·지역·상태), 체크박스(한국 관계·거래 이력·SI), 탭, 지역(한국/중국)
   - 화면 숫자: 「N곳」 문구, 카드 수, 지도 점 수
2. 별표(접촉 목록 담기/빼기)를 누를 때 세 곳이 함께 바뀐다.
   - 카드의 ★/☆
   - 상세 서랍의 버튼 문구(담기 ↔ 빼기)
   - 하단 막대의 「접촉 목록 N곳」
3. 새로 열어도 접촉 목록이 남아 있다.
   - 브라우저 저장소를 쓰고, 읽기·쓰기는 모두 try/catch로 감싼다.
   - 저장소가 막힌 환경에서도 화면이 깨지지 않는다.
4. 「조건 지우기」를 누르면 모든 토글이 처음 상태로 돌아가고 숫자도 함께 돌아간다.
5. 다른 탭으로 갔다 돌아와도 고른 상태가 유지된다. 지도에서 기업을 누르면 매칭 탭 상세로 정확히 넘어간다.
6. 갱신 스탬프의 rev가 이번 빌드 값과 같다(1번 규칙).
7. 화면 폭과 테마:
   - 데스크탑 1366, 모바일 390·360에서 가로 넘침 0건
   - 라이트·다크 두 테마 모두 확인
   - 스크립트 오류 0건
8. 결과는 검증 HTML로 남기고, 통과 출력 없이 「완료」라고 보고하지 않는다.

## 3. 광물 가치사슬 앱 제작 절차 (재사용용)

1. **범위 해석**
   - 5단계로 나눈다: 광산주 / 광업자원(탐사·개발·공기업) / 생산업체(제련·소재) / 유통업체 / 최종사용자.
   - 여기에 기존 투자자 DB를 「투자·금융」으로 붙인다.
   - 해석은 첫 메시지로 먼저 알린다.
2. **공통 규칙 파일(SCHEMA.md)**을 먼저 쓴다.
   - 단계 값, 광종 표준 낱말, 22개 필드, 「추정 금지 → 확인 필요」, 개인정보 금지를 정한다.
   - 추가 요청(SI·귀금속 등)은 같은 파일 끝에 「추가 규칙」으로 덧붙인다.
3. **단계별 병렬 조사**: 단계마다 조사 에이전트를 하나씩 둔다.
   - 웹 검색은 턴당 약 200회를 모든 에이전트가 나눠 쓴다. 회사당 2~3회로 묶는다.
   - 회사 공식 페이지를 직접 읽는 방식을 우선한다.
4. **병합(merge.py)**
   - 광종 표준화: 「핵심광물 전반」은 금·은과 맞추지 않는다. 금·은·납은 낱말 단위로 맞춘다.
   - 같은 기관이 두 단계에 있으면 하나로 합치고 「겸하는 단계」로 남긴다. 예: 글렌코어 = 광산주 + 유통.
   - 추가 조사 묶음끼리 겹치면 이름 기준으로 자동으로 합친다.
   - 거래·합작 상대 칸을 풀어 DB 기업과 잇는다. 「A·B」 표기는 나누고, 「~ 자회사 X」는 X로 잇는다.
   - 오매칭은 수동 표(MANUAL)와 차단 표(BLOCK)로 바로잡는다. 예: Mitsui Kinzoku → 미쓰이금속(물산 아님), Hyundai Hysco·ReSource는 연결 안 함.
   - 협회 회원명단에서 찾은 소속은 기업의 「소속 협회」 칸에 자동으로 더한다.
   - 최종사용자 SI는 광산·광물 관련 지분·합작·선급 투자만 인정한다. 셀 합작·제철소 합작은 제외한다.
5. **로고**
   - 받는 순서: Google s2 파비콘 → DuckDuckGo → gstatic faviconV2.
   - 같은 해시가 여러 회사에 나오면 기본 아이콘인지 점검한다.
   - 전체 로고를 한 장에 모아 눈으로 확인한다.
   - 엑셀 그림 위치는 행 앵커가 2칸 어긋날 수 있다. 감사보고서의 「로고 없음」 목록과 대조한다.
6. **엑셀(openpyxl)**
   - 요약 숫자는 모두 COUNTIF 수식으로 넣는다.
   - 열을 추가하면 열 위치 assert로 수식 범위를 다시 확인한다.
   - 관심도·접촉 여부는 드롭다운으로 둔다.
7. **앱(단일 HTML)**
   - 매칭 엔진: 내 단계 → 찾는 상대 → 대상 단계 표.
   - 맞는 이유를 칩으로 보여 준다. 점수·등급은 매기지 않는다.
   - 탭: 가치사슬 지도, 광물 지도(USGS 매장·생산), 광맥 지도(한국 시·군 / 중국 성), 협회·회원.
   - 지도 라이브러리: d3 7.9.0과 topojson 3.0.2를 cdnjs에서 불러온다.
   - 지도 경계 자료는 파일 안에 넣는다.
     - world-atlas 110m (npm)
     - southkorea-maps kostat 2013 (GitHub raw)
     - geojson-map-china
   - 나라 이름 → 지도 코드는 긴 이름부터 치환한다. 그래야 「인도」가 「인도네시아」에 잘못 걸리지 않는다.
8. **검증**
   - playwright로 1366/390/360 폭, 다크 모드, 오류 0건, 시나리오를 확인한다.
   - 시나리오 예: 생산업체 → 원료 공급처, 회사명 자동 채움, 지도 클릭.
   - 그다음 작성과 분리된 감사자가 표본을 대조한다.
9. **전달**
   - 아티팩트 한도(1,000개)에 걸리면 파일로 드리고 프로젝트 문서로 저장한다.
   - 「송부」 지시 전에는 Orchestrator로 넘기지 않는다.

## 4. 이번 작업에서 겪은 함정 (다음에 먼저 확인)
- 「핵심광물 전반」이 금 선택에 걸려 금 결과가 부풀었다(44곳 → 실제 23곳).
- 투자자 DB와 가치사슬 DB에 같은 기관이 중복으로 들어갔다(JOGMEC, 한국광해광업공단, 수출금융공사, Trafigura 등 14쌍).
- 출처 없이 기억으로 적었다고 보고된 매출 값(록히드·RTX·보잉·에어버스)은 「확인 필요」로 되돌렸다.
- USGS 표는 광종마다 단위가 다르다. 철광석·바나듐·몰리브덴은 매장량 단위가 따로 있다(`reserves_unit`). 표의 각주 숫자가 값에 붙어 읽히는 경우가 있어 PDF 원문과 대조했다.
- d3 join에 함수를 넘길 때 enter 선택에서 데이터를 읽으면 오류가 난다. `.join("g").each(...)`로 그린다.

## 5. 추가 함정 (2026-10-24 21시대 보강)
- 운영사·지분 칸을 쪼갤 때 숫자를 지우면 「South32」가 「South」로 남아 서던코퍼에 잘못 붙는다. 퍼센트 표기만 지우고 숫자가 든 이름은 그대로 둔다. 운영사가 「확인 필요」인 기록은 연결하지 않는다.
- 회사 이름 입력칸의 change 이벤트는 입력칸을 벗어날 때 한 번 더 일어난다. 같은 값이면 다시 그리지 않아야 첫 클릭(별표)이 빗나가지 않는다.
- 숨김 줄(hidden)을 끼워 넣을 때 기존 버튼이 그 안으로 들어가지 않는지 확인한다(「조건 지우기」 사례).
- 지도 점이 겹치면 아래 점을 누를 수 없다. 점 지름 이상으로 벌려 놓는다.
- 투자자 DB에 있는 전략적투자자(고려아연·미쓰이·마아덴 등)는 가치사슬 쪽 기록 하나로 합치고 「겸하는 단계」로 남긴다(이번 19쌍).
- WebFetch가 시간당 한도에 걸려도, 셸의 curl은 프록시를 거쳐 USGS PDF·공개 페이지를 받을 수 있었다(독립 감사 실측). 한국 공공 API 호스트는 여전히 막혀 있다.
- 광업원부(광업권자) 조회는 공식 공개 API가 없다. 「광업권 온라인 민원발급」(gwangup.motir.go.kr)에서 원부를 받아 붙여 넣는 방식으로 두고, 개인 광업권자 이름은 기본으로 가린다.
- 중국 표기는 「광상」이 아니라 「광산」으로 쓴다(2026-10-24 대표님 지시).
