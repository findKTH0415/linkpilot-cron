# 쇼츠 올리기 — 유튜브·인스타그램 계정 잇기 (사람 손 절차)

〈2026-10-28 사장님: 「인스타그램, YouTube, 쇼츠 배포자동화까지 자동화 해줘」 · CLAUDE.md §30〉

**무엇을 위해 하나** — 올리는 프로그램(Actions «쇼츠 올리기»)은 다 지어 두었습니다. 남은 것은 «이 계정에 올려도 된다»는 열쇠를 넣는 일 하나입니다.
열쇠는 GitHub 의 비밀 칸에만 들어가고, 저장소·로그·답변 어디에도 적히지 않습니다.

★ 이 문서에는 값을 하나도 적지 않습니다 — 공개 저장소입니다.

---

## 1. 유튜브 (열쇠 셋)

넣을 이름: `YOUTUBE_CLIENT_ID` · `YOUTUBE_CLIENT_SECRET` · `YOUTUBE_REFRESH_TOKEN`

낯선 말: **OAuth** = «내 계정에 이 프로그램이 올려도 된다»고 한 번 허락해 주는 방식. **갱신 열쇠(refresh token)** = 그 허락을 오래 쓰게 하는 열쇠.

1. **어디서**: 맥의 웹브라우저 · **무엇을**: Google Cloud 콘솔 (console.cloud.google.com) · **어떻게**: 맨 위 프로젝트 고르기 → [새 프로젝트] → 이름 «linkpilot-shorts» → [만들기].
   **그러면**: 위쪽에 새 프로젝트 이름이 보입니다.
2. **어디서**: 같은 콘솔 · **무엇을**: 왼쪽 메뉴 [API 및 서비스] → [라이브러리] → «YouTube Data API v3» 검색 → [사용].
   **그러면**: 그 API 화면에 «API 사용 설정됨»이 뜹니다.
3. **어디서**: [API 및 서비스] → [OAuth 동의 화면] · **어떻게**: 사용자 유형 [외부] → 앱 이름·이메일만 넣고 저장 → [테스트 사용자]에 유튜브 채널의 구글 계정을 더합니다.
   ★ **여기서 대개 막힙니다** — 맨 위 «게시 상태»가 [테스트]이면 갱신 열쇠가 **7일 뒤 저절로 끊깁니다.** [앱 게시] 를 눌러 «프로덕션»으로 바꿔 두십시오(검수 없이 본인 계정에 쓰는 것은 됩니다 · 로그인 때 «확인되지 않은 앱» 경고가 한 번 뜹니다 → [고급] → [이동]).
4. **어디서**: [API 및 서비스] → [사용자 인증 정보] → [+ 사용자 인증 정보 만들기] → [OAuth 클라이언트 ID] · **어떻게**: 유형 [웹 애플리케이션] · «승인된 리디렉션 URI»에 `https://developers.google.com/oauthplayground` 를 넣고 [만들기].
   **그러면**: «클라이언트 ID»와 «클라이언트 보안 비밀번호» 두 값이 뜹니다 — 이것이 열쇠 첫째·둘째입니다(창을 닫지 말고 5번으로).
5. **어디서**: 새 탭 developers.google.com/oauthplayground · **어떻게**: 오른쪽 위 톱니(설정) → [Use your own OAuth credentials] 체크 → 4번의 두 값 붙여 넣기 →
   왼쪽 아래 칸에 `https://www.googleapis.com/auth/youtube.upload` 를 적고 [Authorize APIs] → 유튜브 채널 계정으로 로그인·허용 → [Exchange authorization code for tokens].
   **그러면**: «Refresh token» 칸에 값이 생깁니다 — 이것이 열쇠 셋째입니다.
6. **어디서**: GitHub 홈페이지 · linkpilot-cron 저장소 → [Settings] → 왼쪽 [Secrets and variables] → [Actions] → [New repository secret] — 세 이름으로 각각 넣습니다.
   ★ [Codespaces]·[Dependabot] 칸이 아니라 **[Actions]** 칸입니다(§4.6 — 다른 칸에 넣으면 아무 오류 없이 빈 값이 됩니다).

★ 유튜브 정책: 검수 안 받은 API 프로젝트로 올린 영상은 **비공개로 잠깁니다.** 올린 뒤 유튜브 스튜디오에서 공개로 바꾸시거나, 나중에 API 검수를 신청합니다. 프로그램은 잠긴 사실을 기록에 그대로 적습니다.

## 2. 인스타그램 (열쇠 둘)

넣을 이름: `INSTAGRAM_USER_ID` · `INSTAGRAM_ACCESS_TOKEN`

1. **어디서**: 폰의 인스타그램 앱 · **무엇을**: [프로필] → [≡] → [계정 유형 및 도구] → [프로페셔널 계정으로 전환](비즈니스 또는 크리에이터).
   **그러면**: 프로필에 «프로페셔널 대시보드»가 생깁니다. ★ 개인 계정은 API 로 못 올립니다.
2. **어디서**: 맥 웹브라우저 · developers.facebook.com · **어떻게**: [내 앱] → [앱 만들기] → 용도 «기타» → 유형 [비즈니스] → 이름 «linkpilot-shorts».
3. **어디서**: 만든 앱 화면 · **어떻게**: [제품 추가] → «Instagram» [설정] → [Instagram 로그인을 통한 API 설정] → [계정 추가]로 1번 계정을 잇고 [토큰 생성].
   권한에 `instagram_business_basic` · `instagram_business_content_publish` 가 있어야 합니다.
   **그러면**: «IGAA…» 로 시작하는 접속 열쇠와 «Instagram 사용자 ID» 숫자가 보입니다. ★ 숫자를 못 찾으시면 `me` 두 글자를 넣으셔도 됩니다.
4. GitHub 에 1번 6단계와 같은 자리로 두 이름을 넣습니다.

★ 이 열쇠는 **60일**마다 만료됩니다 — 만료되면 «쇼츠 올리기»가 판정 4(열쇠 거부·만료)로 멈추고 그렇게 적습니다. 3번에서 다시 만들어 넣으시면 됩니다.

## 3. 올리기

- **한 편만 올릴 때**: GitHub → [Actions] → «쇼츠 올리기» → [Run workflow] → 번호 · 올릴 곳 · 유튜브 공개 범위 · 확인 칸에 «게시» → [Run workflow].
  **그러면**: 끝난 뒤 `data/_shorts/out/<번호>/_publish.md` 에 올린 주소가 적힙니다. 같은 편은 두 번 안 올라갑니다.
- **만들고 바로 올릴 때**: «쇼츠 만들기» → [Run workflow] → «publish» 칸에 `youtube,instagram` → 만든 뒤 저절로 이어 올립니다.
- ★ 열쇠가 안 들어온 곳은 판정 2(열쇠 없음)로 건너뛰고, 들어온 곳만 올립니다.
