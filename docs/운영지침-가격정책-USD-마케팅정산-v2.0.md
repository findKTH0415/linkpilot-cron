1. 기본 업무 기능은 요금제에 포함하고, AI는 제공 크레딧 안에서 사용한다.

3. 수동 등록·수정·기존 결과 열람에는 AI 크레딧을 차감하지 않는다.
4. 비용이 큰 AI 분석·이미지·영상은 실행 전 범위·비용을 안내한다.
5. 본부 → 국가별 총판 → 서브에이전트(마케터)의 조직과 정산을 연결한다.
6. 총판·마케터의 수익은 실제 정상 구독 결제에 귀속시킨다. 회원 가입이나 하위 마케터 모집 자체에 수당을 지급하지 않는다.
7. 본부·총판·마케터의 외부 지급 계좌와 내부 정산 원장을 구분한다.
8. 고객 수금과 파트너 지급은 검증된 결제·지급 사업자를 통해 처리한다. 문서만으로 은행 계좌가 생성되거나 자금이 이동하지 않는다.
9. 고객 결제 통화가 USD여도 국가별 세금·카드사 환전·수령 계좌의 현지통화 전환은 별도로 안내한다.

### 2.2 원화 1,000원 소개비 요청의 USD 반영

- 기획용 환산값 1 USD = 1,500 KRW를 가정하면 1,000원은 약 $0.6667이다.
- 본 USD 정책의 소개비 총액은 정상 기본 구독 1건당 $0.67로 제안한다.
- 1,500원은 실제 조회 환율이 아니다. 원화 요청을 USD 정책으로 구체화한 설계 가정이다.
- 고객 가격 $3.99·$10.99에는 소개비 재원을 반영했다. 결제 화면에서 소개비를 다시 별도 청구하지 않는다.
- 소개비·구독료는 고정 USD 값이다. 매달 원화 1,000원을 다시 환산하여 소개비를 바꾸지 않는다.
- 추가 좌석·충전·영상에는 이 소개비를 추가하지 않고 초기 가격을 유지한다.
- 직접 유입과 추천 유입 고객의 표시가격은 동일하다. 추천 귀속이 없는 주문에는 소개비가 발생하지 않는다.

## 4. AI 크레딧·실행·반환

### 4.1 지급과 소유

| 종류 | 규칙 |
|---|---|
| 가입 체험 | 검증된 신규 계정 1회 100. 자동 월 재지급 없음 |
| 월 포함 | 결제 성공 주기마다 Pro 500·Business 2,000·유료 추가 좌석당 500 |
| 추가 구매 | $3.29에 1,000. 구독과 별도 구매 원장 |
| 보상 | 사유·발급자·수량·조건 기록 |
| Business 잔액 | 팀 소유. 개인 잔액과 자동 합산·이전하지 않음 |

- 월 포함량은 다음 주기로 이월하지 않는다.
- 체험·구매분의 초기 설정은 자동 소멸 없음이다. 향후 유효기간을 도입할 때는 판매조건과 기존 구매분 보호를 함께 검토한다.
- 구독 해지 때문에 구매 잔액을 자동 소멸시키지 않는다.
- 월 포함분을 먼저 쓰고, 유효기간이 있는 보상·체험분, 그 외 체험·보상분, 선구매한 구매분 순으로 사용한다.
- 충전 잔액과 소개비 USD 잔액은 전혀 다른 원장이다. 서로 자동 교환·현금화하지 않는다.
- 자동 충전 기본 OFF, 월 추가 지출 한도 제공, 사용량 80%와 소진 시 알림.
- 잔액 소진 후에도 저장 결과 열람과 허용된 수동 기능은 유지한다.

### 4.2 시범 차감표

| 작업 | 시작 크레딧 | 확정 견적에 포함할 범위 |
|---|---:|---|
| 짧은 글·요약·인사말 | 1 | 최대 입력·출력 길이 |
| 명함 OCR | 2 / 장 | 앞·뒷면·복수 명함 규칙 |
| 통화분석 | 5 / 분 | 전체 녹음 시간·요약·할일 |
| 기본 투자자 추천 | 100 / 건 | 자료량·질문 묶음·기존 DB 범위·후보 수 |
| 기본 보고서 | 100 / 건 | 템플릿·자료량·결과 길이 |
| 심층 조사·긴 보고서 | 별도 견적 | 외부 검색 상한·자료량·결과 범위 |
| 이미지 | 모델별 견적 | 모델·해상도·장수 |
| 영상 | 별도 USD 상품 | 모델·길이·해상도·생성 수 |

- 이 표는 시범 시작 단가이다. 원가를 확인한 작업 범위만 판매한다.
- “부터” 가격만 보여주고 곧바로 실행하지 않는다. 실행 전에 확정 또는 최대 차감량을 보여준다.
- 기본 투자자 추천은 프로젝트 가져오기·입력 → 분석 → 필요한 추가 질문 → 사용자 확인 → 후보 추천을 한 번의 분석으로 묶는다.
- 추가 질문마다 별도 과금하지 않는다. 사용자가 범위를 크게 바꾼 재분석은 새 견적을 안내한다.
- 통화는 전체 과금 대상 시간을 합산한 뒤 분 단위 올림한다. 내부 조각마다 중복 올림하지 않는다.
- 단순 템플릿 편집·결과 재열람에는 재차감하지 않는다.

### 4.3 처리 순서

권한 확인 → 견적·사용자 확인 → 최대량 예약 → 작업 실행 → 결과 제공 가능 확인 → 확정 차감·차액 해제.

- 더블 클릭·재전송·중복 결제 이벤트는 한 번만 처리한다.
- 동시 작업의 잔액 중복 예약·음수 잔액을 방지한다.
- 실패로 결과를 제공하지 못하면 예약 해제 또는 차감 반환.
- 내부 자동 재시도 비용은 내부 원가로 기록하며 추가 고객 차감 없음.
- 부분 결과 정산은 실행 전에 공시한 규칙으로만 처리한다.
- 월 갱신 중인 예약은 원래 지급 묶음에 정산한다. 만료한 포함분을 새 구매 잔액으로 되살리지 않는다.
- 고객이 승인한 최대 견적을 초과해야 하면 새 동의 없이 계속하지 않는다.

## 5. 본부·국가별 총판·서브에이전트 구조

| 구분 | 역할 | 등록·승인 주체 | 기본 감독 범위 |
|---|---|---|---|
| 본부 | 판매 계약·수금·정책·전체 정산·서비스 운영 | 본부 관리자 | 전체 국가·조직·계정 |

| 서브에이전트(마케터) | 자신의 추천 링크·코드로 고객 유입 | 등록 신청 후 승인 | 본인 유입·본인 소개비 |

- 조직의 상하 관계는 사업 역할이다. 하위 인원을 모집했다는 이유로 자동 보상이 생기지 않는다.
- 소개비는 고객의 실매출과 귀속 주문에만 연결한다.
- 국가별 총판 지정이 그 국가 전체 매출에 대한 자동 수익권을 뜻하지 않는다.
- 총판 독점·영업 지역·계약기간·책임은 별도 계약과 유효기간으로 관리한다.
- 국가 총판 1개를 초기 기본값으로 하되 복수 총판이 필요하면 지역·상품·채널 범위를 겹치지 않게 설정한다.
- 마케터의 소속 총판·적용 국가는 추천 고객의 주문에 스냅샷으로 고정한다.
- 거주 국가·고객 청구 국가·영업 담당 국가·총판 배정 국가는 별도 필드이다.
- 소속을 바꾸어도 과거 발생 소개비를 새 총판에게 재배분하지 않는다. 향후 갱신의 변경 시점은 계약·귀속 버전으로 결정한다.

## 6. 계좌 체계와 자금 흐름

### 6.1 계좌 유형

| 계좌·원장 | 소유·주체 | 목적 | 화면 표시 |
|---|---|---|---|
| 본부 USD 수금 계좌·가맹점 계정 | 실제 판매 본부 법인 | 고객 결제 수취·정산 | 결제사 잔액·입금·수수료·정산 예정 |
| 본부 USD 운영·지급 은행계좌 | 본부 법인 | 운영비·파트너 지급 재원 | 잔액·확인 시각·입출금·미지급액 |
| 국가 총판 외부 수령 계좌 | 승인된 총판 개인·법인 | 확정 총판 소개비 수령 | 검증 상태·마스킹 계좌·지급 내역 |
| 마케터 외부 수령 계좌 | 승인된 마케터 개인·법인 | 확정 마케터 소개비 수령 | 검증 상태·마스킹 계좌·지급 내역 |
| 총판·마케터 내부 정산 원장 | LinkPilot의 채무·정산 기록 | 발생·보류·확정·지급 관리 | 예정·확정·지급중·완료·반환 잔액 |

내부 원장 생성은 실제 은행 계좌 개설이 아니다. 은행·지급사업자의 계좌·수령자 등록을 별도 완료해야 실제 USD 지급이 가능하다.

### 6.2 기본 자금 흐름

1. 고객이 USD로 결제한다.
2. 결제사에서 본부 판매자 계정으로 수금·정산한다.
3. 결제·귀속 이벤트를 근거로 총판·마케터의 소개비를 내부 원장에 기록한다.
4. 보류기간·환불·계좌 검증을 확인하여 지급 가능액을 확정한다.
5. 본부가 총판과 마케터 각각의 외부 수령 계좌로 직접 지급한다.
6. 지급 결과와 은행·결제사 내역을 대사한다.

- 초기 기본안은 본부가 두 수령자에게 직접 지급한다. 총판이 마케터 자금을 중간 보관·재송금하는 구조로 시작하지 않는다.
- 국가별 별도 판매 법인이 필요한 경우 실제 판매자·수금·세금·정산 계약을 먼저 정의하고 별도 흐름으로 구현한다.
- 고객 수금액 전체를 총판·마케터의 예치금처럼 표시하지 않는다.
- 운영계좌 잔액, 결제사 미정산 잔액, 소개비 미지급 부채를 중복 합산하지 않는다.
- 실시간 계좌 연동이 없으면 수동 확인 잔액과 확인 시각을 표시한다. 실시간으로 보이는 허위 잔액을 만들지 않는다.

## 7. 소개비 $0.67 배분

공제 전 정상 기본 구독 1건당 총 소개비 예산은 $0.67이다.

| 유입 형태 | 국가 총판 | 마케터 | 소개비 총액 |
|---|---:|---:|---:|
| 총판 소속 마케터의 유효 추천 | $0.20 | $0.47 | $0.67 |
| 본부 직속 독립 마케터의 유효 추천 | $0.00 | $0.67 | $0.67 |
| 국가 총판 자체 추천, 하위 마케터 없음 | $0.67 | $0.00 | $0.67 |
| 추천 귀속 없는 직접 가입·결제 | $0.00 | $0.00 | $0.00 |

- $0.20·$0.47 분배는 구체화를 위한 초기 제안값이다. 총판 계약별로 다르면 적용 버전을 분리하되 총액을 중복 지급하지 않는다.
- 총판 $0.67에 마케터 $0.67을 추가하는 방식은 기본안이 아니다.
- 본부에는 판매매출에서 소개비·결제·AI·운영비를 차감한 사업 손익이 남는다. 이를 확정 수익·보장 이익으로 표시하지 않는다.
- 총판과 마케터가 같은 수령자라면 동일 주문의 총액이 $0.67을 넘지 않게 수령자별로 합산한다.
- 최초 기본 구독과 정상 월 갱신에 반복 발생하는 기본안이다. 무료 가입·추가 좌석·충전·영상·세금에는 지급하지 않는다.
- Business는 기본 팀 결제 1건당 적용한다. 3명당 세 번 지급하지 않는다.
- 환불·차지백·무료 쿠폰·미수·중복 주문·자기 추천·허위 계정은 지급 대상에서 제외 또는 재검토한다.
- 할인·일할 결제는 적용 소개비가 가격을 초과하지 않게 별도 정책을 정한다. 검증되지 않은 할인 상품에 정상 월 $0.67을 자동 적용하지 않는다.

## 11. 추천 귀속과 중복 방지

1. 승인된 마케터에 고유 추천코드·링크·캠페인 코드를 발급한다.
2. 링크 유입은 초기 30일 귀속 기간을 제안값으로 적용한다. 필요한 동의·추적 조건을 지킨다.
3. 유효한 최초 링크를 후보로 저장하고, 고객이 가입 화면에서 명시적으로 입력·확인한 유효 코드가 있으면 그 값을 우선한다.
4. 가입 완료 시 회원 추천 관계를 고정하고 최초 유료 결제 시 주문 귀속 스냅샷을 만든다.
5. 결제에 마케터·총판·영업 국가·분배 버전·상품 버전을 저장한다.
6. 코드 누락을 이유로 뒤늦게 관리자가 임의 수익을 배정하지 않는다. 증빙·사유·승인 이력을 남긴 예외 처리만 허용한다.
