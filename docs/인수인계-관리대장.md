# 인수인계 관리대장

> 근거: 「LinkPilot 총체적 업무 인수인계 완료검증 지침 v1.0」 §6
> 판정 근거는 [`인수인계-완료검증-2026-08-26.md`](인수인계-완료검증-2026-08-26.md) 에 있다.
> 이 파일은 **미완료 항목을 추적하는 장부**다 — 보고서는 그때의 사진이고, 이쪽은 살아 움직인다.

★★★ **지침 §6 의 한 줄이 이 파일의 존재 이유다** —
**「인계자 또는 인수자가 지정되지 않은 항목은 완료로 판정하지 않는다」**.

그래서 **이름을 지어내지 않는다.** 모르는 칸은 `미지정` 으로 둔다 (CLAUDE.md §9 —
추측으로 메우고 넘어가지 않는다). `npm run handover:check` 가 몇 칸이 비었는지 센다.

★★ **필수 게이트 13번은 이 표가 채워져야 열린다.** 다른 것을 다 고쳐도
담당자·목표일이 비어 있으면 전체 판정은 `INCOMPLETE` 다.

★ 목표일은 `YYYY-MM-DD` 로 적는다. 「곧」·「이번 주」는 목표일이 아니다 —
지나갔는지를 잴 수 없다.

## 표 읽는 법

| 칸 | 뜻 |
|---|---|
| 중요도 | `CRITICAL` / `HIGH` / `MEDIUM` / `LOW` (지침 §5) |
| 상태 | `NOT_STARTED` / `UNVERIFIED` / `PARTIAL` / `READY_FOR_TEST` / `TEST_FAILED` / `BLOCKED` / `VERIFIED` / `ACCEPTED` |
| 완료조건 | **무엇이 참이면 끝인가.** 「했다」가 아니라 잴 수 있는 문장으로 적는다 |

## 채우는 법

**한 줄에 사람 하나씩** 정하시면 됩니다. 두 칸만 채우면 그 줄은 살아납니다 —

- **인계자** : 지금 그것을 아는 사람
- **인수자** : 앞으로 그것을 맡을 사람
- **목표일** : `2026-09-15` 같은 날짜

`npm run handover:check` 가 남은 칸을 셉니다. 전부 채워지면 필수 게이트 13번이 열립니다.

## 지난 판

이 표의 첫 판은 2026-08-26 감사에서 나왔다. 항목을 지우지 않는다 —
끝난 것은 상태를 `ACCEPTED` 로 바꾸고 **증빙과 날짜를 남긴다** (CLAUDE.md §9 와 같은 규칙).
지우면 반년 뒤에 같은 것을 다시 발견한다.
