## 7. 레이아웃

- 줄바꿈은 flex-wrap과 flex-basis로 처리합니다. 미디어쿼리는 쓰지 않습니다. 좁아지면 기본 크기를 못 채운 칸부터 아래로 내려갑니다.
- 모바일 미리보기는 같은 화면을 `max-width:390px`에 넣고 `8px solid #0A1419` · 반경 `36px` 틀을 씌웁니다.

| 패턴 | 값 | 쓰임 |
|---|---|---|
| 본문 + 옆 요약 | `flex:999 1 440px` + `flex:1 1 260px` | 사업궁합, 참여 대기 |
| 넓은 + 좁은 | `flex:3 1 460px` + `flex:2 1 300px` | 명식표 + 십이지, 오행 + 용어 |
| 같은 폭 두 칸 | `flex:1 1 340px` ×2 · `1 1 320px` ×2 | 내 정보, 명함 |
| 카드 격자 | `repeat(auto-fit,minmax(250 / 260 / 280px,1fr))` | 첫 화면 카드, 사업 기질, 사업별 해석 |

## 9. SVG 도식 규격

모든 도식은 viewBox 단위입니다. 글자 크기와 선 굵기도 viewBox 기준 값입니다.

### 9.1 두 명식 사이 합·충 연결선

| 항목 | 값 |
|---|---|
| viewBox | `0 0 100 100` · `preserveAspectRatio="none"` · 띠 높이 56px |
| 선 위치 | 기둥 i의 중심 x = `(i + .5) × 25` · y 0 → 100 |
| 합 | ink 실선 · 굵기 2 (강조 3.5) · `vector-effect:non-scaling-stroke` |
| 충 | `#D70015` · `stroke-dasharray:5 4` |
| 번호 위치 | 선의 `t = .5 / .28 / .72` 지점 (겹침 방지) |
| 강조 아닌 선 | `opacity .25` |

### 9.2 십이지 원판

| 항목 | 값 |
|---|---|
| viewBox | `-8 -8 116 116` · 최대 폭 240–300px |
| 지지 배치 | 子를 위(−90°)에 두고 시계 방향 30°씩 · 반지름 36 |
| 지지 노드 | `r 6.6` · 글자 serif 700 6.4 · 내 것 `stroke #0A1419 1.6` · 파트너 `#7FA800 1.6` · 그 외 `rgba(60,60,67,.18) .5`, 글자 `rgba(60,60,67,.4)` |
| 기준 원 | `r 36` · `rgba(60,60,67,.14)` · `.5` · 중심점 `r 2` |
| 계절 호 | 반지름 45 · 90°씩 · `stroke-width 2.4` · `opacity .5` · 겨울(亥子丑) 水 · 봄(寅卯辰) 木 · 여름(巳午未) 火 · 가을(申酉戌) 金 |
| 계절 글자 | 반지름 52 · 산세리프 700 4.6 · 오행 fg |
| 합·충 현 | 반지름 29 · 합 ink 실선 `.8` · 충 `#D70015` `2.4 1.8` 점선 · 강조 `1.5` |
| 번호 원 | `r 3.8` · `#FFFFFF` · `stroke .8` · 800 4 |

### 9.3 오행 상생·상극 오각형

| 항목 | 값 |

## 12. 인수인계 메모

- 로직의 `res.three` 중 “조율할 부분” 점 색이 이전 팔레트 값 `#D93A2E`로 남아 있습니다. 새 오행 화(火) 값 `#C23A2C`나 충 색 `#D70015` 중 하나로 맞추세요.
- 결과 화면의 `res.el`(나비형 오행 막대 데이터)은 오각형으로 바꾼 뒤 쓰지 않습니다. 지워도 됩니다.
- `<select>`는 선택지를 `sc-for`로 그려서, 처음 그릴 때 값이 반영되지 않는 문제가 있었습니다. 그래서 `data-v` 속성과 `syncSel()`로 값을 맞춥니다. 실제 구현에서는 표준 controlled select로 바꾸세요.
- 명식 · 십성 · 합충 · 해석 문장은 모두 화면 설명용 예시입니다. 실제 계산 엔진의 결과로 바꿔야 합니다.
