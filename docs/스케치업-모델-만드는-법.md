# 스케치업 모델 만드는 법 — 맥북에서

> **누가**: 사장님이 직접 (D-95, 2026-08-24 결정).
> **어디서**: 맥북 — **SketchUp 을 설치할 필요가 없다.** 2026-08-24 실측으로
> SketchUp 이 **클라우드에서 돈다**는 것을 확인했다: GitHub 에서 띄운 Claude
> 웹 세션에서 `build_model` 이 성공했고, 저장하면 `.skp` 가 **다운로드
> 주소**로 온다. 맥북에 필요한 것은 Claude 뿐이다.
> **무엇을 위해**: 엔진이 만든 계획(`model-plan.json`)대로 3D 모델을 만들고,
> 결과(`.skp`·그림·`model-result.json`)를 프로젝트 폴더에 돌려놓기 위해서다.
> 자동 실행(크론)은 이 연결이 있는지 보장되지 않아, 이 부분만 사람 자리에서 한다.
>
> ⚠️ **이 절차서는 아직 처음부터 끝까지는 돌려 보지 못했다** (연결 확인과
> 최소 실행까지만 실측했다). 따라 하시다 막히는 곳이 나오면 그 자리를 알려
> 주시면 문서를 고친다 — 막힌 곳이 이 문서의 버그다.

---

## 준비물 — 하나뿐이다

**Trimble SketchUp 커넥터가 연결돼 있어야 한다.** 커넥터란 Claude 가 외부
서비스(여기서는 클라우드 SketchUp)를 부리게 해 주는 연결이다.

- 확인하는 곳: **claude.ai → 설정(Settings) → 커넥터(Connectors)** 에서
  Trimble SketchUp 이 「연결됨」인지 본다. 없으면 거기서 연결하고 로그인한다.
- **여기서 대개 막힌다.** 연결이 안 돼 있으면 Claude 는 「SketchUp 도구가
  없다」고만 하고 이유를 말해 주지 않는다. 도구가 없다고 하면 십중팔구 이거다.
- SketchUp 프로그램 설치·실행은 필요 없다. 화면에 SketchUp 창이 뜨지 않는
  것이 정상이다 — 확인은 그림(장면 PNG·저장 미리보기)으로 한다.

## 순서 — 일곱 단계

### ① 맥북에서 Claude 를 연다

둘 중 편한 쪽이면 된다:

- **브라우저**: claude.ai 에서 새 대화를 연다
- **터미널**: `claude` 를 쳐서 Claude Code 를 연다

### ② 계획 파일을 준비한다

엔진이 만든 `model-plan.json` 을 준다 — 파일을 올리거나, 내용을 붙여 넣거나,
저장소 경로를 알려 주면 된다.

- **처음 연습이라면**: 저장소의 `im-agent/samples/model-plan.sample.json` 을
  쓴다. 예시 데이터라고 파일 안에 적혀 있다.

### ③ 이렇게 시킨다

아래 문장을 그대로 붙여 넣는다.

> SketchUp 스킬 목록을 확인하고 baseline 스킬을 전부 읽은 다음,
> model-plan.json 을 읽고 그 계획대로 SketchUp 매스 모델을 만들어 줘.
> 새 작업이니 clean 하게 시작해 줘. 단위는 mm 다.
> 만들고 나면 지오메트리 정리와 검증을 하고, 카메라·스타일을 잡고
> 장면을 만든 뒤 저장해 줘.
> 규칙은 im-agent/prompts/sketchup-engineering-agent.md 를 따른다.

- 「baseline 스킬을 전부 읽는다」는 생략하면 안 된다. **읽지 않고 만들면
  깨진 코드가 나온다고 도구 설명이 직접 경고한다** — 우리 규칙이 아니라
  도구의 계약이다. 위 문장에 이미 들어 있으니 그대로 쓰면 된다.

### ④ 눈으로 확인한다

SketchUp 창이 없으므로 **그림으로 확인한다.** Claude 에게 장면 그림을
보여 달라고 하고, 이 둘을 본다:

- 매스가 **실제로 생겼는가** (빈 그림이면 뭔가 잘못됐다)
- 층수·비례가 계획과 **눈대중으로라도 맞는가**

### ⑤ 저장한다

「저장해 줘」라고 하면 `.skp` 파일의 **다운로드 주소와 미리보기 그림**이 온다.
주소를 눌러 파일을 받는다. 장면 그림(PNG)도 함께 받아 달라고 한다.

### ⑥ 결과 기록을 만들게 한다

> model-result.json 을 만들어 줘.
> 규격은 docs/스케치업-모델-계획-규격.md §3 이다.
> plan_created 에는 계획 파일의 created 값을 그대로 복사해 줘.

### ⑦ 파일을 프로젝트 폴더에 돌려놓는다

받은 것 전부 — `.skp` · PNG · `model-result.json` — 를 해당 프로젝트의
**`04_Property/`** 폴더에 넣는다. 새 폴더를 만들지 않는다.

이것으로 끝이다. 이후는 엔진 쪽(수령 Agent, 단계 4)이 결과를 계획과 대조한다.

## 막히면

| 증상 | 원인일 가능성이 큰 것 |
|---|---|
| 「SketchUp 도구가 없다」 | 커넥터 미연결 — 준비물로 돌아간다 |
| 사용 한도 안내(업그레이드 화면)가 뜬다 | 무료 구간 한도다. 한도·요금은 아직 실측 전이라(D-95 비고) 뜨면 그 화면을 알려 주시면 등록부에 적는다 |
| 크기가 이상하다 (너무 크거나 작다) | 단위 사고다. 계획은 mm 인데 다른 단위로 읽었다 — 「단위는 mm 다」를 다시 말해 준다 |
| 이전 작업 잔재가 섞인다 | 「clean 하게 새로 시작해 줘」라고 한다 (새 작업 첫 호출은 초기화가 규칙이다) |

문제가 반복되면 그 화면을 찍어 알려 주시면 된다 — 절차서를 고치는 것이
이 문서의 유지보수다.
