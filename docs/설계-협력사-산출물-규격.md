# 설계 협력사 산출물 규격

> **이 문서를 협력사에 그대로 보낸다.** 우리가 무엇을 받아야 파이프라인에
> 들어가는지 적은 것이고, 그대로 안 오면 값이 비거나 **틀린 값이 그럴듯하게
> 들어온다.**

**근거**: 등록부 **D-37**(형상에서 물량을 계산하지 않는다) · **D-38**(Rhino 서버를
세우지 않고 협력사 결과를 받는다), 2026-08-16 결정.

---

## 왜 이렇게 정했나

우리 쪽에 기하 엔진(IfcOpenShell)도, Rhino 라이선스 서버도 두지 않기로 했다.
**둘 다 협력사가 이미 가지고 있고 이미 하는 일**이기 때문이다.

대신 조건이 하나 붙는다 — **우리는 받은 것을 다시 재지 않는다.**
형상만 오면 물량은 「없음」으로 남고, 그 상태로 견적이 나가면 물량이 빠진
견적이 된다. 그래서 **수량이 파일 안에 들어 있어야 한다.**

| 우리가 하는 것 | 우리가 **안 하는 것** |
|---|---|
| 파일에 들어 있는 수량을 읽는다 | 형상에서 물량을 새로 계산한다 |
| 단가를 공공데이터로 대조한다 | 수량 × 단가로 견적을 자동 확정한다 |
| 빠진 것을 이름을 붙여 알린다 | 빠진 것을 0 으로 채운다 |

## 1. 물량 — IFC (`.ifc`)

### 반드시 켜야 하는 것: **Base Quantities (기본 수량)**

내보내기 대화상자에서 이 항목 하나를 켜는 것이 전부다. 도구별 위치:

| 도구 | 위치 |
|---|---|
| Revit | IFC 내보내기 › 「Property Sets」 탭 › **Export base quantities** |
| ArchiCAD | IFC 변환 설정 › 「Property Mapping」 › **Base Quantities** |
| Rhino / Grasshopper | IFC 내보내기 플러그인의 Quantity Sets 옵션 |

**이걸 안 켜면** 파일은 정상이고 형상도 다 들어 있는데 **수량만 없다.**
우리 쪽에서는 이렇게 나온다:

```
이 모델에는 수량(IfcElementQuantity)이 들어 있지 않다.
내보낼 때 「Base Quantities / 기본 수량」 옵션을 켜고 다시 내보내야 한다.
형상에서 물량을 새로 계산하지는 않는다
```

### 함께 맞춰 주면 좋은 것

- **스키마**: IFC4 또는 IFC2X3 (둘 다 읽는다)
- **단위**: 길이 `m`, 면적 `㎡`, 부피 `㎥` — 모델 단위를 mm 로 두면 수량도 mm 계열로
  들어와 **면적이 백만 배로 나온다.** 숫자가 커도 우리는 못 알아본다
- **부재 분류**: 벽·슬래브·기둥·보가 각자 제 타입(`IfcWall`·`IfcSlab` …)으로
  나가야 한다. 전부 `IfcBuildingElementProxy` 로 나가면 무엇의 물량인지 사라진다

## 2. 매스·조감도 — 이미지 + 수치

Rhino/Grasshopper 결과는 **파일 그대로 주지 않아도 된다.** 우리는 `.3dm` 을
읽지 않는다(그러려면 라이브러리를 들여야 하는데 안 들이기로 했다).

받는 것:

| 무엇 | 형식 | 왜 |
|---|---|---|
| 매스 이미지 | PNG 또는 SVG | IM 에 싣는다. SVG 면 JPEG 도 우리가 만든다 |
| 매스 수치 | 표(연면적·동별 면적·층수·높이) | 이미지에서 숫자를 읽어 내지 않는다 |
| 전제 조건 | 글로 | 용적률·이격·사선을 무엇으로 뒀는지 |

**전제 조건이 특히 중요하다.** 매스는 전제에 따라 연면적이 크게 갈리는데,
숫자만 오면 그 전제가 사라지고 **우리 문서에는 확정값처럼 실린다.**

> 이 산출물은 **생성물**이다. 우리 시스템에서 공부(公簿)에서 온 값과 **다른 칸**에
> 두고, 사람이 확인하고 채택하기 전에는 IM 본문 수치로 쓰지 않는다.

## 3. 보내기 전에 한 번 돌려 주십시오

받는 쪽에서 확인하는 것과 같은 검사를 협력사도 돌릴 수 있다:

```
npm run im:check-model -- <파일.ifc>
```

통과하면 그대로 보내면 되고, 막히면 **무엇을 켜서 다시 내보내면 되는지**
그 자리에서 알려 준다. 파일을 주고받으며 며칠 버리는 것보다 싸다.

---

## 4. 우리가 다시 묻게 되는 경우

아래는 규격대로 와도 사람이 정해야 하는 것들이다. 미리 알려 주면 왕복이 준다.

- 같은 부재가 여러 번 등록된 경우 (증설·리모델링 이력) → 어느 것이 현재인지
- 동이 여럿인데 수량이 합쳐져 온 경우 → 동별로 나눠 주실 수 있는지
- 지하·지상 구분이 필요한데 층 정보가 없는 경우
