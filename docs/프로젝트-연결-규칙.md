# 규칙 — 플랫폼 프로젝트를 가져와 자료를 붙인다

| | |
|---|---|
| **정한 날** | 2026-08-20 (KST) |
| **적용** | 앱 [보고서 생성] → [자료 붙이기] 탭 (`files.html`) |
| **왜 필요한가** | 프로젝트가 **두 곳에** 있다. 어느 쪽이 원본인지 정하지 않으면 자료가 엉뚱한 곳에 붙고, 붙인 사람은 붙였다고 믿는다 |

---

## 0. 지금 실제로 어떻게 도는가 (실측)

규칙을 정하기 전에, 지금 코드가 하는 일부터 적는다.

| | 실제 |
|---|---|
| 프로젝트 목록 | `GET /projects` → `store.listProjects()` — **엔진의 `im-projects/` 폴더를 읽는다.** 앱의 딜파이프라인이 아니다 |
| 프로젝트 번호 | **엔진이 만든다.** `LP-{DC\|SOL\|RE\|GEN}-{연도}-{일련 3자리}` (`store.nextProjectId`) |
| 만드는 입구 | `POST /projects` — 받는 것은 `request` · `assetType` · `issuer` 뿐 |
| **앱 프로젝트를 가리키는 자리** | `externalId` — `POST /projects` 가 받고 `01_Project/project.json` 에 남는다. `GET /projects` 가 함께 낸다 〈2026-08-20 추가〉 |
| 화면이 미리 받는 목록 | `window.LINKPILOT_FILES.preload.projects` — 앱이 넣을 수 있다 |
| 고른 프로젝트 알림 | 화면 → 앱 `lp-files-project` (iframe 이면 postMessage, 아니면 문서 이벤트) |

★ **그래서 지금은 두 목록이 따로 논다.** 앱에 「서창산업 / CB발행」이 있어도 엔진에는
없고, 엔진에 `LP-GEN-2026-001` 이 있어도 앱은 그것이 어느 딜인지 모른다.

---

## 1. 원본은 **앱**이다

**사람이 프로젝트를 만드는 곳은 딜파이프라인 하나뿐이다.**
엔진의 `LP-…` 는 프로젝트가 아니라 **그 프로젝트의 작업 폴더**다.

- 자료·산출물·장부가 쌓이는 곳이라 번호가 필요할 뿐이고, **딜을 대표하지 않는다.**
- 그래서 사용자에게 보이는 이름은 **앱의 이름**이다. 엔진 번호는 뒤에 붙는 꼬리표다.

★ 이 하나를 안 정하면 「프로젝트가 두 개」가 된다. 그 상태에서 자료를 붙이면
**어느 쪽에 붙었는지 아무도 모른다.**

---

## 2. 목록은 **앱이 준다**

자료 붙이기 화면의 프로젝트 칸은 **앱이 넣어 준 목록**을 그린다.

```js
window.LINKPILOT_FILES = {
  api: '/api/linkpilot', inTab: true, session: …,
  preload: { projects: [
    { id: 'LP-GEN-2026-001', name: '잠원동 역세권개발 주상복합 개발', externalId: 'deal-8842' },
    …
  ] },
};
```

- `id` — **엔진 작업 폴더 번호.** 자료가 실제로 붙는 곳
- `name` — **앱이 부르는 이름.** 화면에 이것을 보여 준다
- `externalId` — **앱의 딜 키** (§3)

★ 앱이 목록을 안 주면 엔진의 `GET /projects` 로 넘어간다. **그것은 대비책이지
기본이 아니다** — 그때 목록은 앱의 딜과 다를 수 있다.

---

## 3. 잇는 것은 **키다. 이름이 아니다**

앱의 딜과 엔진 폴더는 **키 하나로** 잇는다.

```
앱 딜 (deal-8842)  ←→  엔진 폴더 (LP-GEN-2026-001)
```

- 이 키를 엔진 프로젝트에 **남긴다** — `01_Project/project.json` 의 `externalId`
- **이름으로 잇지 않는다.** 앱에서 이름을 바꾸는 날 연결이 끊기고, 끊긴 것을
  아무도 모른다. 이름은 바뀌라고 있는 것이다
- 키는 **앱이 만든다.** 엔진은 받아 적기만 한다 — 양쪽이 만들면 어느 것이
  진짜인지 알 수 없게 된다

★ 이 자리는 **넣었다** 〈2026-08-20〉 — `POST /projects` 가 `externalId` 를 받고,
`01_Project/project.json` 에 남고, `GET /projects` 가 함께 낸다.
**키는 앱이 만든다.** 안 주면 `null` 이고, 그때는 앱 딜과 이어지지 않은 폴더다.

---

## 4. 엔진 폴더가 없으면 **자료를 붙이지 않는다**

앱의 딜에 대응하는 엔진 폴더가 없으면 붙일 곳이 없다.

- 화면은 **「보고서 생성 1단계에서 먼저 만드십시오」**로 보낸다
- **화면이 몰래 만들지 않는다.** 만들면 번호가 하나 소모되고, 자산군이 안 정해져
  `GEN` 으로 굳는다 — 나중에 바꾸려면 폴더를 다시 만들어야 한다
- **비어 있는 채로 두지 않는다.** 목록이 비면 사용자는 「고를 게 없네」로 읽고
  끝난다. 왜 없는지를 말한다

---

## 5. 자료가 붙는 자리

고른 프로젝트의 **엔진 폴더 안**이다. 갈래마다 남는 것이 다르다.

| 갈래 | 어디에 | 남는 것 |
|---|---|---|
| **외부 폴더 연결** | `02_Source_Data/.linked.json` (장부) | **파일은 안 남는다.** 어디 있는지·어느 판인지·지문·읽은 때 |
| **1회성 업로드** | 없음 | 읽고 **바로 버린다.** 지문과 읽은 때만 기록 |

★ 연결 자료의 **접근권은 장부에 안 들어간다.** 짧게 사는 자리(`core/handoff.js`)가
잠깐 들고 있다가 스스로 버린다 — 장부는 오래 남고, 오래 남는 곳에 열쇠를 두지 않는다.

★ 어느 갈래든 **프로젝트를 고르기 전에는 아무것도 못 붙인다.** 붙일 곳이 없기 때문이다.

---

## 6. 금지

| | 왜 |
|---|---|
| **이름으로 잇기** | 이름은 바뀐다. 바뀐 날 조용히 끊긴다 |
| 화면이 프로젝트 번호를 **만들기** | 번호는 엔진이 만든다 (일련번호가 겹친다) |
| 앱이 프로젝트 키를 **엔진 번호로 대체하기** | 딜은 앱 것이다. 엔진 번호는 폴더 이름일 뿐 |
| 앱이 자료를 **보관하기** | 보관은 엔진(`vault`)이 한다. 두 곳에 두면 어느 것이 원본인지 사라진다 |
| 프로젝트 없이 **올리기** | 붙을 곳이 없다. 「나중에 옮기지」는 옮기지 않는다 |
| 목록이 비었는데 **그냥 두기** | 이유를 말한다. 빈 목록은 「자료가 없다」로 읽힌다 |

---

## 7. 이 규칙을 성립시키려면 **넣어야 하는 것**

지금 코드에 없는 것만 적는다. 있는 것은 §0 에 있다.

| | 무엇 | 누가 | 상태 |
|:--:|---|---|---|
| ① | `POST /projects` 가 **`externalId` 를 받는다** | 엔진 | ✅ |
| ② | `01_Project/project.json` 에 **남긴다** | 엔진 | ✅ |
| ③ | `GET /projects` 가 **함께 낸다** | 엔진 | ✅ |
| ④ | 화면이 **작업 폴더 없는 딜**을 목록에 두고, 고르면 「먼저 만드십시오」 | 엔진 | ✅ |
| ⑤ | 앱이 `preload.projects` 로 **자기 목록(54건)을 넣는다** | **본체** | ☐ |
| ⑥ | 앱이 딜을 만들 때 `externalId` 로 **엔진 폴더를 만든다** | **본체** | ☐ |

### 앱이 넣는 목록의 모양

```js
preload: { projects: [
  // 작업 폴더가 있는 딜
  { id: 'LP-RE-2026-001', name: '잠원동 역세권개발 주상복합 개발', externalId: 'deal-8842' },
  // 아직 없는 딜 — id 를 비운다. 목록에서 빼지 않는다
  { id: null, name: '벌레퇴치 LED 전구', externalId: 'deal-8901' },
] }
```

★ **`id` 를 비운 딜을 목록에서 빼지 않는다.** 빼면 사용자는 자기 딜이 왜 없는지
모른 채 찾는다. 고르면 「보고서 생성 1단계에서 먼저 만드십시오」라고 말한다.

★ ⑤⑥ 이 없으면 목록은 **엔진 폴더**만 보여 준다 — 앱의 54건이 아니다.
지금 화면이 「— 고르세요 —」로만 뜨는 이유가 그것이다.
