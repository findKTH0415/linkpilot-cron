## 1. 실행 목표

당신은 LinkPilot의 `AI Project Manager Orchestrator`다. `Product Architecture`, `Billing & Subscription`, `Core Platform`, `Security & Privacy`, `Community`, `Work Management`, `Investment Intelligence`, `Energy Analysis`, `Report Generation`, `API Manager`, `Design Director`, `Validation & Release Manager`에게 업무를 배정하고 교차검증하라.

회원가입은 **무료로 시작**한다. 모든 회원에게 전체 메뉴, 기능 설명, 공개 가능한 목록·원천 출처, 예시 화면과 업그레이드 조건을 보여준다. 개인·조직의 비공개 데이터, 유료 API 결과, 다른 회원의 프로젝트 문서는 이 원칙만으로 공개하지 않는다. 실제 업무 실행은 등급과 사용량, 프로젝트 역할, 원본 데이터 권한을 서버에서 함께 검사한다.

회원 등급은 `무료 FREE → 프리미엄 PREMIUM → 비즈니스 BUSINESS`의 포함 관계다. 상위 등급은 하위 등급 기능을 포함한다. 비즈니스는 정상적인 이용에 **월별 횟수 차감 없이** 전체 기능을 사용한다. 보안·남용 방지 속도 제한, 단일 요청의 파일 크기·실행 시간·동시 작업 제한은 모든 등급에 적용하며, 별도 비용이 발생하는 외부 서비스는 사전에 공개한 범위와 한도 안에서만 호출한다. 이 운영 제한을 숨긴 채 `완전 무제한`이라고 광고하지 말라.

## 2. 메뉴와 정보 구조

| 구간 | 메뉴/섹션 | 기본 제공 |
|---|---|---|
| 무료 | 오늘의 브리핑, 오늘의 인사이트, 커뮤니티 | 모든 회원의 기본 이용 |
| 프리미엄 | 할일관리, 통화분석, 인맥관리, 일정관리, 프로젝트관리, 딜 파이프라인, **투자·정책지원 정보** | 무료 회원은 제한 체험, 프리미엄은 월간 한도, 비즈니스는 정상 이용 무제한 |
| 비즈니스 | 에너지 사업분석, 보고서 만들기 | 무료·프리미엄은 안내/안전한 샘플 체험, 비즈니스는 실제 작업 무제한 |

기존 `투자정보` 표시명을 **`투자·정책지원 정보`**로 변경한다. 사용자가 쓴 `투자자정보`는 이 섹션 안의 `투자자 정보` 카테고리로 두어 기존 투자·시장 정보와 구분한다. `정책자금` 카테고리를 새로 추가한다.

`투자·정책지원 정보`의 첫 화면은 `투자자 정보 / 시장·공시 / 정부 지원사업 / 정책자금` 탭으로 구성한다. `정책자금` 카드에는 시행기관, 공고명, 지원 대상·업종·지역, 자금 유형(융자·보증·이차보전 등), 신청기간, 주요 조건, 공식 공고 링크, 갱신 시각, 확인 상태를 표시한다. 금리·한도·예산·접수 상태는 공고의 기준일과 함께 표시하고, 조건 변경·마감 시 최신 원문으로 다시 확인하게 한다. `신청 가능`이나 `선정 확정`을 AI 추정만으로 판정하지 않는다.

정책자금 정보의 후보 원천은 기업마당의 공식 지원사업 API와 중소벤처기업진흥공단·소상공인시장진흥공단의 공식 공고다. API 권한, 갱신 주기, 재배포 조건을 확인한 뒤 연결한다. 공개 공고의 제목·요약·공식 링크는 모든 회원에게 보이며, 기업 프로필에 맞춘 매칭·알림·프로젝트 연결·비교표 생성은 등급별 실행 횟수를 적용한다.

내 정보에는 `현재 등급 / 사용량 / 다음 초기화일 / 다음 결제일 / 결제 내역 / 영수증 / 결제수단 관리 / 해지`를 한곳에 놓는다. 관리자센터에는 등급별 권한표, 사용량·비용, 국내·해외 결제 대사, 환불·분쟁, 예외·체험권, 정책자금 원천의 최신성 상태를 둔다.

## 3. 공개 화면과 실행 통제의 구분

1. 로그인 전에도 공개 섹션의 메뉴·제품 설명·요금 비교·예시 결과를 볼 수 있다. 로그인 후 무료 회원은 자신에게 허용된 데이터에 한해 제한 실행한다.
2. **메뉴는 감추지 않는다.** 잠긴 동작은 버튼 근처에 남은 횟수·제한 이유·상위 등급 혜택을 표시한다. 한도를 넘기기 전에 결과와 예상 소모량을 알려준다.
3. `콘텐츠 노출`은 공개 정보와 제품 소개의 노출을 뜻한다. 비공개 연락처, 통화, 일정, 프로젝트, 딜, 외부 클라우드의 비밀문서를 회원 등급만으로 열람할 수 없게 한다.
4. 개인 기능은 등급·사용량을 검사하고, 협업 기능은 **등급 + 프로젝트 역할 + 문서 원본 클라우드 권한**을 모두 확인한다. 무료 초대 참여자는 소유자가 허용한 범위의 읽기·댓글 참여가 가능하되 유료 생성·분석은 자기 등급에 따른다. 비즈니스 소유자의 구독을 다른 회원에게 자동 전파하지 않는다.
5. 공개 정책 공고의 원문 링크를 막지 않는다. LinkPilot이 제공하는 개인화 매칭·알림·저장·분석 횟수만 통제한다.

## 4. 등급별 초기 사용정책 제안

`월`은 무료 회원에게는 **매월 1일 00:00 KST**, 유료 회원에게는 **각 결제 주기 시작 시각**을 뜻한다. 저장 가능한 `최대 활성 건수`와 그달 `신규 실행 횟수`를 혼동하지 말라. 수치는 출시 전 사용자 승인 대상이며 정책 버전과 시행일을 저장한다.

- 무료의 프리미엄 기능은 실제 업무 일부를 체험할 수 있게 한다. 통화분석은 녹음 제공 동의·보존·삭제 정책이 준비되지 않았으면 사전 준비된 샘플로 대체하고 `샘플`을 선명하게 표시한다. 프리미엄의 비즈니스 체험은 실제 고비용 분석·완성 보고서 생성이나 유료 API를 호출하지 않는다.
- 무료 구간의 읽기에는 과금성 횟수 제한을 두지 않는다. 커뮤니티 게시·초대·메시지에는 모든 등급에 공통인 스팸·남용 방지 제한을 둔다.
- 프리미엄의 한도에 도달하면 기존 결과와 본인 데이터는 읽을 수 있고 새 생성만 막는다. 월간 카운터가 초기화되면 다시 실행할 수 있다. 비즈니스로 즉시 상향한 경우 서버 확인 후 한도를 해제한다.
- 비즈니스의 `무제한`은 선의의 정상 사용에 대한 상품 약속이다. 외부 API가 분당·일일 제한을 갖거나 유료 단가가 발생한다면 호출 지연·대기열·승인된 예산 안의 대체 경로를 공개한다. 추가 과금을 사용자 동의 없이 발생시키거나 조용히 임의의 월간 한도로 전환하지 않는다.
- 초과 실행은 자동 결제하지 않는다. 필요한 경우 별도 추가권 상품을 가격·횟수·기간·환불 조건까지 승인받아 도입한다.

## 5. 국내·해외 결제 경로

### 5.1 권장 결제 라우팅

| 구매자와 결제수단 | 1차 경로 | 구독 처리 | 주의사항 |
|---|---|---|---|
| 국내 구매자·국내 발급 카드/지원 계좌 | **토스페이먼츠 자동결제(빌링)** | LinkPilot이 월/연 주기, 청구, 실패 재시도, 해지 후 미청구를 관리 | 자동결제 리스크 검토·추가 계약 및 전용 MID 필요. 카드번호를 LinkPilot에 저장하지 않음 |
| 해외 구매자·PayPal 이용 가능 | **PayPal Subscriptions** 별도 연동 | PayPal 구독 상태·결제 이벤트를 확인하고 LinkPilot 사용권과 동기화 | 한국 사업자 계정의 판매·정산 자격, 대상국가, 실제 구독 결제·환불 시험 후 출시 |
| 해외 구매자·PayPal 구독 불가/해외 카드만 사용 | 별도 해외 카드 정기결제 계약을 검토할 때까지 `UNAVAILABLE` | 검증 전 자동구독을 표시하지 않음 | 토스의 일반 해외 카드 **1회 결제**와 토스 빌링은 서로 다른 기능. 수동 갱신 상품은 별도 승인 후 제공 |

결제 경로는 로그인 언어·IP만으로 결정하지 않는다. 실제 결제 국가·발급 카드/계정·청구통화와 사용 가능한 상품을 확인하고 구매자가 적합한 경로를 선택하게 한다. 한국 구매자의 국내 거래를 PayPal로 보내지 않는다. 해외 회원에게 토스 빌링을 제공하지 않는다.

토스페이먼츠는 국내 정기결제의 빌링키 발급·승인을 제공하지만 구독 주기 예약과 상태 관리 자체는 상점이 구현해야 하고 추가 계약이 필요하다. 현재 토스 자동결제 결제창 문서는 국내 발급 카드만 지원하며 해외 카드·해외 결제를 지원하지 않는다고 명시한다. 별도의 토스 **일반 해외결제**는 해외 카드 또는 PayPal 1회 결제와 다통화 계약을 다루므로, 이를 자동구독 기능으로 간주하지 말라.

PayPal의 한국 비즈니스 페이지는 구독 결제를 소개하고 한국 계정의 해외 판매대금 수취는 가능하다고 안내한다. 한국 계정 간 국내 결제는 제한한다. PayPal의 해외 구독 실제 가용성, 계정 심사, 지원 국가·통화, 수수료·환전·정산·세금 처리, LinkPilot 업종 취급은 계약 전 `UNVERIFIED`다.

Stripe는 현재 공식 결제 서비스 지원 국가 목록에 한국이 없어 **한국 법인만으로 바로 계약하는 기본 경로로 설정하지 않는다**. 해외 현지 법인을 실제로 보유할 경우 별도 재검토한다. Paddle은 국가 목록상 한국 공급자 자체를 배제하지 않지만, 투자기회·투자/금융 조언·커뮤니티 접근 중심 판매와 관련한 공식 금지 업종 항목이 있으므로 LinkPilot의 기본 해외 경로에서 제외한다. 이 판단은 해당 약관을 현재 사업 모델에 대조한 설계 판단이며 최종 계약 심사를 대신하지 않는다.

### 5.2 결제와 사용권의 연결

`회원가입(FREE) → 요금·갱신조건 확인 → PREMIUM/BUSINESS 선택 → 국내/해외 결제 경로 선택 → 제공자 결제 화면 → 서버의 거래 조회/서명 검증 → 주문·구독 활성 확인 → Entitlement 발급 → 기능 실행`

결제창 성공 리다이렉트, 브라우저 알림, 클라이언트의 플랜 값만으로 유료 권한을 주지 않는다. 결제 제공자의 서버 응답과 신뢰 가능한 웹훅을 대조하고 `order_id + provider + provider_transaction_id`를 멱등 처리한다. 실패·취소·환불·차지백·구독 만료 시 권한 상태를 정해진 규칙으로 갱신한다. 웹훅 지연·중복·역순 도착에는 정기 대사 작업으로 복구한다.

카드·계좌 원문, CVC는 LinkPilot에 저장하지 않는다. 토스 빌링키·PayPal 구독 ID·API 비밀키 등은 권한을 나누어 암호화 보관하고 로그에 노출하지 않는다. 결제 제공자 간 고객 ID는 내부 `user_id`와 일대일 매핑한다. 동일 주문이 두 경로에서 이중 청구되지 않게 한다.

## 6. 회원가입·갱신·변경 사용자 흐름

1. **무료 가입:** 이메일/소셜 인증 → 약관·개인정보 선택 동의 → 무료 계정 생성. 결제수단 입력을 강요하지 않는다. 전체 메뉴를 보여주고 체험 조건·남은 횟수를 표기한다.
2. **유료 전환:** 혜택 비교 → 월/연 구독과 청구 통화·세금/환전 가능성·다음 결제일·해지 방법 공개 → 결제 제공자 화면 → 서버 검증 → 즉시 사용권 반영. 결제 전 동의 화면을 기록한다.
3. **업그레이드:** PREMIUM → BUSINESS는 가격차·적용시점·일할 계산 여부를 화면에서 먼저 확정하고 결제 확인 후 적용한다. 중복 결제 방지 및 원 구독 처리 방식을 정의한다.
4. **다운그레이드·해지:** 사용자가 직접 해지할 수 있게 하고 종료일과 다음 청구 중단을 표시한다. 이미 만든 할일·일정·프로젝트·외부 클라우드 참조를 삭제하지 않고 읽기/내보내기·협업 권한을 유지하되 새 유료 작업을 제한한다. 원본 클라우드 권한 철회는 프로젝트 정책에 따로 연결한다.
5. **결제 실패:** 짧은 유예 상태와 결제수단 변경 경로를 안내한다. 유예기간은 상품 정책 승인값으로 설정한다. 재시도/해지 시점과 미납 권한은 일관되게 처리한다.
6. **환불·분쟁:** 해당 거래와 구독 상태를 대사한 뒤 규칙에 따라 권한을 조정한다. 이미 생성된 회원 데이터는 임의 삭제하지 않는다. 가격·갱신·해지·환불 정책은 출시 전 법률·세무·제공자 계약 검토 대상으로 남긴다.

## 7. 권한·사용량 엔진의 실행 규칙

단일 서버 함수 `authorizeAction(user_id, organization_id, resource_id, action, policy_version)`를 모든 웹·모바일·API·Agent·백그라운드 작업에서 호출한다. 권한 판단은 다음 순서를 따른다.

`로그인 상태 → 구독/유예 상태 → 등급별 기능 허용 → 프로젝트/조직 역할 → 원본 자료 권한 → 남은 사용량 → 승인된 외부 API 예산 → 실행 예약 → 성공 후 사용량 확정`

- 사용량은 생성 **성공** 건으로 센다. 통화·보고서처럼 긴 작업은 시작 시 1건을 예약하고 성공 시 확정, 실패·사용자 취소는 반환한다. 통화는 실행 건수와 분량을 함께 검사한다.
- 동시 요청·재시도·중복 웹훅에 의한 우회를 막기 위해 원자적 카운터와 `request_id` 멱등키를 사용한다. 서버에서 성공한 결과의 재열람은 새 사용량으로 세지 않는다.
- 활성 프로젝트·딜·연락처의 한도는 현재 소유/참여 중인 객체를 구분해 센다. 아카이브로 한도를 반복 초기화하는 악용 규칙을 정하고 삭제를 강제하지 않는다.
- 사용자별, 조직별, 제공자별 수치와 `policy_version`, 기간 시작·종료, 단위, 환급 사유를 기록한다. 관리자 예외는 사유·기간·승인자·감사로그를 필수로 한다.
- 프리미엄 소유자가 만든 프로젝트에 무료 회원이 초대된 경우 읽기·댓글은 명시 권한 안에서 허용할 수 있지만, 통화분석·보고서 생성·외부 API 개인화 호출은 실행 회원의 등급을 따른다. 외부 클라우드 문서는 플랫폼에 파일 사본을 만들지 않는다.

최소 엔터티: `plan`, `plan_policy_version`, `subscription`, `billing_customer`, `payment_transaction`, `entitlement`, `usage_counter`, `usage_reservation`, `feature_trial`, `refund_case`, `provider_event_inbox`, `policy_fund_source`, `policy_fund_notice`. 카드번호와 원본 파일 본문은 저장 대상이 아니다.

## 8. 화면 및 문구

- 상단 요금표: `무료 / 프리미엄 / 비즈니스` 3열. 포함 기능, 월간 한도, 비즈니스 정상 이용 무제한 범위, 결제 주기와 부가세·환율 표시 기준을 한눈에 확인하게 한다. 실제 가격은 승인 전 `미정`이며 임의 금액을 넣지 않는다.
- 제한에 도달한 버튼: `이번 달 3/3회 사용 · 다음 초기화 10월 1일 · 프리미엄에서 계속 사용`처럼 현재 정책과 날짜를 계산해 보여준다. 실행 결과를 만든 뒤 뒤늦게 결제를 요구하지 않는다.
- 에너지 분석·보고서 체험: 배지 `샘플 데이터`, 결과 하단 `실제 사업 판단에 사용 불가`. 실제 사업 자료 제출과 결과물 저장은 비즈니스 가입 및 별도 데이터 권한 후 제공한다.
- `투자·정책지원 정보`의 정책자금 카드: `공식 출처`, `마지막 확인`, `접수 기간`, `신청기관으로 이동`, `내 사업과 비교(횟수 적용)`를 분리한다. 유료 배지로 공식 공고 원문 접근을 가리지 않는다.
- 모바일 S22·iOS·Safari·Chrome에서 결제 화면 복귀, 영수증, 구독 해지, 한도 소진, 리다이렉트 실패의 실제 경로를 시험한다.

## 9. 기존 플랫폼과의 충돌 정리

- 기존 마스터 문서의 `투자정보` 메뉴·4.4 Investment Intelligence Engine 대상 화면·8.1 분석 메뉴·11장 분석 단계·최초 실행 섹션 명칭을 `투자·정책지원 정보`로 바꾸고, `투자자 정보` 및 `정책자금`을 하위 카테고리에 추가한다. 내부 안정 ID/API 경로는 호환 별칭을 두고 변경이 필요한 경우 구경로 리다이렉트·검색 인덱스·이벤트를 전환한다.
- 이전 문서는 파일·이미지·결과물 저장소를 공통 기반으로 전제한다. 비밀 프로젝트 문서는 최근 커뮤니티 협업 지침 v1.2의 **회원 클라우드 원본 + LinkPilot 최소 참조**로 처리한다. 보고서 결과물도 사용자 클라우드에 직접 저장하는 기능이 검증될 때까지 실제 생성·플랫폼 임시 보관을 완료로 판정하지 않는다.
- `투자자 정보`는 연락처와 개인 식별 자료를 포함할 수 있으므로 회원 등급과 무관하게 동의·원본 권한·조회 감사를 적용한다. 정책자금 공고 정보와 같은 공개 자료로 취급하지 않는다.
- 이 실행지침은 기존 화면의 실제 적용 여부를 주장하지 않는다. 현재 저장소·DB·결제 계약·API·테스트 증빙을 읽기 전용으로 확인하고 `DOCUMENTED / PLANNED / DEVELOPING / FUNCTION_VERIFIED / INTEGRATION_VERIFIED / UNVERIFIED / BLOCKED` 상태를 기록한다.

## 10. 구현 단계와 시험 게이트

1. **현황 감사:** 회원가입·결제·사용량·내 정보·관리자센터·기존 투자정보 화면, 운영 DB와 테스트 기록을 읽기 전용으로 대조한다. 상품 가격·사업자 계약·정산 권한은 확인 전 `UNVERIFIED`.
2. **정책 확정:** 기능 식별자, 공개/체험/유료 구분, 제안 한도, 비즈니스 정상 이용 무제한 범위, 원가·용량·가격·환불·유예 규칙을 사용자 승인용 표로 만든다.
3. **Staging:** 플랜 정책 엔진, 사용량 카운터, 두 결제 제공자 어댑터, 구독 웹훅·대사·권한 반영, 정책자금 카테고리·공식 원천 연결을 개발한다. 테스트 키·샌드박스만 사용한다.
4. **독립 시험:** 국내·해외 신규 가입, 성공·실패·중복 결제, 웹훅 유실·역순, 업그레이드·다운그레이드, 취소·만료·환불·차지백, 한도 동시 초과·초기화, 프로젝트 초대·외부 문서 권한, 모바일·브라우저를 교차 시험한다.
5. **출시 판정:** 가격/약관·토스 계약·PayPal 사업자 적격성·정산·세무·보안·고객지원·환불 처리·비용 상한, 실제 결제 리허설의 증빙이 모두 확보되고 CRITICAL/HIGH 미해결 문제가 없을 때만 배포 승인 요청.

예상 결과 및 테스트 예:

| 사례 | 기대 결과 |
|---|---|
| 무료 회원이 할일 4번째 생성 요청 | 서버가 생성 전 차단, 기존 3건은 읽기 가능, 남은 횟수 0 표시 |
| 동일 통화분석 요청이 두 번 전송 | 성공 결과 하나, 사용량 1건 및 실제 분량만 차감 |
| 프리미엄 프로젝트 11번째 활성화 | 사용자가 아카이브/비즈니스 전환을 선택할 수 있고 자료 삭제 없음 |
| 비즈니스 정상 이용 중 31번째 딜 생성 | 월간 상품 횟수로 차단하지 않음. 보안·속도 제한은 별도 적용 |
| 국내 구매자가 PayPal 결제 시도 | 국내 토스 경로 안내, PayPal 국내 결제 경로 제공 안 함 |

| 무료 회원이 비즈니스 샘플 분석 요청 | 샘플 데이터와 남은 체험 횟수 표시, 실제 유료 API 호출·문서 생성 없음 |
| 공개 정책자금 공고 열람 | 원문 링크 모두에게 제공, 개인화 매칭 실행만 등급 한도 적용 |
| 다른 조직의 비밀 프로젝트 URL 입수 | 등급이 비즈니스라도 프로젝트/클라우드 권한 없으면 접근 거부 |

## 11. 사용자 결정과 승인 대상

1. `4장`의 무료·프리미엄 제안 횟수와 비즈니스 정상 이용 무제한 범위, 남용 방지 속도·파일 크기·작업 시간.
2. 프리미엄/비즈니스의 월·연 가격, 부가세 포함 여부, 결제 통화, 환불·유예·일할 계산·가격 변경 방식.
3. 국내 토스 자동결제 추가 계약과 해외 PayPal 비즈니스 계정·구독 적격성 확인. 계약 전 실제 결제·정산은 실행하지 않는다.
4. 정책자금 공식 API 신청, 기관별 자료 사용·표시 조건, 데이터 갱신 주기와 비용 상한.
5. 출시 범위·관리자 권한·재무/개인정보 검토, 테스트 결과와 배포 승인.
