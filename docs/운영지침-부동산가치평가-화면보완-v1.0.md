# LinkPilot 부동산 가치평가 분석·보완·연동 실행 프롬프트 v1.0

- 작성 기준: 2026-09-26
- 적용 화면: LinkPilot 데스크톱 통합본의 **비즈니스 → 부동산 가치평가** 화면
- 검토 범위: 사용자가 제공한 화면 이미지 5장과 기존 **「부동산평가_마스터_프롬프트_v1.0.md」 Rev.3**의 대조. 화면의 물건·거래·사업비·가격은 실제 원자료를 확인하지 못한 **화면상 예시값**이다.
- 적용 순서: 현행 법령·공식 원자료 → 기존 가치평가 마스터 지침 및 API 지침 → 이 화면 보완 프롬프트. 충돌하면 근거와 해결안을 기록한다.

---

## 바로 실행할 프롬프트

당신은 LinkPilot의 부동산 가치평가 제품책임자, 감정평가 방법론 검토자, 개발사업 금융모델 검토자, 데이터 품질 책임자, UX 설계자다. 첨부 화면과 기존 마스터 지침을 바탕으로 **현재 화면의 숫자를 실제 감정평가액으로 확정하지 말고**, 확인 가능한 자료로 재계산되는 가치평가 흐름과 UI를 설계·구현하라. 정식 감정평가사가 작성·서명하지 않은 출력물 명칭은 **「부동산 가치평가 검토보고서」**로 한다.

화면 수치는 **검산 예시**로만 사용한다. `12,480㎡ × 1,566만 원/㎡ = 1,954.368억 원`, `48,600㎡ ÷ 12,480㎡ ≈ 389.4%`, `0.4×2,010 + 0.4×1,940 + 0.2×1,870 = 1,954억 원`, `1,954억 원 × 60% = 1,172.4억 원`이다. 숫자가 산술적으로 맞아도 **실제 거래·인허가·분양가능 면적·금융 승인**은 입증되지 않는다. `48,600㎡`가 용적률 산정용 연면적인지 확인하기 전에는 `389.4%`를 법적 용적률로 단정하지 않는다. 약 1.08조 원과 7,900억 원의 단순 차액 2,900억 원을 현재 토지가치 또는 순이익이라고 부르지 않는다.

### 2. 물건 식별과 원자료의 증거 대장을 먼저 만들라

1. 하나의 평가에 `asset_id`, 전체 필지 PNU, 지번·도로명주소, 동·호, 권리범위, 평가 목적, 기준시점, 자료조회일을 고정한다. 1개 필지라도 누락되면 일괄 평가액 확정을 보류한다.
2. 등기사항증명서·신탁원부·토지대장·지적도·건축물대장·임대차/점유자료·계약서·정비계획 고시문을 교차 대조한다. 유치권 주장, 법정지상권 가능성, 선순위 권리, 가처분·소송·체납·분묘·오염·무단점유는 **해당/미해당을 문서로 확인**하고, 확인하지 못하면 `UNVERIFIED`로 남긴다. 법률 판단은 담당 변호사 검토 대상으로 보낸다.
3. 각 수치에 `값, 단위, 대상범위, 출처기관, 원문 URL 또는 승인된 외부문서 링크, 문서 버전/해시, 기준일, 조회일, 수집방식, 책임자, 상태(VERIFIED/PARTIAL/UNVERIFIED/CONFLICTED), 갱신 필요일`을 저장한다. API 실패를 거래 없음·위험 없음으로 해석하지 않는다.
4. 국토교통부 실거래 공개와 한국부동산원 R-ONE 통계는 목적·집계 기준이 다르므로 같은 분모로 합치지 않는다. 실거래 API의 부분 지번만으로 특정 물건을 확정하지 않는다. 해제·정정 여부를 다시 조회한다.
5. V-World 일반/위성/지적/건축물 레이어는 위치·형상·환경의 조사 보조자료로 쓰고, 필지별 규제의 최종 확인은 공식 공부와 고시문으로 한다. 지도 이미지가 비어 있으면 지도 확인 완료로 표시하지 않는다.
6. 비밀문서 원본은 LinkPilot 서버에 보관하지 않는다. 회원이 허가한 Dropbox·Google Drive·Box·네이버 등 외부 저장소의 **권한 범위가 제한된 문서 링크와 최소 메타데이터**를 참조한다. 공유·권한 회수·만료·접근 감사와 유출 방지를 설계한다. 자동 다운로드·본문 색인은 별도 동의와 보안 검토가 있을 때만 한다.

### 3. 평가 가능성 게이트를 UI와 계산에 적용하라

| 게이트 | 통과 조건 | 미통과 시 화면·기능 |
|---|---|---|
| G0 대상·권리 | 필지, 소유·지분, 평가 대상, 기준일 확정 | 가격 산출 대신 ‘대상 범위 확인 중’ |
| G1 비교자료 | 실거래 원문과 해제·시점·물건성 보정 확인, 공시지가 연도 구분 | 거래사례 시산값만 조건부 표시, 통계적 ‘신뢰구간’ 표현 금지 |
| G2 권리·인허가 | 등기/점유·유치권/소송·용도지역·정비계획·지자체 규제 대조 | 개발완료가치·PF 가능성·사업권 양도가 비교에 ‘조건부’ 표시 |
| G3 비용·분양·금융 | 분양가능 면적, 주택형별 가격·속도, 상세 사업비, 공정표, 자기자본·차입 약정 검증 | 수익환원/개발잔여가치와 대출 가능액 확정 금지 |
| G4 독립검증 | 산식 재현, 단위·기간·권리 일치, 방법 간 차이 해소, 검토자 승인 | 외부 공유용 최종 의견·IM 자동 반영 보류 |

게이트가 일부만 통과한 상태는 `잠정 시뮬레이션`, `확인 필요`, `산정 유보` 중 정확한 문구로 나타낸다. 결론의 출처·신뢰수준과 **확정에 필요한 다음 행동**을 한 화면에서 보여준다. 원자료의 등급과 추정치의 신뢰도를 혼동하지 않는다.

### 4. 가치의 종류와 평가방법을 분리하라

1. **현 상태 토지·건물 시장가치**, **사업권/지분 거래가**, **인허가 조건부 개발잔여가치**, **개발 완료 후 장래 매각가치**, **급매·경매·공매 회수 시나리오**, **담보 인정가액/대출 검토액**, **순지분가치**를 별도 카드와 별도 모델로 둔다. 서로 다른 금액의 차이를 무조건 ‘할인’ 또는 ‘상승 여력’으로 해석하지 않는다.
2. 대상에 맞는 주된 평가방법을 선정하고 다른 방식으로 합리성을 검토한다. 거래사례비교법에는 사례별 보정 전·후와 `시점/지역/면적/접근/이용상태/권리` 요인을 공개한다. 공시지가기준법에는 표준지 선정·시점수정·지역·개별요인과 개별공시지가의 참고 역할을 분리한다.
3. 원가법은 **현존 건물의 재조달원가, 감가, 실제 포함 시설**을 다루고, 아직 짓지 않은 건물의 공사비를 그대로 현재 부동산 가치에 더하지 않는다. 공사비는 KCSC 설계·시방 기준, 설계/견적/발주 내역, 시점별 공사비 지표와 분리해 검증한다. KCSC 기준 자체를 단가표로 오용하지 않는다.
4. 임대운영 수익방식은 실증 가능한 임대료·공실·운영비·CAPEX·환원율/할인율을 사용한다. 개발사업 수익방식은 분양 또는 임대의 월·분기별 현금흐름, 인허가·철거·착공·준공·분양·회수 시점을 사용한 개발잔여가치/DCF로 분리한다. 운영형 수익환원과 개발잔여가치를 같은 이름의 한 값으로 섞지 않는다.
5. 화면의 40:40:20은 **설정 예시**로만 둔다. 방법별 대상 권리와 기준시점이 다르면 가중평균 계산 자체를 막는다. 일치해도 고정 가중치 평균을 최종가로 자동 채택하지 않는다. 주된 방법의 선정 이유, 독립적인 방법의 교차검증, 차이가 난 이유, 시산가액 조정의 논거를 기록하고 담당 평가전문가에게 넘긴다. 이는 기존 마스터 지침 제10장의 ‘단순 평균 금지’와 일치해야 한다.
6. 사례 표본이 희소하거나 권리·인허가 차이가 크면 비교사례 반경/기간 확장을 제안하되, 검색 범위를 바꾼 이력과 보정 위험을 표시한다. 법원경매 낙찰률은 토지 실거래 가격의 대체가 아니며, 공매와도 섞지 않는다. 화면의 90%/85% 색상 기준은 투자 안전판정이 아닌 사용자 지정 탐색 경보로 취급한다.

### 5. 개발·건설·분양의 연결 모델을 만들라

- **면적 브리지:** 총 대지 → 법정/실질 건축 가능 대지 → 건폐율·용적률 산정면적 → 지하/지상 연면적 → 전용/공용 → 분양가능 면적 → 주택형별 세대수. `분양수입 = Σ(상품별 분양가능 면적 또는 세대수 × 검증 단가 × 시점별 계약·입금률)`로 검산하고, 표시 단위인 `3.3㎡당`과 `㎡당`을 혼합하지 않는다.
- **인허가 브리지:** 현 상태, 정비구역 제안, 지정, 사업시행, 관리처분, 착공, 준공을 별도 확률·기한으로 다룬다. 지정 전 계획을 기정사실로 반영하지 않는다. 건축규모는 지자체 조례, 정비계획, 높이·일조·주차·소방·교통·환경·기부채납·임대주택 조건을 확인한 범위에서만 산정한다.
- **원가 브리지:** 토지 취득/사업권 인수 → 철거·이주·보상 → 직접 공사비(구조·마감·MEP·조경) → 설계·감리·인허가 → 부담금·기반시설 → 분양/마케팅 → 세금·VAT → 금융비·수수료 → 예비비·물가상승 → 소송·지연 비용을 시점별로 추적한다. `총사업비 7,900억 원`의 포함·제외 항목을 표시해 이중계산을 막는다.
- **시장 브리지:** 한국부동산원 가격·지가·임대 동향, 국토부 실거래, 경쟁 공급·미분양·인구·소득, 비교 분양가와 실제 흡수율을 교차 확인한다. 분양률 95%를 일괄 확정하지 않고 월별 속도, 할인·중도금 혜택·미분양 재고를 모델링한다.
- **민감도:** 분양가 ±10%, 분양속도 지연, 공사비 +10~20%, 금리 상승, 인허가 12~24개월 지연, 용적률·기부채납 변경, 소송·유치권 해소비용을 각각·복합으로 분석한다. 수치는 실제 사업 특성에 맞춰 조정하며, 임의의 확률을 ‘공식 전망’이라 하지 않는다. 손익분기 분양가·원가·기간 및 최대 토지취득가를 역산한다.

### 6. 금융설계는 ‘가능액’이 아니라 조건별 자금조달 전략으로 연결하라

Equity 투입 비율·시점, 브릿지 대출 상환, 본 PF 전환조건, 시공사 책임준공/신용보강, 선임차·선매입자 계약, 분양대금 유입과 신탁·담보 순위를 **동일 현금흐름표**에서 관리한다. 금융기관 제안서·견적·약정이 없으면 금리·LTV·한도·책준을 `가정/미확인`으로 표시한다.

| 조달 대안 | 가치에 연결되는 조건 | 검증 지표 |
|---|---|---|
| 토지매입 후 개발 | 매입대금·선순위·취득세·추가 자기자본 | 총 자기자본, 최고 차입 잔액, 회수액 |
| 사업권 인수/JV | 인수 권리·부채·조합/주민 동의·지분 희석 | 자산가치와 별개인 사업권 가격·순지분 |
| 브릿지 → PF | 인허가·시공사·분양/임대 사전확약 충족 | 전환 실패 시 상환재원과 만기 갭 |
| 선임차/선매입 | 실제 계약의 구속력·해제권·가격 조건 | 수입 안정성, 가격/IRR 변화 |

시나리오별 `sources & uses`, 월별 최고 부족자금, 이자·수수료, 대출약정 재무비율, DSCR/IRR/NPV와 수익배분을 보여준다. 담보 인정가액과 실제 승인액, 차입자 순조달액을 구분한다. `LTV 60% 대출 가능`은 `예시 LTV 60%를 단순 적용한 약 1,172억 원(승인·선순위·비용 미반영)`으로 바꾸고, 은행 확인 전 투자/공유 화면에서 확정 문구를 금지한다.

### 7. LinkPilot 다른 기능과의 시너지를 구현하라

| 연결 기능 | 공유할 최소 데이터 | 사용자 가치와 통제 |
|---|---|---|
| 프로젝트 관리 | `asset_id`, 게이트, 인허가·권리·실사 과제, 담당자·기한 | 증빙 미확인 사항을 작업으로 자동 생성; 완료는 문서 검증 후에만 |
| 딜 파이프라인 | 거래 구조, 제시가, 사업권·토지·채무 구분, 조건부 최댓값 | 매도 제시가와 모델 기준가 차이 설명, 협상안 기록 |
| IM/보고서 만들기 | 승인된 가액 종류, 기준시점, 가정·시나리오, 원자료 인용 | 임시 수치의 자동 전파 금지; 정본 지침과 출처 목록·변경 이력 포함 |
| 투자·정책지원 정보 | 자금조달 옵션·지원제도 해당성 확인 작업 | 지원제도를 보조 시나리오로만 반영, 실제 선정·수령 전 확정 수입 금지 |
| 일정·할일·협업 | 인허가·법률·금융·시공 실사 마일스톤 | 권한별 검토 요청, 승인·반려 사유와 재평가 알림 |
| 회원별 외부 클라우드 링크 | 문서명·출처·소유자·만료·해시·접근 권한 | 원본 비밀문서 플랫폼 저장 최소화; 투자자에게는 승인된 요약만 공유 |

Business 회원 기능에 배치하되, 무료·Premium 노출 및 체험 횟수 정책과 서버측 권한 검사로 접근을 통제한다. 결제 상태를 추정하지 않는다. 구독 권한이 평가 결과의 사실성 등급을 바꾸지 않도록 한다.

### 8. 사용자가 한눈에 읽을 화면으로 재구성하라

첫 화면 순서는 **평가 대상과 기준일 → 신뢰 상태/미완료 게이트 → 현재 상태 참고가치·개발 조건부 가치·사업권 거래가·조달 시나리오의 별도 카드 → 가격 워터폴과 핵심 변수 → 비교사례·지도 → 권리·인허가·분양·원가·PF 위험 → 근거/계산 열기 → 담당자 조치**로 한다.

- 현재 화면의 `평가 단계 4/6`과 `1,954억 원`이 동시에 보일 때, 가격 위에 **‘잠정 시뮬레이션 · 실거래/권리/원가 미검증’** 배지를 붙인다. 필요한 게이트를 누르면 누락 증빙과 담당 업무가 열린다.
- 거래사례·수익·원가 막대는 **값의 대상(현 상태/준공 후), 기준시점, 원자료 등급, 방법별 산식**을 함께 표시한다. 미검증 방법은 회색 처리하고 대표값 산정에서 제외한다. 결론의 범위는 가정 기반 민감도 범위로 명시한다.
- 지도/위성/지적/건축물·현장 사진 탭에 갱신일·축척·출처·사용권을 표시한다. 레이어 간 필지 경계 차이가 있으면 경고한다.
- 거래사례 행을 누르면 원문, 계약일/공개일, 해제 확인, 면적, 권리·인허가 수준, 보정 전/후 계산이 열린다. 차트의 전체 거래건수와 실제 채택 사례를 별도 분모로 둔다.
- 경매는 실거래와 독립 탭으로 분리하고 법원경매/공매, 매각회차, 감정 기준일, 낙찰일, 권리 부담을 표시한다.
- `보고서 만들기로 보내기`는 G4 승인 후 기본 활성화한다. 그 전에는 내부 검토용 워터마크를 포함한 미리보기만 허용한다. PF 전문가 문의에는 승인된 요약과 질의항목만 보내고 원본 문서는 사용자가 직접 공유 범위를 정한다.

### 9. 산출물과 완료조건

다음 순서로 결과를 제출하라.

1. **화면 진단:** 현재 강점, 잘못 읽힐 수 있는 숫자, 빠진 검증, 우선순위(P0/P1/P2) 표.
2. **데이터 계약:** 필드 사전, 단위·기준시점·권리범위, API/외부문서 출처, 상태와 갱신 규칙, 권한 범위.
3. **계산 설계:** 방법별 식, 사례 보정, 분양가능 면적, 사업비, 현금흐름, PF·Equity와 산식의 역추적 경로. 산식이 불명확하면 결과를 숨긴다.
4. **사용자 미리보기:** 데스크톱과 모바일 상단 카드, 근거 열기, 시나리오 비교, 차단 게이트의 문구와 간단한 와이어프레임 설명. 기존 LinkPilot 디자인 톤을 유지한다.
5. **연동 명세:** 프로젝트·딜·IM·협업·외부 저장소로 전달하는 필드와 전송 금지 조건.
6. **검증 결과:** 실제 근거로 확인한 값과 `UNVERIFIED`를 분리한 대조표. 자료가 없으면 샘플 화면 수치의 사실 여부를 ‘검증 실패’가 아닌 ‘미확인’으로 기록한다.

완료 판정에는 다음 테스트를 모두 포함한다.

- 같은 평가의 필지·권리·기준일·면적이 모든 카드, 비교표, IM에 일치한다.
- `㎡↔3.3㎡`, `만원↔억 원↔조 원`, 명목/실질, 세전/세후, 자산/자기자본 현금흐름이 자동 검산된다.
- `1,954억 원`, `1.08조 원`, `7,900억 원`, `620억 원`, `LTV 60%`의 산출·포함범위가 증빙 부족 시 자동으로 ‘예시/UNVERIFIED’가 된다.
- 인허가 지정 전, 유치권·선순위 등 권리 미확인, 분양가능 면적 미확정, 사업비 항목 미확정, PF 약정 없음 중 어느 하나라도 중요한 경우 외부용 ‘확정 가치’ 버튼이 비활성화된다.
- 낙찰가율과 실거래가를 혼용하지 않고, API 오류·빈 결과·오래된 자료를 0건 또는 정상으로 표시하지 않는다.
- 비밀문서는 외부 저장소 권한이 사라지면 LinkPilot에서 열리지 않고 공유 기록에 권한 회수가 남는다.
- 평가법인/감정평가사 검토·서명 없이 ‘공식 감정평가서’나 ‘금융기관 승인 대출액’으로 표시하지 않는다.
