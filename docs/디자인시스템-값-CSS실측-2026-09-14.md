# LinkPilot 디자인 시스템 값 — CSS 실측

실제 구현 파일의 스타일 선언을 전수 집계해 정리한 값 문서다. 추정값이나 권장값이 아니라 **코드에 실제로 쓰인 선언과 그 출현 횟수**이며, 대비값은 WCAG 2.1 상대휘도 공식으로 직접 계산했다.

| 항목 | 내용 |
|---|---|
| 추출일 | 2026-09-14 |
| 대상 파일 | `LinkPilot 로고 리디자인.dc.html` (198,532자) · `아침 브리핑 재구성 v2.dc.html` (34,929자) · `할일 화면 재구성 v3.dc.html` (31,905자) |
| 추출 대상 | hex · rgba · font / font-size / font-weight / line-height / letter-spacing · border-radius · gap · padding · box-shadow · SVG stroke-width / linecap / viewBox |
| 구조 | 별도 `.css` 파일과 CSS 커스텀 속성(`--*`)은 존재하지 않는다. 스타일은 전부 인라인 선언이다. 공통 자원은 Google Fonts 링크 1개뿐이다. |

파일 성격이 다르므로 아래 표기를 쓴다 — **앱**: 브리핑·할일 화면(모바일 390px 실제 UI) / **문서**: 로고 리디자인 파일(A4급 시안·주석 텍스트 포함). 규격 기준은 앱 쪽이고, 문서 쪽 값은 참고다.

| 로고 심볼 패스 | `M50 10 L88 90 L50 68 L12 90 Z` | |

아이콘 선 색은 `currentColor`로 두고 라임 포인트만 `#B5E01F`를 지정한다. 선택 상태 색은 코드에서 주입한다 — 밝은 배경 `#5A7A00`, 어두운 배경 `#B5E01F`.

`stroke-width="2"` 47건과 `stroke-linecap="butt"` 40건은 전부 구 아이콘 세트다. 교체가 끝나면 0이 되어야 한다.

---

## 5. 그림자

| 값 | 출현 | 용도 |
|---|---:|---|
| `0 2px 8px rgba(0,0,0,.14)` | 2 | 앱 아이콘 목업 부양 |
| `0 1px 3px rgba(18,22,31,.06)` | 1 | 할일 v3 상단 바 |

앱 화면은 사실상 그림자를 쓰지 않는다. 층위는 배경색(`#F5F6F8` 바탕 / `#FFFFFF` 카드)과 1px 경계선으로만 만든다.

## 7. 후속 조치

1. `#E5342B` → `#D32A21` 교체 — 흰 글자 대비 4.32 → 5.09. 배지 8건.
2. `#5B8C00` 잔존 1건을 `#5A7A00`로 정리.
3. 본문에 쓰인 `rgba(18,22,31,.55)` 이하를 `.6` 이상으로 상향 (라벨·메타는 유지).
4. Noto Sans KR `600` 을 폰트 링크에 추가하거나 선언 125건을 500/700으로 정리.
5. 구 아이콘 세트 잔여분 정리 — `stroke-width="2"` 47건, `stroke-linecap="butt"` 40건.
6. 반경 18종 → 5단계, gap 24종 → 4px 스케일, 0.5px 폰트 크기 8종 → 정수 스케일.
7. `#FFF` / `#FFFFFF` 표기 통일, 1회성 색 17종 제외.
8. 6장 토큰을 코드에 정의하고 인라인 hex를 `var()`로 치환.
