## 3. 작업

### 작업 ① 파일 배치 — **13개**

`im-agent/ui/platform/` 에서 아래 13개를 **앱과 같은 출처**에 올린다.
(목록은 손으로 적은 것이 아니라 화면들이 실제로 요구하는 것을 훑어 뽑았다)

```
/im/tokens.css        ← ★ 디자인 토큰
/im/outputs.html      /im/report-flow.html   /im/files.html      ← 탭 셋
/im/intake.html       /im/fields.html        /im/reports.html    ← 4단계 (탭 바에 달지 않는다)
/im/flow-core.js      /im/fields-core.js     /im/gate-core.js
/im/live-core.js      /im/catalog.js         /im/inapp.js
```

★★ **`tokens.css` 를 빠뜨리면 색·글꼴이 통째로 빠지는데 오류는 안 난다** —
CSS 는 못 찾은 변수를 조용히 넘긴다. 그래서 화면이 스스로 확인하고
**「디자인 토큰(tokens.css)이 실리지 않았습니다」**를 띄운다. 그 문구가 보이면
파일이 안 올라간 것이다.

★ **같은 출처여야 한다.** 다른 도메인이면 브라우저가 iframe 높이 측정을 막아
화면이 400px 쯤에서 **잘린 채 정상처럼** 보인다.

★ `intake` · `fields` · `reports` 는 **탭 바에 달지 않는다** — `report-flow.html`
이 iframe 으로 부른다. 따로 달면 4단계가 6개 탭처럼 보인다.

### 작업 ② 서버 — 라우터 둘

```js
// server.js (포트 8181)
const AGENT = '/volume1/linkpilot/im-agent';
const ROOT  = '/volume1/linkpilot/im-projects';

const read    = require(AGENT + '/ui/api-router.cjs');   // 읽기 6개
const reports = require(AGENT + '/ui/report-api.cjs');   // 쓰기 22개
const { createQueue } = require(AGENT + '/ui/run-queue.cjs');
const queue = createQueue({ agentRoot: ROOT, concurrency: 1 });

app.use('/api/linkpilot', read.createRouter({ agentRoot: ROOT, agentModulePath: AGENT }));

app.use('/api/linkpilot', reports.createRouter({
  agentRoot: ROOT,
  agentModulePath: AGENT,
  authenticate: (req) => req.session && req.session.user,   // 없으면 마운트에서 예외
  startRun:   (id, spec, user) => queue.startRun(id, spec, user),
  runningFor: (id) => {                          // ★★ 빠뜨리기 쉽다 — 아래를 읽는다
    const r = queue.latestFor(id);
    return r && (r.status === 'running' || r.status === 'queued') ? r : null;
  },
  // fetchLinked · headLinked · extractOneshot 은 이번에 넘기지 않는다 (§1)
}));

process.on('SIGTERM', () => queue.stop());
```

### 작업 ③ 탭 바 — **이름을 적지 말고 목록을 읽는다**

```js
import FLOW from '/im/flow-core.js';        // 또는 window.LinkPilotFlow

FLOW.TABS.map(t => ({ label: t.tab, note: t.tabNote, src: '/im/' + t.file, plan: t.plan }))
// [ { id:'done',  tab:'완성 보고서', file:'outputs.html',     plan:'pro'  },
//   { id:'make',  tab:'보고서 생성', file:'report-flow.html', plan:'pro'  },
//   { id:'files', tab:'자료 업로드', file:'files.html',       plan:'free' } ]
```

탭 내용 안에서 채우는 값은 **탭마다 하나씩**이다.

```js
window.LINKPILOT_OUTPUTS     = { api:'/api/linkpilot', session:currentUser, inTab:true };
window.LINKPILOT_REPORT_FLOW = { api:'/api/linkpilot', base:'/im/', session:currentUser,
                                 inTab:true, external:{ repoUrl:'…', agentUrl:'…' } };
window.LINKPILOT_FILES       = { api:'/api/linkpilot', session:currentUser, inTab:true };
```

★★ **`inTab: true` 를 반드시 켠다.** 탭 이름과 화면 제목이 **같은 글자**라
안 켜면 「보고서 생성」 아래에 「보고서 생성」이 한 번 더 나온다.
거꾸로 **단독으로 열 때 켜 두면 이름 없는 화면**이 된다.

★ `external`(기존 외부 분석 경로)은 **지우지 않는다** — 붙이는 일이 지금 쓰는
흐름을 끊으면 안 된다.

### 작업 ④ 환경변수 — **본체 프로세스에** 넣는다

GitHub Secrets 만으로는 아무 일도 안 일어난다. 공공데이터를 부르는 것은
NAS 에서 도는 프로세스다. `cp .env.example .env`

| 없으면 | |
|---|---|
| `IM_AGENT_ROOT` | 프로젝트 폴더 위치를 모른다 (**필수**) |
| `VWORLD_KEY` + `VWORLD_DOMAIN` | 07 Geo 를 통째로 건너뛴다 |
| `DATA_GO_KR_KEY` | 실거래가·건축물대장·인허가를 건너뛴다 |
| `KMA_APIHUB_KEY` · `REB_API_KEY` · `ECOS_API_KEY` | 해당 절이 빈다 |

★ **키가 없으면 지어내지 않고 `unavailable` 을 돌려주고 그 절을 비운다.**
★ `VWORLD_DOMAIN` 은 콘솔의 서비스URL 을 **글자 그대로** 넣는다 — 스킴·경로를
벗기면 **간헐적으로**(5회 중 2회 실측) 인증이 거부되고, 증상이 「가끔 값이 안
들어온다」로만 보여 원인 추적이 가장 오래 걸린다.
★ `DATA_GO_KR_KEY` 는 **Decoding(일반) 인증키**다. Encoding 키를 넣으면 인증만
실패하는데 증상이 「키가 틀렸다」와 구분되지 않는다.

### 작업 ⑤ 한글 글꼴 — **설치했다는 말로는 부족하다**

넣을 것: **`Noto Sans CJK KR` · `Noto Serif CJK KR`**
(데비안·우분투 계열은 `fonts-noto-cjk`. Synology DSM 에 꾸러미가 없으면 글꼴 파일을
`im-agent/../fonts/` 에 `NotoSansKR-400.woff2` 형식으로 넣는다 — 코드가 문서에 박는다)

**확인은 산출물로 한다:**

```bash
strings 12_Final/im-a4.pdf | grep CJK
# CJKkr 이 나와야 한다.  CJKjp · CJKsc · CJKtc · WenQuanYi 가 나오면 잘못된 것
```

★ **한글이 화면에 멀쩡히 보이는 것은 근거가 아니다.** 일본어·중국어 변형도 한글은
그린다 — 다른 것은 한자 모양이라 눈으로는 안 잡힌다. 실제로 이 저장소의 PDF 에
한글이 중국어 글꼴로 박혀 나간 적이 있고, **「설치했다」는 검사는 통과하고 있었다.**

## 4. 조용히 무너지는 것들 — **오류가 안 나서 더 위험하다**

| 빠뜨리면 | 무슨 일이 | 어떻게 알아채나 |
|---|---|---|
| `authenticate` | **마운트에서 예외**를 던진다 (일부러 그렇게 했다) | 서버가 안 뜬다 — 이건 시끄러워서 안전하다 |
| **`runningFor`** | **오류도 경고도 없이** 「생성 중 값 저장 거부」가 꺼진다. 생성 도중 값을 고칠 수 있게 되고, **그날 산출물이 데이터와 어긋난다** | 아무 표시도 없다. §6 ⑧ 로만 잡힌다 |
| `tokens.css` | 색·글꼴이 통째로 빠지는데 CSS 는 조용히 넘어간다 | 화면이 스스로 「토큰이 실리지 않았습니다」를 띄운다 |
| `inTab` | 제목이 두 번 나온다 / 단독으로 열면 이름이 없다 | 눈으로 |
| 다른 출처(도메인) | iframe 높이 측정이 막혀 **잘린 채 정상처럼** 보인다 | 화면 아래가 400px 쯤에서 잘린다 |
| 한글 글꼴 | 한글이 다른 나라 글꼴로 박힌다 | **PDF 를 열어야** 안다 (§5) |

★ 큐에는 `runningFor` 라는 이름의 메서드가 **없다**(`latestFor` 다). 그래서 위
코드처럼 직접 이어 줘야 하고, 안 이으면 **아무 일도 안 일어난 것처럼 보인다.**

## 7. 금지 사항

| | 왜 |
|---|---|
| 화면 파일을 **고쳐서** 붙인다 | 출처 검사·플랜 판정이 두 벌이 된다. 고칠 곳이 있으면 저장소로 돌려보낸다 |
| 탭 이름·단계 이름을 **앱에 적어 둔다** | `flow-core.js` 가 단일 출처다. 적어 두면 한쪽만 고치는 날 탭 이름과 화면 제목이 갈린다 (2026-08-18 에 실제로 이름을 한 번 바꿨다) |
| 산출물 목록·진행률을 **앱이 계산한다** | 서버가 준다. 산출물이 하나 늘 때 한쪽만 고치면 진행률이 **조용히** 틀린다 |
| 실패를 **성공으로** 돌려준다 | 값이 조용히 빠지고 문서는 멀쩡해 보인다 — 이 시스템에서 가장 나쁜 실패다 |
| 키·토큰을 코드·로그·커밋에 **평문으로** 남긴다 | 절대 금지. 장부에 토큰이 섞이면 서버가 예외로 막는다 |
| `im-projects/` 를 지운다 | 산출물과 프로젝트 데이터가 거기 있다 |

## 8. 롤백

1. `app.use('/api/linkpilot', …)` **두 줄을 주석 처리**하고 재시작 → API 가 사라진다
2. 탭 바에서 **세 탭을 뺀다** → 화면이 사라진다
3. `/im/` 폴더는 지우지 않아도 된다 (아무도 안 부르면 그냥 정적 파일이다)
4. **`im-projects/` 는 지우지 않는다**
