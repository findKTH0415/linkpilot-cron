★ **지우기 전에 제 사고를 찾았습니다.** 병합 커밋이 **부모를 하나만** 갖고 있었습니다. 충돌을 푼 뒤 `git add -A` 를 `git reset` 으로 되돌리면서 **「병합 중」 표시가 함께 지워졌기** 때문입니다. 파일은 멀쩡히 들어갔지만 git 은 합쳤다는 사실을 몰랐고, 그대로 지웠으면 **커밋 둘이 어디에도 안 남았습니다.** `-s ours` 로 부모만 이어 붙였습니다(트리는 한 글자도 안 바뀜).

★ **평문 개인 휴대폰 번호**를 세 파일에서 지웠습니다. 저장소는 공개입니다. 더 나쁜 것은 **검사가 그 번호의 자릿수에 묶여 있어** 지우면 빨개지는 구조였다는 점입니다 — 사실상 못 지우게 만들어 둔 셈이었습니다. 옛 커밋은 **그대로 둡니다**(D-131) — 역사를 다시 쓰면 깨지는 범위가 너무 큽니다.
