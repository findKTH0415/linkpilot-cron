# 금융기관 세부정보 필드 구성안

- 작성일: 2026-10-20
- 용도: 글로벌 투자자·금융기관 엑셀 및 LinkPilot 등록·관리
- 성격: 데이터 필드 설계안. 개별 기관의 실제 투자·대출 조건은 별도 확인 필요.

## 1. 전체 필드

| 구분 | 세부내용 필드 |
|---|---|
| ① 기본정보 | 기관명(원어·영문·한글), 로고, 본사 국가, 도시, 주소, 홈페이지, 설립연도 |
| ② 기관 분류 | 은행, 증권사, 보험사, 자산운용사, 연기금, 국부펀드, 사모펀드(PE), 벤처캐피털(VC), 개발금융기관, 정책금융기관 |
| ③ 기관 규모 | 총자산, 운용자산(AUM), 운용펀드 규모, 기준통화, 금액 기준일, 신용등급·평가기관 |
| ④ 금융·투자 방식 | 기업대출, 프로젝트금융(PF), 인프라대출, 지분투자, 펀드출자, 메자닌, 보증, 수출금융, 인수금융 |
| ⑤ 관심 사업 분야 | 부동산, 인프라, 태양광·풍력, ESS, 데이터센터, 제조업, 광물·자원, 물류, 호텔, 농업·식품 등 |
| ⑥ 대상 지역 | 투자 가능 국가, 우선 투자 지역, 투자 제한 국가, 현지 사무소 |
| ⑦ 투자 조건 | 최소·최대 투자금액, 선호 투자금액, 투자기간, 목표수익률, 지분율, 경영 참여 여부, 회수 방식 |
| ⑧ 대출 조건 | 대출금액 범위, 금리·기준금리·가산금리, 만기, 거치기간, 상환방식, 담보, 보증, LTV, DSCR, 최소 자기자본비율 |
| ⑨ 사업 단계 | 개발 초기, 인허가, 착공 전, 건설 중, 준공, 운영 중, 인수·매각, 구조조정 |
| ⑩ 한국 관련 정보 | 한국 투자 가능 여부, 한국 진출 여부, 한국 사무소, 한국 투자 실적, 한국 협력기관, 한국어 대응 여부 |
| ⑪ 주요 실적 | 사업명, 국가, 분야, 투자·대출금액, 참여 방식, 투자연도, 공동 투자기관, 진행 상태 |
| ⑫ 담당자·연락처 | 담당자명, 직책, 부서, 담당 지역·분야, 업무용 이메일, 대표전화, 문의 페이지, LinkedIn, 사용언어 |
| ⑬ 제안·심사 절차 | 접수 경로, 필수 제출서류, 접수 가능 시기, 심사 단계, 예상 심사기간, NDA 필요 여부 |
| ⑭ 출처·검증 | 출처 URL, 자료명, 공시·발표일, 최종 확인일, 검증 상태, 비고 |
| ⑮ 내부 관리 | 담당 회원·직원, 관심도, 적합도, 접촉 여부, 최근 접촉일, 협의 단계, 다음 조치, 후속 연락일 |

## 2. 최초 등록 필수 필드

| 필드 | 입력 기준 |
|---|---|
| 기관명 | 영문 또는 원어 공식 명칭 기준. 한글명 병기 가능 |
| 기관 유형 | 대표 유형 1개 선택. 필요한 경우 보조 유형 추가 |
| 국가 | 본사 소재 국가 |
| 홈페이지 | 공식 홈페이지 URL |
| 투자·금융 방식 | 복수 선택 가능 |
| 관심 분야 | 복수 선택 가능 |
| 대상 지역 | 국가 또는 권역 단위로 입력 |
| 투자금액 범위 | 최소·최대 금액과 통화를 분리. 미공개면 상태 표기 |
| 한국 투자 가능 여부 | 가능 / 불가 / 확인 필요 |
| 문의 경로 | 공식 문의 페이지, 대표 이메일 또는 공개된 업무용 연락처 |
| 출처 URL | 해당 정보의 근거 페이지 |
| 최종 확인일 | YYYY-MM-DD 형식 |

필수 필드는 입력 칸을 갖추되, 확인되지 않은 내용을 임의로 채우지 않는다.

## 3. 입력·관리 기준

- 미공개: 기관이 해당 정보를 공개하지 않음.
- 확인 필요: 공개 여부 또는 실제 조건을 아직 확인하지 못함.
- 해당 없음: 해당 기관이나 금융 방식에 적용되지 않음.
- 금액은 숫자와 통화를 분리한다. 원문 금액을 보존하고 환산금액에는 환율·기준일을 기록한다.
- 총자산·운용자산·펀드 규모는 서로 다른 항목으로 관리한다.
- 금리·목표수익률·대출 조건은 적용 대상, 기준일, 근거를 함께 기록한다.
- 한국 진출 여부와 한국 투자 가능 여부는 별도 필드로 관리한다.
- 기관의 일반 투자 방침과 개별 펀드·상품의 조건은 구분한다.
- 담당자는 공개된 업무용 정보 또는 적법하게 확보한 연락처를 사용한다.
- 내부 적합도·협의 메모는 공개용 기관 소개와 분리한다.
- 기관 ID를 부여하고 담당자·펀드·투자 실적을 해당 ID로 연결하면 중복 관리를 줄일 수 있다.

## 4. 주요 용어

| 약어 | 한글 설명 |
|---|---|
| AUM | 운용자산 |
| PE | 사모 지분투자 또는 사모펀드 |
| VC | 벤처캐피털 |
| PF | 프로젝트금융 |
| ESS | 에너지저장장치 |
| LTV | 담보가치 대비 대출금 비율 |
| DSCR | 원리금상환커버리지비율. 원리금 상환 재원과 상환액의 비율 |
| NDA | 비밀유지계약 |
| 메자닌 | 전환사채 등 대출과 지분투자의 중간 성격을 가진 금융 |

## 5. 요약

기관 목록 구축에는 기본정보를 우선 등록한다. 실제 투자유치·금융조달에 활용하려면 투자금액, 사업 단계, 한국 투자 가능 여부, 접촉 경로, 협의 상태까지 관리한다.
