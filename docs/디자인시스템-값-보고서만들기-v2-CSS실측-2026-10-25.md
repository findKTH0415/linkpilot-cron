## 12. 인수인계 시 확인할 점 (집계에서 보인 것)

- 글자 크기가 18단계로 흩어져 있습니다 (`10px`–`36px`, `.5px` 단위 포함). 토큰화할 때 `11.5 / 12.5 / 13.5 / 14.5`를 정수 단계로 묶을지 정해야 합니다.
- "보고서 만들기" 제목이 배너(`-.02em`)와 오른쪽 칸(`-.03em`)에서 자간이 다릅니다.
- 검정 버튼 hover가 `#2B3440` ×8, `#24323A` ×2 두 가지입니다.
- 숫자 글꼴 Space Grotesk는 이 화면에만 쓰입니다. 다른 화면과 맞출지 정해야 합니다.
- `#5A7A00` (라임 글자)은 작은 글자 대비용 진한 라임입니다. `#AAE106`은 바탕 · 선 전용으로 쓰였고 흰 바탕 위 글자로는 쓰이지 않습니다.
- 정보 파랑 `#0063CC` · `#E6F0FF`, 경고 주황 계열은 LinkPilot 핵심 3색(ink · lime · tint) 밖의 의미 색입니다.
- 스타일은 모두 인라인입니다. 클래스 · 외부 CSS 파일이 없어 위 값이 곧 원본입니다.
