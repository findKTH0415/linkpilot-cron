### ⚠ 9번에서 나온 것 — 한글이 일본어 글꼴로 나가고 있었다

초록으로 끝난 CI(`dc642e4`)의 로그 **본문**에 이렇게 적혀 있었다.

```
⚠ 글꼴: 요청한 글꼴이 없다: Noto Serif KR, Noto Sans KR
   — 대신 Noto Sans CJK JP 로 그려진다
```

CI 는 `fonts-noto-cjk` 를 설치한다. **그 꾸러미가 심는 이름은 `Noto Sans CJK KR`
이지 `Noto Sans KR` 이 아니다.** 요청이 통하지 않아 브라우저가 다른 CJK 글꼴을
골랐고, 「글꼴을 설치했다」는 선언만 맞은 채 **문서는 계속 다른 활자로 나갔다**
(등록부 D-52 재발 · MEMORY.md M-09).

같은 기계에서 실제 PDF 를 만들어 전후를 쟀다.

| | PDF 에 박힌 글꼴 |
|---|---|
| 고치기 전 | `WenQuanYiZenHei` (중국어) |
| 고친 뒤 | `NotoSansCJKkr` · `NotoSerifCJKkr` (한국어) |

**이번 배포에 이 수정이 함께 들어간다.** 글꼴 스택에 실제 설치되는 이름을 넣고
(`tokens.js` 한 곳), 테스트가 **선언이 아니라 만들어진 PDF 를 열어** 확인한다.
→ §3 의 「NAS 한글 글꼴」 항목도 이 기준으로 바뀐다 (아래).

### ❌ 8번이 뜻하는 것 — 숨기지 않는다

`core/linked.js` 의 `materialize()`(연결 자료를 실제로 가져오는 함수)를
**이 저장소의 어떤 코드도 부르지 않는다.** 즉 **연결한 자료가 보고서에 실리지
않는다.** 1회성도 마찬가지로 읽는 경로가 본체 쪽에 있다.

이 저장소 이력에 같은 실패가 두 번 있었다(D-48 · D-62 — 모듈을 만들고 아무 데서도
안 불렀다). 그때는 **조용히 빠졌고 아무도 몰랐다.**

**이번에는 조용히 두지 않았다** — 사용자 경로를 **닫았다**:

| 엔드포인트 | 붙기 전 동작 |
|---|---|
| `POST /projects/:id/linked` | **501** 「저장소 내려받기가 붙어 있지 않습니다 — 연결해도 자료를 읽지 못해 보고서에 실리지 않습니다」 |
| `POST /projects/:id/oneshot` | **501** 「읽는 경로가 붙어 있지 않습니다 — 올려도 보고서에 실리지 않고, 보관하지 않으므로 다시 쓸 수도 없습니다」 |
| `POST /projects/:id/linked/verify` | **501** (조회기 미연결) |

★ 1회성은 특히 위험하다 — 받아 두고 안 읽으면 **보관도 안 하므로 자료를 잃는
것과 같다.** 그래서 「성공」을 돌려주지 않는다.

**그래서 이 상태로 배포해도 안전하다.** 다만 자료 탭 화면을 붙이면 안 된다.

## 4. 실행 순서

### 4-1. 파일 배치

`im-agent/ui/platform/` 의 **`.html` · `.js` 를 앱과 같은 출처**에 올린다.

```
/im/tokens.css           ← ★ 디자인 토큰. 빠뜨리면 화면이 색 없이 뜬다
/im/report-flow.html     ← 「새 보고서 생성」 탭 내용
/im/outputs.html         ← 「완성 보고서」 탭 내용
/im/intake.html  /im/fields.html  /im/reports.html
/im/flow-core.js  /im/fields-core.js  /im/gate-core.js
/im/live-core.js  /im/catalog.js  /im/inapp.js
```

★★ **`tokens.css` 를 빠뜨리면 색·글꼴이 통째로 빠지는데 오류는 안 난다** —
CSS 는 못 찾은 변수를 조용히 넘긴다. 그래서 화면이 스스로 확인하고
「디자인 토큰(tokens.css)이 실리지 않았습니다」를 띄운다. **그 문구가 보이면
파일이 안 올라간 것**이다 (§5 확인 6번).

★ **같은 출처여야 한다.** 다른 도메인이면 브라우저가 iframe 높이 측정을 막고,
화면이 400px 쯤에서 **잘린 채 정상처럼** 보인다.
★ `intake` · `fields` · `reports` 는 **탭 바에 달지 않는다** — `report-flow.html`
이 iframe 으로 부른다. 따로 달면 4단계가 7개 탭처럼 보인다.

### 4-2. 서버 — 라우터 둘

```js
// server.js (포트 8181)
const AGENT = '/volume1/linkpilot/im-agent';
const ROOT  = '/volume1/linkpilot/im-projects';

const read    = require(AGENT + '/ui/api-router.cjs');
const reports = require(AGENT + '/ui/report-api.cjs');
const { createQueue } = require(AGENT + '/ui/run-queue.cjs');
const queue = createQueue({ agentRoot: ROOT, concurrency: 1 });

app.use('/api/linkpilot', read.createRouter({ agentRoot: ROOT, agentModulePath: AGENT }));

app.use('/api/linkpilot', reports.createRouter({
  agentRoot: ROOT,
  agentModulePath: AGENT,
  authenticate: (req) => req.session && req.session.user,
  startRun: (id, spec, user) => queue.startRun(id, spec, user),
  runningFor: (id) => {                        // ★★ 빠뜨리기 쉽다
    const r = queue.latestFor(id);
    return r && (r.status === 'running' || r.status === 'queued') ? r : null;
  },
  // fetchLinked · extractOneshot 은 **이번 배포에서 넘기지 않는다** —
  // 안 넘기면 자료 경로가 501 로 닫힌다 (§2 8번). 그것이 지금 맞는 상태다.
}));

process.on('SIGTERM', () => queue.stop());
```

**조용히 무너지는 둘**

| | 안 하면 |
|---|---|
| `authenticate` | **마운트에서 예외**를 던진다 (일부러 그렇게 했다) |
| `runningFor` | **오류도 경고도 없이** 「생성 중 값 저장 거부」가 꺼진다. 그날 산출물이 데이터와 어긋난다. 큐에 그 이름의 메서드가 없으므로(`latestFor` 다) 위처럼 직접 잇는다 |

### 4-3. 탭 바 — 이름을 복사해 적지 않는다

```js
import FLOW from '/im/flow-core.js';        // 또는 window.LinkPilotFlow

FLOW.OUTPUTS_SECTION  // { tab:'완성 보고서',    file:'outputs.html',     plan:'pro' }
FLOW.SECTION          // { tab:'새 보고서 생성', file:'report-flow.html', plan:'pro' }
```

탭 내용 안에서:

```js
window.LINKPILOT_OUTPUTS     = { api:'/api/linkpilot', session:currentUser, inTab:true };
window.LINKPILOT_REPORT_FLOW = { api:'/api/linkpilot', base:'/im/', session:currentUser,
                                 inTab:true, external:{ repoUrl:'…', agentUrl:'…' } };
```

★ `inTab` 을 **안 켜면 제목이 두 번** 나오고, **단독으로 열 때 켜 두면 이름 없는
화면**이 된다.
★ `external`(기존 외부 분석 경로)은 **지우지 않는다** — 붙이는 일이 기존 흐름을
끊으면 안 된다.

### 4-4. 환경변수 — **본체 프로세스에** 넣는다

GitHub Secrets 만으로는 아무 일도 안 일어난다. 공공데이터를 쓰는 것은 NAS 에서
도는 프로세스다. `cp .env.example .env`

| 없으면 | |
|---|---|
| `IM_AGENT_ROOT` | 프로젝트 폴더 위치를 모른다 (**필수**) |
| `VWORLD_KEY` + `VWORLD_DOMAIN` | 07 Geo 통째로 건너뜀 |
| `DATA_GO_KR_KEY` | 실거래가·건축물대장·인허가 건너뜀 |

**키가 없으면 지어내지 않고 `unavailable` 을 돌려준다** — 그 절이 빈다.
`VWORLD_DOMAIN` 은 콘솔의 서비스URL 을 **글자 그대로** 넣는다 (스킴·경로를 벗기면
간헐적으로 인증이 거부된다).

## 6. 롤백

이 배포는 **본체에 파일을 얹고 라우터를 마운트하는 것**뿐이다.

1. `app.use('/api/linkpilot', …)` 두 줄을 주석 처리하고 재시작 — API 가 사라진다
2. 탭 바에서 두 탭을 뺀다 — 화면이 사라진다
3. `/im/` 폴더는 지우지 않아도 된다 (아무도 부르지 않으면 그냥 정적 파일이다)

**`im-projects/` 는 지우지 않는다.** 만들어진 산출물과 프로젝트 데이터가 거기 있다.

## 8. 이 배포로 사용자에게 달라지는 것

| | 지금 | 배포 후 |
|---|---|---|
| 값 입력 | 앱 밖 AGENT | 앱 2단계 — **출처 없으면 저장이 안 열린다** |
| 계산 항목 | 사람이 적어 넣을 수 있다 | 입력란을 **아예 안 만든다** (19개) |
| 사양 확정 | 없음 | 3단계에서 잠근다 — 확정 전에는 생성이 안 열린다 |
| 완성본 | 「등록된 완성본 0건」 | **나온 것 · 아직 안 나온 것 · 이 딜에서는 안 나오는 것** |
| 배포 판정 | 없음 | 검증 못 지나면 **목록에도 표시되고 내려받기도 막힌다** |

★ **100% 는 「만들어졌다」이지 「보내도 된다」가 아니다.** 화면이 그렇게 말하고,
파일 내려받기도 검증을 통과해야 열린다.
