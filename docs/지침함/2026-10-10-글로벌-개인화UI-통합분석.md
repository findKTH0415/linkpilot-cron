## 1. 결론
한국어를 쓰는 1인 사업가의 업무 비서로는 기능 폭이 넓다. 글로벌·전문가 커뮤니티·비즈니스 개인화 플랫폼으로 통합하려면 기반 넷이 먼저다.
1. 다국어·지역화 0곳
2. 서버 쪽 유료 권한 판정 미완 · 등급 체계 세 벌
3. 커뮤니티 핵심 탭(받은 공유·전문가 자문) 미구현
4. 기기 사이 동기화 고장이 같은 모양으로 반복

## 2. 축별 평가
| 축 | 지금 | 강점 | 문제 |
|---|---|---|---|
| 편의성 | 중상 | 한 벌 머리 개별/통합 검색 · 브리핑 0.8초 먼저 그리기 · 메뉴 편집 | 섹션 16개 이상 · 같은 기능이 두 자리에 서는 고장 반복 |
| 필요성 | 국내 높음 · 글로벌 중간 | 명함→연락처→프로젝트·딜→할일·일정→브리핑 흐름 · AI 통화 요약 | 투자·정책·에너지·가치평가가 한국 공공데이터 전용, 대부분 자료 준비 중 |
| 개인화 | 중간 | 관심뉴스 · 인사말 받는 사람 14 · 말투 7 · 테마 | 꾸밈 위주 · 역할·업종별 홈 없음 · 언어·통화·시간대 설정 없음 |
| 커뮤니티 | 하 | 문의 화면 · 공유 뷰어 · NDA | 전문가 신원·평판·결제·분쟁 처리 0 |
| 직관성 | 중간 | 한 화면 한 할 일 원칙 · 실패 사유를 사람 말로 | 메뉴 이름이 한국 업무 어휘 |
| 운영 효율 | 중하 | 교차검증 200단계 이상 · 자동 배포 | 앱 압축 크기 한도(600KB)에 붙음 · Staging 없음 |

## 3. 권하는 차례
1. 기반(4~6주): 서버 권한 완결 · 동기화 창구 한 벌 · 화면 문자열 사전 추출 · 번들 분리로 크기 여유
2. 구조(약 4주): 섹션을 «내 일 / 내 사람 / 내 거래 / 시장·정보 / 커뮤니티» 다섯 갈래로 · 역할별 홈 · 언어·통화·시간대
3. 커뮤니티(6주 이상): 전문가 신원·평판 · 유료 자문 결제 · 공유함
4. 나라별 투자·정책 자료는 마지막

## 4. 검토자에게 묻는 것
- 차례(기반 → 구조 → 커뮤니티)가 맞는가, 빠진 위험은 무엇인가
- 일정 추정이 현실적인가
- 글로벌 B2B 개인화 플랫폼으로서 빠진 축(예: 협업·권한·데이터 이동성·규제)은 무엇인가

## 5. 못 잰 것
실제 사용 지표 · 해외 경쟁 제품 비교 · 해외 사용자 의견.
