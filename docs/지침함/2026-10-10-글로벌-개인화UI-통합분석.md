## 1. 결론
한국어를 쓰는 1인 사업가의 업무 비서로는 기능 폭이 넓다. 글로벌·전문가 커뮤니티·비즈니스 개인화 플랫폼으로 통합하려면 기반 넷을 먼저 채운다.
1. 다국어·지역화를 시작할 자리를 만든다. 지금 화면 글자는 코드에 한국어로 들어 있다(§12-21 · 5,466곳 실측).
2. 유료 권한을 서버가 판정하게 마무리한다. 넷째 단계까지 들어갔다(D-325). 등급 체계를 하나로 정한다(D-326 · 지금 세 벌).
3. 커뮤니티 핵심 탭을 채운다. 받은 공유·전문가 자문은 자리만 있다(D-355).
4. 기기 사이 동기화를 한 벌 창구로 모은다. 같은 모양의 고장이 기록에 열여섯 건 있다(M-120~M-135).

## 3. 진행 차례
일정은 어림이다. 실제 일정은 단계마다 범위를 정한 뒤 다시 잰다.
1. 기반(어림 4~6주 · 담당 Orchestrator): 서버 권한 마무리 · 동기화 한 벌 창구 · 화면 글자 사전 추출 · 앱 크기 여유 확보
2. 구조(어림 4주 · 담당 Orchestrator, 화면 결정은 사장님): 섹션 다섯 갈래(내 일 / 내 사람 / 내 거래 / 시장·정보 / 커뮤니티) · 역할별 홈 · 언어·통화·시간대
3. 커뮤니티(어림 6주 이상 · 담당 Orchestrator, 가격·결제 승인은 사장님): 전문가 신원·평판 · 유료 자문 결제 · 공유함
4. 나라별 투자·정책 자료는 마지막(담당 Orchestrator)

목표일은 사장님이 §4 에 답하신 날(승인일)을 D 로 센다.

## 4. 정해 주실 것 — 사장님
1. **어디서**: 이 대화창(claude.ai 프로젝트 「LinkPilot 리뉴얼 재구성」 또는 Orchestrator 세션).
2. **무엇을**: 진행 차례(§3)를 그대로 갈지, 커뮤니티를 앞당길지 한 가지를 고른다.
3. **어떻게**: 「차례대로」 또는 「커뮤니티 먼저」라고 한 줄로 답한다.
4. **그러면**: Orchestrator 가 1단계 첫 일감의 업무지침을 만든다. 첫 일감은 화면 글자 사전 추출이다. 지침함에 올려 교차검증을 거친 뒤 반영한다.
