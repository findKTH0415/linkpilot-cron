## 3. 전환 뒤 매일 보는 것

1. **러너 온라인** — `offline` 이면 섹션 맨 위 경고. «NAS 전원 · Container Manager `github-runner` 프로젝트 · 급하면 `LP_RUNNER` 변수 삭제» 셋을 적는다.
2. **지난 24시간 platform 실행** — 총 · NAS · GitHub 러너 · 실패 건수. 실패는 작업 이름과 첫 오류 줄.
   «NAS 러너 이미지에 빠진 것» 오류면 README 의 «빌드 다시» 를 적는다.
3. **돈이 새는 곳** — `LP_RUNNER=nas` 인데 GitHub 러너에서 돈 job. `LP_DEPLOY_RUNNER` 를 안 켠 동안의 deploy-nas 는 «예정된 남음»으로 따로 센다.
4. **청구액** — 어제 · 이번 달 누적 · 예산 $40 대비 %. `gh api users/findKTH0415/settings/billing/usage` 를 시도하고, 못 읽으면 UNVERIFIED + «청구 → 용법 화면 캡처 부탁».
5. **멈춘 대기열** — `queued` 30분 넘은 job.
6. **NAS 감시** — cron 의 `platform-nas-health.yml` 이 오늘 돌았는가(이 감시는 공개 저장소라 예산 차단과 무관해야 한다 — 돌지 않았으면 그 자체가 이상).
7. **토큰 만료** — 만료일 `[사장님 기입: YYYY-MM-DD]`. 30일 전부터 «토큰 만료 D-n» 을 맨 위에.
8. **안전** — cron 에 자기 서버 러너가 붙어 있으면 맨 위 경고(§22).
