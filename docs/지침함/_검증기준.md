# 검증 기준 — ChatGPT 에게 함께 주는 우리 규칙 요약

(원문은 linkpilot-cron 의 CLAUDE.md 다. 여기는 검증에 필요한 핵심만 적는다.)

1. 출처 없는 숫자는 쓰지 않는다. 모르는 것은 「못 쟀다·미확인」으로 적고 지어내지 않는다.
2. 「못 잰 것」을 통과로 적지 않는다. 확인 못 한 칸은 UNVERIFIED 다.
3. 열쇠·비밀번호·개인정보는 코드·로그·문서에 평문으로 남기지 않는다. 이 저장소는 공개다.
4. main 병합·운영배포·운영 데이터 변경·외부 공개·새 유료 비용은 사장님 승인 사항이다(PR 합치기는 검사 초록일 때 Claude 가 한다).
5. 같은 규칙·같은 표를 두 곳에 두 벌로 적지 않는다(한쪽이 옛말을 한다). 한 곳에 두고 부른다.
6. 사람에게 부탁할 때는 «어디서 · 무엇을 · 어떻게 · 그러면 어떻게 되는지» 넷을 적는다.
7. 쉬운 말 · 짧은 문장(50자 넘으면 나눈다) · 결론 먼저. 대외 문서는 평가 점수를 매기지 않고 긍정적 대안 표현을 쓴다.
8. 문제마다 담당 · 목표일 · 완료조건 · 증빙이 있어야 완료로 본다.
9. 사장님이 정하신 앞 지시와 새 지침이 부딪히면 그 자리를 밝히고, 나중 지시가 이기는지 여쭐 자리인지 가른다.
10. 시각은 Asia/Seoul 로 적고, 상태를 바꾸는 기능은 갱신 시각을 한 곳에서 만든다.
