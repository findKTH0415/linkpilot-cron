# 태양광 분석 화면 수정 지침 (2026-10-25)

- 대상: LinkPilot 플랫폼 › 태양광 사업분석 (사업요약 · 리포트 미리보기 · ② 지적·건축물 가상배치도 · 지붕형 수익공유)
- 근거: 운영자 표시 화면 4장 (빨간 표시 3곳)
- 상태: 「송부」 지시 후 AI Project Manager Orchestrator에게 전달 → 수취 · 작업착수 확인

## 1. 미리보기 상단 막대 삭제

- 리포트 미리보기(출력) 화면 맨 위의 막대(회사명 · Translation · 공유 버튼이 있는 줄)를 지운다.
- 공유 · 번역 기능이 필요하면 미리보기 밖 원래 화면(왼쪽 「태양광 분석 리포트 공유」 카드)에서만 쓴다.
- 인쇄 · PDF 출력물에 이 막대가 찍히지 않는지 확인한다.

## 2. 지붕 모듈 배치 오류 — 건물 전체가 아니라 실제 지붕에만

현상: 「② 지적·건축물 가상배치도」에서 패널이 건물 외곽선(브이월드 건물 도형 6,286㎡) 전체에 깔린다. 실제로는 건물 전체가 지붕이 아니다 (옥탑 · 설비 · 다른 높이의 지붕 · 천창 · 그늘 구간 포함).

고칠 방향: 세 가지 자료로 지붕 면적을 따로 구하고, 맞춰 본 뒤 그 안에만 배치한다.

| 순서 | 자료 | 구하는 값 | 비고 |
|---|---|---|---|
| 1 | 지붕면적 (건축물대장 표제부 · 건축면적 / 동별 면적) | 대장상 면적 | 공공데이터포털 건축HUB API. 키는 GitHub Actions 경로로만 (API 규정집 v2.0) |
| 2 | 건축도면 (지붕평면도 · 배치도) | 도면상 지붕면 · 옥탑 · 설비 위치 | 의뢰인이 올린 도면이 있을 때. 없으면 「도면 미제출」 표시 |
| 3 | 위성사진 (항공 · 위성 영상) | 지붕면 윤곽 · 설비 · 그늘 | 지붕면을 나눠 그리고 설비 · 천창 구간을 뺀다 |

규칙:
- 세 값을 화면에 나란히 보이고, 채택한 값과 차이(%)를 적는다.
- 두 자료 이상이 10% 안에서 맞을 때만 「정밀 배치계획」이라고 부른다. 아니면 「추정 배치 · 현장 실측 필요」로 표시한다.
- 지붕 가장자리 이격(테두리 1m), 옥탑 · 설비 · 천창 구간, 북향 경사면을 빼고 남은 면에만 패널을 그린다.
- 모듈 수 · 설비용량 · 발전량은 채택한 지붕 면적으로 다시 계산한다 (지금 값 705매 · 451.2kW는 건물 전체 기준이라 다시 나와야 한다).
- 확인 못 한 자료는 0으로 채우지 않고 「미확인」으로 둔다.

## 3. 그래프 제목 변경

- 「솔라오 누적 이익 추이 (세전)」 → **「본건 누적 이익 추이 [세전]」**
- 같은 화면에 다른 회사 이름이 더 있다: 카드 제목 「지붕형 수익공유 · 무상설치 (솔라오형)」, 아래 각주 「타이런트 솔라오 표준표」. 이것도 「본건」 기준으로 바꿀지 운영자 확인 후 처리한다 (임의 변경 금지).

## 4. 완료 확인 (교차검증)
