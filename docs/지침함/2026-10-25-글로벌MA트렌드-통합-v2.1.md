# LINKPILOT 글로벌 기업검색·M&A 산업 트렌드 통합 작업지침 v2.1

작성일: 2026-10-25 | 목적: 기존 v2.0에 글로벌·국가별 실제 거래 트렌드 추천 기능 추가

## 1. 목표 및 원칙
- 글로벌 및 국가별로 최근 12개월 M&A 거래건수·공개 거래금액·전년 대비 변화율을 분석하고 추천 산업군의 노출 순위를 동적으로 변경한다.
- 기존 3대 산업군(미래 전략성장, K-스페셜, 글로벌 공급망·유통), 글로벌 법인검색, M&A 실사, LinkedIn 전문가 연결을 유지한다.
- '거래가 많은 산업'과 '미래 성장성이 높은 산업'을 서로 다른 지표와 탭으로 구분한다.
- 무료 공개 데이터의 커버리지 부족을 명확히 표시한다. 실제 거래 순위는 동일한 데이터셋·기간·정의 안에서만 계산한다.

## 2. 정보 구조
메인 > 글로벌 기업검색 > [기업검색] [M&A 트렌드] [미래 성장산업] [K-스페셜] [인수후보] [전문가 추천] [딜파이프라인] [보고서].
트렌드 탭 필터: 글로벌/국가/지역, 타깃기업 소재지/인수자 소재지, 산업 대·중·소분류, 최근 3/6/12/36개월, 거래 발표/완료, 공개/비공개 기업, 인수지분 50% 이상/소수지분/JV, 통화, 거래금액 구간, 데이터 출처.

## 3. 트렌드 카드 필수 항목
- 산업명, 국가, 기준일, 집계기간, 거래건수, 거래건수 YoY, 공개 거래금액 합계, 거래금액 YoY, 거래금액 공개율, 중앙값 거래금액, 주요 거래사례, 해외 인수 비중, 출처 및 커버리지.
- '거래건수 1위'와 '거래금액 1위' 배지를 구별하며 순위가 확인되지 않으면 순위 대신 '주목 산업'으로 표기.
- 원천이 유료 데이터일 경우 공개 보고서의 집계 수치만 출처 표시하여 인용하고 원시 데이터 재배포 금지.

## 4. 실제 시장 참고 벤치마크(확인된 자료)
- FTI Consulting, 2026년 2분기 글로벌 공시 거래건수 비중: 산업재 28.0%, IT 18.0%, 금융 11.2%. 이는 해당 분기 해당 데이터셋 기준이지 전 세계 모든 거래의 완전 집계가 아니다.
- PwC, 2025년 글로벌 거래금액 전년 대비 +36%, 거래건수 +1%. 대형 거래가 금액을 견인.
- PwC UK, 2026년 상반기 영국 거래건수: 산업재·서비스 382건, TMT 320건, 소비재 248건, 금융·부동산 205건, 헬스케어 86건, 에너지·유틸리티·자원 58건(해당 보고서 범위).
- JETRO, 2022~2024년 일본의 외국인 인수 대상 기업 산업별 거래건수: 소프트웨어·ICT 245건(41.1%), 서비스 79건(13.3%), 전기기계 38건(6.4%). 기간과 국경간 거래 범위를 반드시 표시.
- 국가별 동일 기준의 무료 완전 집계가 없으면 '검증된 순위 없음' 표시. 임의 숫자 생성 금지.

## 5. 추천 점수 설계(가중치 초기안)
- 최근 12개월 거래건수 백분위 25점
- 거래건수 전년 대비 증가율 15점
- 공개 거래금액 백분위 10점
- 산업 수요 성장률(독립적 산업통계) 20점
- 인수 가능 기업 후보수 및 거래 접근성 15점
- 데이터 신뢰도·커버리지 10점
- 국가·규제·외국인투자 제약 5점
결측 지표는 0점으로 대체하지 않고 가용 지표 기준으로 재정규화하며 '신뢰도 낮음' 표시. 극단적 대형 거래 1건으로 순위가 왜곡되지 않도록 건수와 금액 별도 노출.

## 6. K-스페셜 트렌드 확장
K-푸드(식품·음료·프랜차이즈·콜드체인), K-뷰티(브랜드·ODM·원료·유통), K-컬처(음악·영상·게임·IP), K-패션, K-헬스, K-리빙, K-관광, K-교육, K-펫, K-디자인.
산업별로 M&A 거래건수·금액 외에 수출 성장률, 해외 온라인 판매, 브랜드 인지도, IP·상표권, 해외 유통계약, OEM/ODM 의존도, 현지 규제 적합성 분석.
K-스페셜은 국가별 실제 거래가 적을 수 있으므로 '시장수요 상승'을 'M&A 거래 급증'으로 오표시하지 않는다.

## 7. 국가별 데이터 수집 계층
1차: SEC EDGAR, DART, UK Companies House, GLEIF, INSEE/Sirene, 프랑스 기업 API, 일본 gBizINFO, 독일 Unternehmensregister 등 공식 법인·공시 원천.
2차: 공개 M&A 통계·보고서(PwC, BCG, FTI, JETRO, 정부기관), 기업 보도자료·거래 공시.
3차: 무역·수출·산업통계(UN Comtrade, OECD, World Bank, KOTRA, 한국 수출입 관련 공식통계).
공식 법인 DB는 전체 M&A 거래 DB가 아님. 거래 자체는 별도 수집·중복제거·거래상태 검증이 필요. 데이터 접근·재사용 라이선스와 API 속도 제한 준수.

## 9. 추천 및 화면 동작
- 기본 화면: 글로벌 최근 12개월, 거래건수 기준 상위 산업 카드. '금액 기준', '성장률 기준', 'K-스페셜', '미래 수요' 전환 가능.
- 국가 선택 시 국가별 거래건수 순위 재계산. 미지원 국가는 정량 순위 대신 관련 보고서·공식 기업 목록 표시.
- 산업 카드 클릭 → 거래추세 차트 → 주요 거래 사례 → 해당 산업 기업 목록 → 인수후보 스크리닝 → LinkedIn 전문가 검색/내부 전문가 추천 → 딜 등록.
- 모든 수치에 출처 링크, 데이터 갱신일, 집계기준 툴팁 제공.
- 전문가 검색은 LinkedIn 공식 이용정책을 준수하고 무단 스크래핑·프로필 재배포 금지.

## 10. 분석 파이프라인
원천 수집 → 기업·거래 식별자 정규화 → 업종 분류 매핑 → 동일 거래 중복 제거 → 발표/완료 상태 판정 → 거래금액·환율 정규화 → 국가/기간별 집계 → 데이터 품질 검증 → 트렌드 점수 → 추천 카드 발행.
공개 보고서 수치는 자체 원시 거래 합계와 섞어 재집계하지 않는다.

## 11. 갱신 정책
기업정보: 원천 허용범위 내 일간~주간; 거래 공시: 일간; 산업 트렌드: 월간; 공식 분기 보고서: 발간 후 갱신; 수출·산업 통계: 원천 주기별. 자동 갱신 실패 시 마지막 정상 갱신일과 지연 상태 표시.

## 12. 검수·Stop/Go
- 국가/산업별 거래건수·금액 분리 여부
- 발표/완료, 지배권/소수지분/JV 구분 여부
- 거래 중복 제거 및 산업분류 매핑 검증 여부
- 공개금액 커버리지·결측치 표시 여부
- 수출 성장과 M&A 거래 증가의 구별 여부
- 각 국가별 수치의 동일 기간·동일 집계범위 비교 여부
- 출처·기준일·갱신일·라이선스 표시 여부
- 인수가능성은 검증된 매각의사/공고와 AI 후보추정을 구분하는지 여부
- 전문가 동의·개인정보·LinkedIn 약관 준수 여부

## 13. 구현 우선순위
P0: 국가/기간/산업 필터, 거래건수/금액 분리, 출처·커버리지, 거래사례.
P1: K-스페셜 트렌드·수출 성장 데이터, 인수후보 검색, 기업상세 연계.
P2: 전문가 추천, 딜파이프라인, AI 트렌드 요약·IM 보고서.
