> **🔴 2026-08-15: `DATA_GO_KR_KEY` 가 채팅에 평문 노출되었다.** Encoding·Decoding
> 두 형태 모두 대화에 남았다. **재발급이 필요하다** — data.go.kr 마이페이지 ›
> 인증키에서 재발급하면 옛 키는 즉시 무효가 된다. 저장소·커밋에는 들어가지
> 않았음을 확인했다 (`git diff` 검사). 새 키는 채팅이 아니라 셸 환경변수 또는
> GitHub Secrets 에만 넣는다.

> **🔴 2026-08-15: `VWORLD_KEY` 개발키가 저장소에 커밋되어 있었다.**
> `smoke-public-data.js:119` 의 "올바른 예"가 **실제 개발키**였다
> (`A9C7…C17A`, 발급 2026-08-07 / 만료 2027-02-07). 커밋 `47e9232` 이후
> **public 저장소에 공개 상태**였다. 본문은 자리표시자
> (`00000000-…`)로 교체했으나 **git 이력에는 남는다 — D-10 과 같은 뿌리다.**
> **vworld.kr 에서 키 재발급(기존 키 삭제)이 필요하다.** 재발급 전까지는
> 누구나 이 키로 지오코딩·WMS 를 호출할 수 있다.

> **✅ 2026-08-15: data.go.kr 활용신청 3종 완료 — 스모크 8/8 통과.**
> 서비스별로 따로 신청해야 한다는 것이 실측으로 확인됐다(키 하나로 전부 열리지
> 않는다). 신청한 것: ① 토지 매매 실거래가 ② 상업업무용 부동산 매매 실거래가

> **🔴 2026-08-15: 재발급한 키가 다시 대화에 평문으로 들어왔다.** 이번이 세 번째다.

### 🟠 D-21. 자료 추출 성공률이 측정된 적 없다

입력란을 52칸에서 8칸으로 줄인 근거가 `core/fieldplan.js` 의 채움 계획이다.
그중 **직접 입력으로 남긴 8개(시행사·토지 확보상태·연면적·총사업비·토지비·
공사비·연간 매출·인허가 현황)는 전부 `extract` 경로** — 올린 자료에서 뽑히면
사람이 안 쳐도 되고, 못 뽑으면 쳐야 한다.

**문제는 그 비율을 실제 자료로 재 본 적이 없다는 것이다.** 추출이 잘 되면 8칸도
거의 비어 있지 않고, 안 되면 8칸을 매번 손으로 친다. 어느 쪽인지 모르면 이 화면이
얼마나 편한지도 모른다.

- 필요한 것: 실제 사업계획서·감정평가서 5~10건으로 8개 항목의 추출 성공률 측정
  (~~공공데이터 키가 없는 지금은 대지면적이 더해져 9개다~~ → **2026-08-15 해소.**
  키 등록·활용신청이 끝나 대지면적은 자동으로 채워진다. 다시 8개다)
- 막고 있는 것: 본체 소스·실제 딜 자료가 이 저장소에 없다 (D-12 와 같은 뿌리)
- 결정 전에는 화면 문구를 "못 뽑으면 직접 넣어야 합니다"로 두고 **성공률을 약속하지 않는다**

### 🟠 D-22. 실거래가 이상치를 거를 것인가

2026-08-15 실측(서울 중구, 최근 3개월): 상업업무용 252건 중 표본으로 잡힌 거래가
**3.78㎡ / 0.1억원 → 2,645,503원/㎡** 였다. 같은 지역 공시지가는 65,730,000원/㎡ —
**25배 차이**다. 지분 거래나 구분소유 조각으로 보인다. 같은 조회의 토지 47건은
40,973,984원/㎡ 로 정상 범위였다.

이대로 평균 단가를 내면 시세 근거가 왜곡된다. 걸러야 하는 것은 맞으나 **기준을
정해야 코드로 옮길 수 있다.**

- [ ] 면적 하한 (예: ___㎡ 미만 제외)
- [ ] 단가 상·하한 (예: 공시지가의 ___% ~ ___%)
- [ ] 중위값 사용 (평균 대신 — 기준을 안 정해도 되지만 건수 정보가 사라진다)
- [ ] 거르지 않고 전부 표시 (판단은 사람이)

> 어느 쪽이든 **제외한 건수를 IM 에 적는다.** 조용히 빼면 근거가 사라진다.

### 🟠 D-23. 정밀 분석 자산군의 필수 입력 항목

데이터센터·물류센터처럼 정밀 분석이 필요한 자산은 **핵심 수치가 공공데이터에
아예 없다.** 2026-08-15 건축물대장 표제부 78개 필드를 실측으로 확인한 결과:

| 필요한 것 | 공공데이터 |
|---|---|
| 구조형식·층수·높이·내진설계 적용여부 | 있다 |
| 내진능력·에너지효율등급 | 필드는 있으나 **값이 공란** |
| **바닥 적재하중(kN/㎡)** · **층고(슬래브-투-슬래브)** · **전력 인입용량** | **없다** |

설계도면·구조계산서는 세움터 보관이며 **공개 대상이 아니다**(설계자 저작권 +
시설 보안). 정보공개청구도 대부분 비공개 처분된다. 매도인에게 직접 받는 것이
유일한 경로다.

즉 현재 화면의 필수 직접 입력 8칸은 **일반 부동산 기준**이고, 데이터센터 딜에는
그대로 쓸 수 없다.

- [ ] 자산군별 입력 항목을 분리한다 → 어느 자산군까지: ________________
- [ ] 분리하지 않는다 (정밀 분석 자산은 이 도구의 대상이 아님을 명시)
