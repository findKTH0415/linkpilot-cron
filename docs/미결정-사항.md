## A. 사양 불일치 — CLAUDE.md 와 실제 코드가 다르다

이 셋은 "무엇을 만들지 못했다"가 아니라 **"기준 문서와 코드가 서로 다른 말을 하고 있다"**
는 문제다. 어느 쪽이 맞는지 정해야 나머지 작업의 목표가 정해진다.

## D. 기술 승인

### ⚪ D-13. PDF·PPTX 서버 생성용 의존성

미승인 상태라 목록에는 두되 비활성 + 사유 표시. 대안(브라우저 인쇄)은 동작한다.
HWP 는 승인과 무관하게 사실상 불가.

### ⚪ D-14. 건설이자(IDC) 자본화 기준

모델 총사업비가 문서값보다 크다 (2,846 → 2,962억원). 현재 `TPC_GAP` 경고만.
회사 기준을 정해야 상수화할 수 있다.

### 🟡 D-15. 시장조사 Connector

`03_research` 는 Connector 가 없어 LLM 기억에 의존한다. 산출물은 전부
`verified=false` 라 재무모델에 들어가지 않지만, **운영 투입 전 웹검색·통계 API 로
URL 출처를 강제해야 한다.**
