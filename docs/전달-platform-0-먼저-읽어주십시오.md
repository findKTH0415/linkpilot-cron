## 1번만 따로 — **오늘 막힌 것이 이것입니다**

로그인 화면이 「등록된 기기 3/3」으로 막습니다. 그런데 **지금 로그인하는 기기가
목록에 이미 있습니다.** 표식이 **기기마다**가 아니라 **탭마다** 만들어지고 있어서,
새 탭을 열 때마다 새 기기로 등록됩니다.

실제 기기는 둘(안드로이드·맥)인데 셋으로 세고 있었습니다.

**재현 — 세 줄**

1. 같은 브라우저에서 로그인한다 → 등록 1
2. **새 탭**을 열어 다시 로그인한다 → 등록 **2**  ← 여기서 갈립니다
3. 2번에서 등록이 안 늘면 고쳐진 것입니다

**고칠 것 — 두 곳**

- 화면: 표식을 **탭 단위 저장소**가 아니라 **브라우저(기기) 단위 저장소**에
  한 번만 만들어 두고, 다음 로그인부터 그것을 그대로 보냅니다.
  (앱·웹뷰라면 OS 저장소가 더 낫습니다.)
- 서버: **같은 표식이 다시 오면 줄을 새로 만들지 않고** 마지막 접속 시각만
  갱신합니다.

★ **이미 쌓인 중복 줄은 따로 지워 주셔야 합니다.** 코드를 고쳐도 옛 줄은
  자리를 차지한 채 남습니다.

★★ 그리고 **빠져나갈 문**을 하나 열어 주십시오. 지금 안내는 「기존 기기에서
  [내 정보 → 로그인 → 등록 기기]로 해제하라」인데, 그 자리에 가려면 로그인을
  해야 합니다. 세 대가 다 어긋나면 **계정 주인이 자기 계정에 못 들어갑니다.**
  로그인 화면에서 비밀번호 확인 후 바로 해제할 수 있으면 이 막다른 길이 사라집니다.
