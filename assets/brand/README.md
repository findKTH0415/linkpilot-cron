# 앱 아이콘 — 나침반 원이 **온전히, 가운데** 보이게

〈2026-08-30 사장님 지시: 「앱이 깔리면 보이는 모습 샘플처럼 타원이 앱안에 중앙에
배치하여 원형그대로 보이도록 만들어줘」 · D-181〉

## 무엇이 잘못돼 있었나

깔린 `LinkPilot.app` 아이콘은 나침반 원이 **사방으로 잘려** 있었습니다.
그림을 아이콘 칸 **끝까지** 늘린 탓입니다.

맥 아이콘은 가장자리까지 채우는 그림이 아닙니다 — **1024 짜리 칸 안에 824 짜리
둥근 사각형**이 가운데 놓이고 사방 100 이 빕니다. 그 규칙을 지키면 원이 안 잘립니다.

## 여기 있는 것

| 파일 | 무엇 |
|---|---|
| `linkpilot-icon.svg` | 앱 아이콘 원본 — 흰 둥근 사각형 + 나침반 |
| `linkpilot-mark.svg` | 나침반만 (바탕 없음). 파비콘·화면용 |
| `LinkPilot.iconset/` | 맥이 요구하는 크기 **열 장** (PNG, 투명) |
| `geometry.js` | 자릿수 — **여기 한 곳에서만 정한다** |
| `build-icon.js` | 위 셋을 만드는 것. `npm run brand:icon` |
| `png-read.js` | 찍어 낸 그림을 **실제로 읽어 보는** 것 (검사가 쓴다) |

다시 만들려면:

```
npm run brand:icon
```

## 맥에서 `.icns` 로 바꾸는 법 — 명령 한 줄

`.icns` 를 만드는 도구(`iconutil`)는 **맥에만** 있습니다. 그래서 여기서는
열 장까지만 만들어 두고, 마지막 한 줄은 사장님 맥에서 치셔야 합니다.

1. `assets/brand/LinkPilot.iconset` 폴더를 맥으로 가져갑니다.
2. **터미널**을 엽니다 (Spotlight 에서 `터미널`).
3. 그 폴더가 있는 곳으로 옮긴 뒤, 아래를 그대로 칩니다.

```
iconutil -c icns LinkPilot.iconset
```

같은 자리에 **`LinkPilot.icns`** 가 생깁니다.

★ **여기서 자주 막힙니다** — 폴더 이름이 반드시 `LinkPilot.iconset` 이어야 하고,
  안의 파일 이름도 그대로여야 합니다. 하나라도 이름이 다르면 `iconutil` 은
  「invalid iconset」 한 줄만 내고 **무엇이 빠졌는지 안 알려 줍니다.**
  그래서 검사(`im-agent/test/app-icon.test.js`)가 열 장의 이름과 크기를 지킵니다.

## 잘 됐는지 보는 법

`.icns` 로 바꾼 뒤 **부두(Dock)에 올려 놓고 작게 보십시오.** 크게 보면 조금
잘려도 멀쩡해 보이고, 작아져야 어긋난 것이 보입니다.

원이 사방 어디도 안 닿고, 흰 판 안에 **동그랗게** 떠 있으면 맞습니다.

## 이 저장소가 할 수 있는 것과 없는 것

- **그림은 여기서 만듭니다** (위 파일들).
- **앱에 넣는 것은 여기서 못 합니다** — `LinkPilot.app` 을 만드는 자리는
  `linkpilot-platform` 이고, 이 세션은 저쪽에 쓰지 않습니다 (CLAUDE.md §8-2).
  이 폴더를 그대로 전달해 주십시오.
