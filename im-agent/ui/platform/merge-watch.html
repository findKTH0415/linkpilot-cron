이 표는 부딪힌다는 뜻이 아닙니다. 같은 파일이라도 서로 다른 줄을 고쳤으면 git 이 합칩니다. 부딪히는 것은 위의 표입니다. 이 표는 「앞으로 부딪힐 만한 자리」를 미리 보는 용도입니다.
「갈래가 늘면 병합이 어려워진다」의 실제 내용. 갈래가 4개면 견줄 짝이 6개이고, 하나만 더 열면 10개가 됩니다. 짝이 느는 만큼 손으로 풀 자리도 늡니다. 어려워지는 것은 갈래 수가 아니라 짝의 수입니다.
