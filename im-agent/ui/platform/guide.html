외부 업무지침

이 문서를 먼저 읽어야 하는 이유

LinkPilot은 사내 업무 플랫폼이며, 외부에서 접속할 때 메신저 내장 브라우저 · 동영상 형식 · 파일 업로드 세 가지에서 자주 막힙니다. 아래 지침은 그 세 가지를 피해 가는 방법을 담고 있습니다.

1

접속 방법

접속 주소
—
권장 브라우저
Chrome · Safari · 삼성인터넷
계정
담당자에게 요청 (이메일 기준 발급)
카카오톡 · 라인 등에서 링크를 바로 열지 마십시오 메신저 안에서 열리는 브라우저(인앱 브라우저)는 새 창 열기와 파일 내려받기를 지원하지 않습니다. 화면이 빈 채로 멈추거나 다운로드가 실패합니다. 앱 상단에 [외부 브라우저로 열기] 배너가 나오면 그것을 눌러 주시고, 배너가 없으면 위 주소를 복사해 Chrome · Safari에 직접 붙여넣어 주십시오.
홈 화면에 추가하면 편합니다 iPhone — Safari에서 공유 → 홈 화면에 추가를 선택합니다.
Android — 접속 후 나타나는 [홈 화면에 추가] 안내를 누릅니다.
앱처럼 실행되어 인앱 브라우저 문제를 근본적으로 피할 수 있습니다.
2

계정과 권한

등급이용 범위

유료 기능은 무료 계정에서도 메뉴에 보이되 잠겨 있습니다(🔒). 어떤 기능이 있는지 확인한 뒤 필요할 때 담당자에게 승급을 요청하십시오.

3

자료 공유 규칙

파일 올리기

  1. 프로젝트를 열고 [수정]으로 들어갑니다.
  2. 자료공유 파일 영역에서 파일을 선택합니다. 용량 제한은 없습니다.
  3. 진행률이 100%가 되고 목록에 파일이 남는지 반드시 확인합니다.
올렸다고 끝이 아닙니다 — 목록에 남아야 올라간 것입니다 업로드가 중간에 끊기면 “N개는 업로드가 끝나지 않았습니다” 안내가 표시됩니다. 이때 같은 파일을 다시 선택하면 끊긴 지점부터 이어서 올라갑니다. 처음부터 다시 올릴 필요가 없습니다.
클라우드에만 있는 파일은 먼저 내려받아 주십시오 휴대폰 갤러리에 썸네일만 있고 원본은 클라우드에 있는 사진 · 영상은 업로드 중 “파일을 읽을 수 없습니다”로 실패합니다. 갤러리에서 한 번 재생하거나 열어 기기에 내려받은 뒤 다시 선택해 주십시오.
4

동영상 올릴 때

휴대폰 「고효율(H.265)」 촬영 영상은 브라우저에서 재생되지 않습니다 파일은 정상이지만 브라우저가 그 형식을 열지 못합니다. 촬영 전에 아래대로 설정해 주시면 문제가 생기지 않습니다.
아이폰
설정 → 카메라 → 포맷 → 높은 호환성 선택
삼성 갤럭시
카메라 → 설정 → 고효율 동영상(HEVC) 끄기
권장 사양
MP4(H.264) · 가로 1920 이하

서버에서 자동으로 변환하는 기능은 준비 중입니다. 적용 전까지는 위 설정으로 올려 주십시오.

5

프로젝트 협업

프로젝트 한 건에 기본 정보 · 관계자 · 회의기록 · 일정 · 할일 · 자료가 함께 붙습니다. 아래 세 가지만 지켜 주시면 보고서가 자동으로 채워집니다.

  • 회의 · 통화 후 — 회의기록에 날짜 · 장소 · 내용 · 후속조치를 남깁니다.
  • 사람을 만나면 — 연락처에 등록하고 해당 프로젝트에 연결합니다. 명함은 촬영하면 자동 인식됩니다.
  • 할 일이 생기면 — 할일에 등록할 때 프로젝트를 지정합니다.
6

미팅 잡기

일정을 주고받기 번거로우면 담당자에게 예약 링크를 요청하십시오. 링크를 열면 가능한 시간대가 표시되고, 원하는 시간을 선택하면 양측에 자동 등록됩니다. 로그인 없이 사용할 수 있습니다.

7

보고서

프로젝트에 쌓인 정보로 사업보고서를 만들 수 있습니다. (유료 회원 기능)

  1. 메뉴 → 보고서 생성에서 프로젝트를 선택합니다.
  2. 필요하면 [AI 요약 생성]으로 분석 단락을 덧붙입니다.
  3. [인쇄 · PDF 저장]으로 저장하거나 인쇄합니다.

보고서 내용은 앱에 입력된 정보에서 나옵니다. 5번 항목을 지켜 주실수록 보고서가 충실해집니다.

8

보안 및 비밀유지

  • 프로젝트 정보 · 투자 자료 · 연락처는 대외비입니다. 별도 합의 없이 외부에 공유하지 마십시오.
  • 공유 링크는 링크를 아는 사람이면 열람 가능합니다. 전달 대상을 확인한 뒤 보내 주십시오.
  • 업무 종료 시 내려받은 자료는 삭제해 주십시오.
  • 계정은 개인에게 발급됩니다. 공용으로 쓰지 마십시오.
9

문제가 생기면

증상먼저 해볼 것
화면이 비거나 멈춤 메신저 인앱 브라우저인지 확인 → Chrome · Safari로 다시 열기
다운로드가 안 됨같은 원인입니다. 외부 브라우저에서 다시 시도
업로드가 끊김같은 파일을 다시 선택 (이어서 올라감)
동영상이 재생 안 됨 4번 항목 확인 후 재촬영 또는 내려받아 기본 동영상 앱으로 열기
화면이 옛날 그대로새로고침. 그래도 같으면 담당자에게 문의

해결되지 않으면 증상 · 사용 기기 · 브라우저 · 발생 시각과 함께 담당자에게 알려 주십시오. 화면 캡처가 있으면 원인 파악이 훨씬 빠릅니다.
