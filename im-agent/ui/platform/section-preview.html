아직 안 된 것

위 목록과 섞지 않습니다 — 섞으면 이미 된 것으로 읽힙니다.

  • 공공데이터 응답을 실제 키로 대조하지 못했다 응답 필드명은 공식 문서 기준으로 작성했다. 다르면 조회는 성공하는데 값이 전부 비고 화면에는 아무 경고도 안 뜬다. `npm run im:smoke` 출력이 있어야 닫힌다.
  • 서버에서 PDF·PPTX 를 만들 수 없다 의존성 추가 미승인. 대안인 브라우저 인쇄 경로는 동작한다.
  • 차입금리는 아직 산업 통상치다 기준금리(국고채)는 출처가 생겼지만, 거기에 더할 자산유형별 스프레드가 시장 판단이라 정해지지 않았다. 지어내면 "출처 있는 기준금리 + 지어낸 스프레드"가 된다.
