디자인 테마 고르기 — 13종

표지·본문·색·활자가 통째로 바뀝니다. 딜을 지정하지 않아 추천은 붙이지 않았습니다 — npm run im:themes -- --asset datacenter 처럼 주면 순위와 근거가 함께 붙습니다.

지금 테마 사이의 차이는 색과 활자뿐입니다. 각 테마는 표지 구조(rule · split · fullImage)와 밀도(normal · compact · airy)를 선언하는데, 렌더러가 아직 그 값을 읽지 않습니다 (안 쓰이는 항목: cover · density · layouts · emphasisKpis · chart). 그래서 아래 견본들은 짜임새가 서로 같습니다 — 색으로 고르시면 되고, 표지 구조까지 갈리게 하려면 렌더러 작업이 따로 필요합니다 (등록부 D-51).
견본의 활자는 실제와 다릅니다. 이 화면을 만든 서버에 테마가 요구하는 Noto Sans KR·Noto Serif KR 이 없어, 브라우저가 다른 글꼴로 대신 그렸습니다. 색·짜임새는 보고 고르셔도 되지만 글자 모양은 최종본과 다릅니다. (글꼴을 번들로 넣기 전까지는 만드는 서버마다 활자가 달라집니다)

Custom

사용자 지정

사용자가 직접 지정하거나 Brand Kit 을 적용

    이 테마로 정하려면 themeId: custom

    고른 기록이 남습니다. 테마를 정하면 누가·언제·왜 골랐는지와 이전 테마가 함께 저장되고(design-state), 되돌릴 수 있습니다.

    내용은 바뀌지 않습니다. 테마는 보이는 방식만 정합니다 — 수치·출처·검증 결과는 어느 테마를 골라도 같습니다.

    표지 견본의 수치는 디자인 확인용 예시이며 실제 프로젝트 값이 아닙니다.
